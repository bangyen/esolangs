# Malbolge 17-input experiments

The public generator covers all seventeen-input tables. To replay its certificate
from the repository root, run the following with a C11 compiler on the path.

```sh
uv run python experiments/malbolge-n17/verify_decoder.py
```

The [selector proof](../../src/esolangs/languages/malbolge/tests/proof_packed_decoder.py)
reconstructs the seven group masks from executable bytes and checks every
assignment. The native check runs all 131,072 inputs from reset. Each column
marker may vary, and every permitted payload byte must restore its word and
reach the predicted lookup address. During unrelated pointer reads the checker
follows all possible operands until the data pointers rejoin. It checks all
1,312 lookup and printer settings, reusing a suffix execution when every cell
it reads before writing gives the same result. The union of the instruction
paths is acyclic, with a longest path of 9,101 commands.

The fixtures below record earlier builds.

## Exact truth table

`fixture-a.mb` reads 17 ASCII bits, most significant first, prints the
corresponding digit from `fixture-a.bits` and halts. All 131,072 inputs
matched the reference table from reset. Row `r` is bit `7 - r % 8` of
byte `r // 8`. For example, rows 0 and 1 print `1` and `0`.

```sh
printf 00000000000000000 | uv run esolangs run Malbolge experiments/malbolge-n17/fixture-a.mb
```

[Fixture B](fixture-b.mb) matched all 131,072 successive bits from
`random.Random(17017).randrange(2)`, using one seeded Python generator
for the whole table.

[Fixture D](fixture-d.mb) uses the same input and bit order. All 131,072
outputs matched the packed reference bytes generated by Python's
`random.Random(230017).randbytes(16384)`.

## Selector coverage

Five groups of inputs share the choice of lookup table and printer polarities.
The [checker](selector_coverage.py) tries all 131,072 assignments to their
17 input rows. Each line of [measured masks](selector-masks.txt) describes
one lookup table. Bit `p` of a column mask records that the program produced
pattern `p` with all three printer polarities set to zero. Within a group,
the first row supplies the least significant bit. Input 89,100 exposes a
pointer dependency outside these masks when words 29,530 and 59,036 vary
together.

```sh
python3 experiments/malbolge-n17/selector_coverage.py
```

## Marker prototype

`marker.mb` reads 17 ASCII bits, most significant first. An input ending
in `10` selects the adjacent marker. The other three endings select the
original marker. The program reads that marker at instruction 38,575 and
halts at 38,576 with empty output.

This is fixture A of the marker experiment. All 131,072 inputs selected
the expected address from reset. The 184-instruction pointer walk would
need to fit into 74 instructions to use it in the full decoder.

Run this trace from the repository root to see the two addresses for
inputs that share their first 15 bits.

```sh
uv run python - <<'PY'
from pathlib import Path

from esolangs.languages.malbolge.interpreter import _Machine
from esolangs.runtime.io import ScriptedIO

source = Path("experiments/malbolge-n17/marker.mb").read_text(encoding="ascii")
for row, expected in [(61472, 51031), (61474, 51032)]:
    io = ScriptedIO(f"{row:017b}")
    machine = _Machine(source, io)
    while machine.ip != 38575 and not machine.halted:
        machine.step()
    assert machine.ip == 38575 and machine.state[2] == expected
    print(row, machine.state[2])
    machine.step()
    assert machine.ip == 38576
    machine.step()
    assert machine.halted and io.reads == 17 and not io.past_end
    assert io.getvalue() == ""
PY
```
