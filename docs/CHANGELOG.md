# Changelog

Breaking changes are listed first. Before 1.0 a minor release may break the
public API; see [the compatibility policy](usage.md#compatibility).
Releases before 0.10.0 are described on the
[GitHub releases page](https://github.com/bangyen/esolangs/releases).

## 1.3.0

- **Breaking:** `encode_inputs("Taglate", bits)` no longer prepends a `0`
  for odd n > 1: `[1, 0, 1]` gives `'101'`, not `'0101'`. A Taglate
  program generated by 1.2.0 for odd n needs that stdin; regenerate it.
- Add Aprknia, Balik, BASICER, lol waht i cant edit talk pages, NOR
  machine, Pilas and Tiangou (102 languages).
- An unknown language name suggests the names it begins:
  `lol` asks "did you mean lol waht i cant edit talk pages?".
- Generated programs change:
  - Taglate programs for odd n are 37-49% smaller (n = 3..9).
  - ROTfuck programs from n = 7 are smaller: 41% at n = 7, 13% at
    n = 10.
  - 6-5 programs from n = 8 are 36-39% smaller.
  - Interprogck8 programs run about a third fewer commands.
- `esolangs run --seed` on a language that draws no random values is
  refused before stdin is read; with stdin held open it hung.
- INTERCAL, Interprogck8, 1 + i, Polynomial and S*bleq interpreters load or
  run faster on large programs; S*bleq rows took time quadratic in the
  program.

## 1.2.0

- **Breaking:** Remove Vandevelo; its name no longer resolves. Its
  generator's linearity was unproved, and an open scaling bound removes a
  language.
- Add Bleh, Freestajlo, Stisp, Kiss, Sonata and SwitchCase (95 languages).
- Generated programs change:
  - Piet, ArrowQueue, B-tapemark and Fish default to the least-area layout.
  - Symmetric and affine tables take count or fold builds in Boolfuck,
    BFStack, Circlefuck, EGL, Fish, Minsky Swap, Modulous, Painfuck,
    ROTfuck, Smallfuck and bit~.
  - Interprogck8 programs grow linearly in the table, about a third of
    the old size at n = 10; they run more commands.
- Forþ runs in time linear in its scopes; a program with S scopes took
  O(S^2).

## 1.1.0

- **Breaking:** Remove `esolangs debug`. The stepping API,
  `esolangs.debugger`, is unchanged.
- **Breaking:** Remove `--portable` and `-p` from `generate` and `run`.
  `dump_program` and `load_program` still save and restore dialect choices
  and template setters.
- **Breaking:** `list` keeps `--generator`, `--interpreter-only` and
  `--grep`; filter on every other capability with `list --json --details`.
- Until 2.0, a minor release may remove CLI options and commands.
- Add Hot and Blindfolded Arithmetic (90 languages).
- Fix: Packlang `balance=True` programs with a 0- or 1-digit loop bound ran
  wrong (n=5); Interprogck8 treats an unclosed `[` line as an unknown
  instruction, not a range.

## 1.0.0

- **Breaking:** `balance=True` picks the text layout fitting the smallest
  on-screen square, max(columns, 2 x rows), then the shortest.  It minimized
  |columns - rows| first, which rendered about twice as tall as wide and
  could pick a far longer program to shave one column.  Most balanced text
  programs change shape.  Rasters likewise rank by max(width, height) in
  pixels, then area; Piet no longer returns a packed layout larger than its
  default.
- **Breaking:** A name resolves punctuation-insensitively only by dropping
  punctuation the language's own name has.  `Piet++`, `Brainfuck++` and
  `hq9++` ran Piet, brainfuck and HQ9+; they now raise
  `UnknownLanguageError`, which 0.15.0 claimed for Piet++.
- **Breaking:** CPython's 4300-digit int/str cap and `OverflowError` raise
  `InterpreterLimitError` (CLI exit 1).  The cap raised `ProgramError` (exit
  2) on valid programs; Fackward's `$` past `sys.maxsize` escaped bare.
- **Breaking:** `CompressedText`'s optional arguments (`language`,
  `settings`, `limits`) are keyword-only, as usage.md promises.
- Fix: `balance=True` fits SendStuff, Pointless, Fackward and What!? by whole
  tokens, exactly; it estimated, and SendStuff `0010` missed a squarer width.

## 0.15.0

- **Breaking:** Remove Factor and Piet++; their names no longer resolve.
  Their generators re-spelled brainfuck's and Piet's.
- **Breaking:** `DialectSettings` refuses a value outside its key's choices
  (`None` included) when constructed; it was accepted until first use.
- **Breaking (CLI):** `generate` refuses to write PNG or gzip to a terminal
  (exit 2); redirect, or pass `--plain` for gzip.
- `ExecutionTimeoutError.bound` names the bound that fired: `"timeout"` or
  `"max_steps"`.
- Add SendStuff, Quassaunt, Codesick, Object disoriented, 1 + i, Pointless,
  Ascenic, Fackward and What!? (88 languages).

## 0.14.0

- **Breaking:** `describe()["input_shape"]` and `["input_encoding"]` are
  `None` unless `reads_input` (templates and Deadfish, HQ9+, Nope.); the CLI
  list filters agree.  `encode_inputs` refuses Deadfish, HQ9+ and Nope.
- **Breaking:** `run(isolated=)` and `generate(balance=)` must be `bool`.
- **Breaking:** a program object's language tag must name a registered
  language and is stored canonically; its settings need a language and must
  be valid for it.  Generated programs are immutable.  `Raster` and
  `CompressedText` refuse bad arguments with `ProgramError`/`ArgumentError`
  (they raised `TypeError`, `AttributeError` or bare `ValueError`).
- **Breaking:** `eof_is_a_value` is true for Fish, thisthat, Piet, Piet++ and
  Unary; `VM.memory` is integer cells only (`[]` for Caballo, Crement and
  B-tapemark).
- **Breaking:** numeric input reads ASCII decimal only (`1_0` and `٣` were
  accepted).  An upscaled raster over 2^28 pixels raises `ArgumentError`.
- **Breaking (CLI):** `help <unknown>` exits 2; a failed run's partial
  output gets no added newline on a pipe; `describe --spec --json` prints the
  spec as a JSON string.
- Add `Debugger.eof_is_a_value`; `Debugger.break_at` and `--break-at` take
  negative positions.
- Fix: an isolated worker exits when its parent is killed (SIGTERM/SIGHUP
  left it running); the CLI with closed stdin, stdout or stderr, or an ASCII
  locale, no longer exits 70; `instantiate(truth_table=)` accepts every
  width-aware template; scaled rasters, `InputExhaustedError` and
  `UnknownLanguageError` pickle intact; `typing.get_type_hints` resolves on
  `Raster` and `CompressedText`; isolated and stepped timeouts share one
  message; bit~ reads input as a byte; Piet and Piet++ drop surrogates.
- Docs: corrected example sizes, counts, and the spec text of 13 languages
  against their behaviour; a dialect-settings section in usage.md.

## 0.10.0

Covers everything since 0.8.0, including 0.9.1, which shipped without notes.

### Breaking changes

The public API is settled ahead of 1.0:

- **Optional arguments are keyword-only** everywhere in `esolangs.__all__`,
  `esolangs.debugger.__all__` and the `Language` methods. Required ones stay
  positional.
  - `generate(language, truth_table, *, width, balance, scale, settings)`
  - `instantiate(language, template, bits, *, width, truth_table, settings)`
  - `encode_inputs(language, bits, *, truth_table)`
  - `run(language, program, *, stdin, timeout, seed, isolated, max_steps,
    scale, max_output, max_memory, settings)`: `stdin` is keyword-only too.
  - `make_vm` / `make_debugger(language, program, *, stdin, scale, settings)`
  - `Debugger.run(*, max_steps, timeout)`
  - `Raster(rows, *, language, settings)`: `rows` is required;
    `Raster.upscaled(scale)` takes a required scale.
- **`run(..., timeout=None)`** is the default. With `isolated=True` it now
  means the 30-second default instead of being refused.
- **`run(..., seed=...)`** must be an `int`; a `str`, `float` or `bool` raises
  `ArgumentError`.
- **`instantiate`** accepts what `generate` returns and raises
  `TemplateError` for a raster, so the documented flow type-checks under
  `mypy --strict`.
- **`ProgramSource` / `InputSource`** use `typing.IO` instead of a private
  protocol.
- **Removed** `InputMismatchWarning` (never emitted) and `complete_vm` from
  `esolangs.debugger.__all__` (still in the internal `esolangs.vm`).
- **`describe()`**: the `interpreter` (an internal module path) and
  `proof_status` fields are gone; `examples` are paths relative to the
  package (`importlib.resources.files("esolangs") / path`); an absent value
  is always `None` (`generator_restrictions` and `answer_pattern` were `""`).
- **Public scope**: `esolangs.__all__`, `esolangs.debugger.__all__` and the
  documented CLI are public; every other module is internal.

Language removed (already absent from 0.9.1):

- **3D Brainfuck**: its specification leaves the core undefined.

Interpreter behaviour that changed to match the specification or the wiki's
examples:

- **Tape-based languages** grow the tape left instead of clamping at cell 0
  (Minifuck still clamps: its tape is right-infinite and the wiki cat opens
  with `<`).
- **Flowchart** does Boolfuck byte I/O; its generated programs read 8 bits an
  input and print an ASCII answer.
- **ROTfuck** rotation is a dialect setting (`backward`|`forward`, default
  `backward`); a jump seeks before rotating.
- **Alight** three-argument `at` is a dialect setting (`list_update`
  `in_place`|`copy`, default `in_place`).
- **Bitdeque** `GOTO N` counts from 1; past the end halts; a taken `GOTO 0`
  raises.
- **RAM0** `goto 0` raises; **Dimensional** rejects a malformed literal before
  running.
- **SLOW ACV MAMMALIAN** `EXCRETE`/`PRONOUNCE` default to the page's modulo 255.
- **INTERCAL** implements INTERCAL-72 plus single-threaded C-INTERCAL;
  `READ OUT` prints zero as a lone overbar; foreign digit words, `COMING FROM`
  gerund labels, and `COME FROM` re-fires.
- **Piet** numeric input accepts only `[+-]digits`; a depth-0 roll pops its
  operands.
- **Sophie** `;` and `:` at end of input read 0.
- **Inject** `readto` keeps blank lines and empties the block at EOF.
- **thisthat** takes newline-separated input sets and the readings the wiki
  examples force.
- **Super SNUSP** without `"` starts rightward on the last line's last
  character.
- **Painfuck** `v` skips on a nonzero cell; a repeated `j` reads each time.
- **6-5**, **3x**, **Collatz Multiverse**, **bit~**, **Forbin**, **Home Row**,
  **Grapheme**, **EGL**, **Fish**, **Thue**, **Befunge**, **Container**,
  **Dig**, **Qoibl**, **Jaune**, **Unlambda** and **Decleq**: smaller semantic
  corrections, each described in the language's docstring.

### Fixes

- All 80 languages were diffed on random programs against an independent
  implementation (a clean-room reimplementation from the esolangs.org page, or
  a reference interpreter such as npiet or C-INTERCAL); the disagreements
  were resolved in favour of the wiki's examples.
- The Line and 3x generators are thread-safe; concurrent use could return a
  corrupt Line program or crash 3x.
- An in-process `MemoryError` raises `InterpreterLimitError`, as isolated
  execution already did.
- Unlambda and Thue run in linear time; deep continuations and long Thue
  states were quadratic (an Unlambda program taking about five minutes now
  takes about a second).

### Packaging and docs

- The `dev` extra is now a `dev` dependency group (`uv sync --group dev`), so
  it no longer appears in the published metadata.
- Repository-only tooling moved out of the package into `scripts/`; the sdist
  no longer carries a partial test suite.
- The wheel is reproducible; CI smoke-tests it on Python 3.12 and 3.14 on
  Linux, macOS and Windows.
- `Typing :: Typed` classifier.
- `describe()` gains `random`: whether the interpreter draws at random, so
  `run(seed=...)` applies. `run --help` points to it for `--seed`.
- `run --help` lists every exit status (0, 1, 2, 70, 120, 124, 130).
- Docs: untrusted programs need `isolated=True`, a `timeout` and, on Linux,
  `max_memory`.
