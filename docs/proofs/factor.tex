\begin{abstract}
A Factor source denotes a decimal integer whose prime
factorization encodes a Brainfuck program: a prime's residue modulo $11$
selects an instruction and its exponent gives the run length.  We prove that
the worst-case Factor source length for a Boolean truth table of length $T$ is
$\Theta(T\log T)$.  The upper bound combines a linear-size Brainfuck
construction with a fixed-modulus short-interval theorem for primes.  The
lower bound counts every integer encoding of at most $D$ digits and remains
valid in the presence of ignored prime factors, comments, and leading zeros;
these encodings realize only $\exp(O(D/\log D))$ behaviors.  The tree's
constant is exact, the walk's leading constant is explicit, and a sieve of
the classes modulo $11$ through $10^{11}$ gives a proven digit ceiling at
every arity up to $19$.  Beyond that arity an explicit short-interval
theorem on GRH makes the threshold numerical: the ceiling is then
$24.6\,T\log T$ at every arity, falling to $35/\log 10<15.21$.
Unconditionally, an explicit log-free density estimate and explicit
zero-free regions at the modulus $11$ give a threshold with a value,
$x_0>e^{15900}$, and a ceiling of $3.05\cdot10^4\,T\log T$ at every arity,
falling below $19181$.  Carrying the
table as tape data and chaining one byte-sized index digit per level beats
the tree's constant, and letting one walk cell serve a whole group of
entries beats it again; spelling two entries in one byte with signed values
then halves the span for half a character a cell, giving $1.006\,T$
characters; and an enumerative code, one Delannoy-numbered vector per group
of entries, reaches $T/\log_2(1+\sqrt2)=0.787\,T$, which is what any program
that carries the table as tape data behind a fixed decoder must spend, since
a drawing of $C$ characters reaches only $(1+\sqrt2)^{C+o(C)}$ tapes.  The
walk's factor of two was an artifact of applying a worst-case gap bound at
every step: the walk crosses each large gap once, so a second moment for
primes in short progressions makes it pay one logarithm a run, exactly on
GRH and within $15/14$ unconditionally.  Running the count with the
instruction primes themselves makes the lower bound explicit too, and
counting only the words free of the five cancelling adjacencies lifts it to
$1/(\log_2(1+\lambda)\log10)=0.1505$ with $\lambda=6.388$ their growth rate.
The constant is thus bracketed between $0.1505$ and $0.3416$ on GRH, a ratio
of $2.27$, and what separates the two is a question about Brainfuck alone.
\end{abstract}

\section{Encoding model}

Let
\[
  N=\prod_p p^{e_p}
\]
be the positive integer spelled by the decimal digits of a Factor source;
every other character is a comment.  A source with no digits is read as
$N=1$, which decodes to the empty program.  An all-zero digit string also
decodes to the empty program; it is one exceptional behavior and is excluded
from the logarithmic notation below.
For a prime $p$, the residue $p\bmod 11$ selects the Brainfuck instruction
according to
\[
\begin{array}{c|cccccccc}
p\bmod 11&1&2&3&4&5&6&7&8\\ \hline
\text{instruction}&>&<&+&-&.&,&[&]
\end{array}
\]
and the exponent $e_p$ is its run length.  Residues $0,9,10$ are ignored.
The selected primes are read in increasing order.

For example, $45=3^2\cdot5$.  Since $3\bmod11=3$ and
$5\bmod11=5$, the source \texttt{45} decodes to \texttt{++.}: two
increments followed by output.  Starting from a zero cell, it emits the byte
of value $2$.  This example also illustrates that source order is irrelevant:
instruction order comes from increasing prime factors.

Write $C=\sum_{p\bmod 11\in\{1,\ldots,8\}}e_p$ for the length of the decoded
Brainfuck program, $m$ for its number of maximal runs, $Q$ for its largest
selected prime, and $D$ for the number of decimal digits of $N$.  Then
\begin{equation}\label{eq:digits}
  \log N=\sum_p e_p\log p,
  \qquad D=\lfloor\log_{10}N\rfloor+1.
\end{equation}
Comments and leading zeros change the literal source length but not $N$;
they can never help a shortest encoding.

Execution uses the standard Brainfuck machine: byte cells wrap modulo $256$,
the tape grows to the right, a move left from its initial cell stays there,
and matched brackets have their usual while-loop semantics.  For $n\ge1$ put
$T=2^n$.  Each input bit is supplied as a separate line containing its ASCII
digit.  A program
\emph{computes} a table $t=(t_0,\ldots,t_{T-1})\in\{0,1\}^{2^n}$ if, for every
$b_1\cdots b_n\in\{0,1\}^n$, a separate run on the input lines
$b_1,\ldots,b_n$ terminates and emits exactly the ASCII digit of
$t_{(b_1\cdots b_n)_2}$, with zero-based subscripts.
Define
\[
 \mathcal C_F(T)=\max_{t\in\{0,1\}^T}
 \min\{\text{total source characters of }P:P\text{ computes }t\}.
\]
Deleting comments and leading zeros never changes execution, so the minimum
source length over programs computing $t$ equals the minimum decimal-digit
count of a positive integer whose decoded program computes $t$.  All
unqualified logarithms below are natural.

\begin{theorem}\label{thm:main}
Every $T$-bit truth table has a Factor program of
$O(T\log(T+1))$ decimal digits.  Some $T$-bit truth tables require
$\Omega(T\log T)$ digits.  Hence $\mathcal C_F(T)=\Theta(T\log T)$.
\end{theorem}

Factor was introduced in 2020 as a prime-factor encoding of
Brainfuck~\cite{factor-spec}.  Its specification invokes Dirichlet's theorem
to ensure an unlimited supply of instruction primes.  We instead study
decimal description length.  The upper bound requires quantitative control
of successive instruction primes, while the lower bound counts all encodings,
including those with ignored factors.

\section{Upper bound}

The construction first emits a Brainfuck decision tree and then replaces each
maximal run by one prime power.  We begin by bounding the size of the decision
tree.

\begin{lemma}[Decision-tree size]\label{lem:tree}
For $n\ge2$, every $T$-bit truth table has a Brainfuck decision-tree program
of length
\[
  C\le\tfrac{35}{2}T+55n+25,
\]
with equality for parity.
\end{lemma}

\begin{proof}
Use the following identity-order construction.  For each input in turn, a
preamble reads its ASCII digit into cell $2i$ with \texttt{,} and subtracts
$48$ to obtain bit $b_i$, leaving cell $2i+1$ as a zero flag.  A node at depth
$i$ is entered at cell $2i$ and left at cell $2i+1$, both zero on exit:
\[
  \texttt{>+<[->-}\;A\;\texttt{]>[-}\;B\;\texttt{]}.
\]
The first loop runs on $b_i$ and clears it and the flag, so the one-branch
$A$ runs exactly when $b_i=1$; the second runs on the surviving flag, so the
zero-branch $B$ runs exactly when $b_i=0$.  The branch $A$ must end at cell
$2i$ and $B$ at cell $2i+1$.  A nonconstant child is
$A=\texttt{>}S\texttt{<<<}$ or $B=\texttt{>}S\texttt{<<}$, where $S$ is its
node.  A constant-one child moves to the result cell $2n$, increments it and
returns, costing $4(n-i)$ in $A$ and $4(n-i)-1$ in $B$; a constant-zero child
costs one \texttt{<} in $A$ and nothing in $B$.  After the root, one final
gadget moves to the result cell, adds the ASCII-zero offset and prints.

Let $F(k)$ bound the length of a node of height $k=n-i$ that is not the
root.  Its own characters number $12$.  At height $1$ both children are
single rows, and they differ because the node's subtree is not constant, so
$F(1)=12+4+0=12+1+3=16$.  At height $k\ge2$ a child costs at most
$\max\{F(k-1)+4,4k\}$ in $A$ and $\max\{F(k-1)+3,4k-1\}$ in $B$.  By
induction $F(k-1)+19=35\cdot2^{k-2}$, and then $F(k-1)\ge4k-4$, so
\[
  F(k)\le12+2F(k-1)+7,
  \qquad
  F(k)\le35\cdot2^{k-1}-19.
\]
The root obeys the same bound unless the table is constant, when it costs at
most $12+8n-1\le35\cdot2^{n-1}-19$ for $n\ge2$.  The preamble costs
$49n+2(n-1)$, the return to cell $0$ costs $2(n-1)$, and the final gadget
costs $(2n-1)+48+1$.  Adding $35\cdot2^{n-1}-19$ gives the displayed bound.
Parity has no constant subtree above the leaves, so every inequality is an
equality.
\end{proof}

The implementation returns the shorter of this identity-order program and one
built for a reordered set of variables, so its $C$ is no larger.  At $n=1$ the
constant-one table costs $118$ characters, three above the displayed formula.

The encoder replaces each maximal run by one prime power.  It scans
primes upward and chooses the first prime in the residue class required by
the next run.  The following standard consequence of the prime number theorem
in short arithmetic progressions controls this adaptive sequence.

\begin{lemma}[Fixed-modulus short intervals]\label{lem:short}
There are constants $x_0$ and $\theta<1$ such that for every reduced
residue class $a\pmod{11}$, every $x\ge x_0$ has a prime
\[
  p\equiv a\pmod {11},
  \qquad x<p\le x+x^\theta.
\]
\end{lemma}

\begin{proof}
The Hoheisel theorem for arithmetic progressions gives the expected
asymptotic number of primes in $(X-h,X]$ in every reduced class modulo $q$
when $q\le(\log X)^A$ and
$h\ge X^{7/12+\varepsilon}(\log X)^A$; see Thorner and
Zaman~\cite[Section~1.2]{thorner-zaman}.  Fix
$7/12+\varepsilon<\theta<1$, put
$X=x+x^\theta$ and $h=x^\theta$.  Since $X\sim x$, the displayed size
condition holds for all sufficiently large $x$, while
$(X-h,X]=(x,x+x^\theta]$.  Taking $q=11$, the count in each of the ten
reduced classes is $(1+o(1))\,h/(10\log X)$, which is positive for large
$x$; one $x_0$ serves all eight classes used below.  The constants $x_0$ and
$\theta$ are not made explicit, and only their existence is used.
\end{proof}

\begin{lemma}\label{lem:adaptive}
If $p_i$ is the prime selected for the $i$th run, then
$p_i=O\bigl(i^{1/(1-\theta)}\bigr)$.  In particular,
$\log Q=O(\log(m+1))$.
\end{lemma}

\begin{proof}
Let $i_0$ be the first index with $p_{i_0}\ge x_0$.  Then
$i_0\le\pi(x_0)+1$, and $p_{i_0}\le x_0+x_0^\theta$ by Lemma~\ref{lem:short}
at $x=x_0$, so the indices before $i_0$ change only the implied constant.
From $i_0$ on, Lemma~\ref{lem:short} gives
\[
  p_{i+1}\le p_i+p_i^\theta.
\]
Put $r=1-\theta>0$.  Concavity of $x^r$ gives
\[
  p_{i+1}^r-p_i^r
  \le r p_i^{r-1}(p_{i+1}-p_i)\le r.
\]
Thus $p_i^r=O(i)$ and $p_i=O(i^{1/r})$.
\end{proof}

\begin{proposition}[Upper bound]\label{prop:upper}
The generated Factor source has $D=O(T\log(T+1))$ digits.
\end{proposition}

\begin{proof}
By Lemma~\ref{lem:tree}, $C=O(T)$, and there are at most $C$ runs.  By
Lemma~\ref{lem:adaptive},
$\log Q=O(\log(m+1))$.  Equation~\eqref{eq:digits} yields
\[
  \log N\le C\log Q
  =O\bigl(C\log(m+1)\bigr)
  =O\bigl(T\log(T+1)\bigr).
\]
Changing logarithm bases proves the digit bound.
\end{proof}

\section{Explicit constants}

Proposition~\ref{prop:upper} hides two constants: the tree's, which
Lemma~\ref{lem:tree} makes exact, and the prime walk's, which depends on the
unstated $x_0$ and $\theta$ of Lemma~\ref{lem:short}.  The walk's leading
constant is explicit even so; its threshold is not.

\begin{corollary}[Leading constant]\label{cor:leading}
For every $\theta$ admissible in Lemma~\ref{lem:short}, the generated
sources satisfy
\[
  \limsup_{T\to\infty}\;\max_{t\in\{0,1\}^T}\frac{D(t)}{T\log T}
  \le\frac{35}{2(1-\theta)\log10}.
\]
Every $\theta>7/12$ is admissible, so the limit superior is at most
$42/\log10<18.25$.
\end{corollary}

\begin{proof}
The proof of Lemma~\ref{lem:adaptive} gives
$p_i^{1-\theta}\le p_{i_0}^{1-\theta}+(1-\theta)i$, hence
$\log Q\le(1-\theta)^{-1}\log m+O(1)$.  With $m\le C$ and
Lemma~\ref{lem:tree},
$\log N\le C\log Q\le\frac{35}{2}T\bigl((1-\theta)^{-1}\log T+O(1)\bigr)
+O(n\log T)$.  Divide by $\log10$.  The proof of Lemma~\ref{lem:short}
accepts every $\theta>7/12$, and $\frac{35}{2}\cdot\frac{12}{5}=42$.
\end{proof}

The constant $\frac{35}{2}$ above is the decision tree's, and the tree is not
the cheapest program.  A table can be carried as data on the tape and indexed,
which trades execution time for length; since $\mathcal C_F(T)$ minimizes over
all programs, that trade is free here.  The obstacle is that a Brainfuck cell
holds one byte, so an index into $T$ cells does not fit in a cell once
$n>8$.  Chaining removes it: split the index into chunks of at most eight
bits, one per level of a tree of blocks, and read each chunk from the input at
the moment and the place its level needs it, so no counter is ever carried.

\begin{lemma}[Chained lookup]\label{lem:chain}
Every $T$-bit truth table has a Brainfuck program of at most
$2.532\,T+O(\log T)$ characters.
\end{lemma}

\begin{proof}
Let the chunk sizes be eight bits at every level, with the remainder placed at
the second level from the top, and put $r=2^{8}=256$.  Define block widths by
$B_{-1}=2$ and $B_j=rB_{j-1}+2$; a level-$j$ block holds $r$ sub-blocks
followed by two scratch cells, its \emph{anchor}, and a leaf block holds $r$
pairs of a walk cell and a data cell.  Unfolding the recursion,
$B_{m-1}=2T+2(T-1)/(r-1)$ for $T=r^m$.

Emit the table by walking the whole span once, writing a \texttt{+} at each
data cell whose entry is set; storing the complement when the set entries are
in the majority caps that at $T/2$.  This leaves the pointer on the top
anchor.  At each level in turn, accumulate the level's chunk from the input
into the anchor by $a\mapsto2a+b$, move it two cells left onto the last
sub-block's anchor, and run
\[
  \texttt{[[-}\,\underbrace{\texttt{<}\cdots\texttt{<}}_{B_{j-1}}
  \texttt{+}\underbrace{\texttt{>}\cdots\texttt{>}}_{B_{j-1}}
  \texttt{]}\underbrace{\texttt{<}\cdots\texttt{<}}_{B_{j-1}}\texttt{-]},
\]
which hops one sub-block left per unit and lands on the anchor of sub-block
$r-1-d$, where $d$ is the chunk.  The hop touches only anchors, which are
scratch, so the data is undisturbed, and the landing cell is left zero.  The
data is therefore laid out reversed at each level.  At the leaf the same step
with $B_{-1}=2$ lands on a walk cell, and one \texttt{>} reaches the answer,
which is printed after adding $48$.

For the count: the walk is $B_{m-1}-2$ characters, the set entries at most
$T/2$, the hop loops $3\sum_{j<m-1}B_j+O(m)$, and reading the chunks
$O(n)$.  Since $\sum_{j\le m-2}B_j=2(T-1)/(r-1)+O(T/r^2)$, the total is
\[
  \Bigl(2+\frac{2}{r-1}\Bigr)T+\frac{T}{2}
  +\frac{6T}{r-1}+O\!\left(\frac{T}{r^2}\right)+O(n)
  =\Bigl(\frac52+\frac{8}{255}\Bigr)T+O\!\left(\frac{T}{r^2}\right)+O(n).
\]
Here $\frac52+\frac{8}{255}=2.53137\ldots$ and the $r^{-2}$ terms contribute
a further $9.3\cdot10^{-5}\,T$, so the total is below $2.532\,T$.
\end{proof}

Two cells an entry is more than the hop needs.  The counter hop requires a
zero cell beside what it addresses, but only at the granularity it
addresses, so the leaf level can address \emph{groups} and let a decision
tree finish the job.

\begin{lemma}[Grouped lookup]\label{lem:group}
Every $T$-bit truth table has a Brainfuck program of at most
$1.516\,T+o(T)$ characters.
\end{lemma}

\begin{proof}
Fix $k=2^{g}$ and lay the table out in groups
\[
  [W][S_0][S_1][d_0]\cdots[d_{k-1}],
\]
of $k+3$ cells for $k$ entries.  Run the chain of Lemma~\ref{lem:chain} on
the top $n-g$ index bits with the groups as its leaf level, so its hop
stride there is $k+3$ and it touches only the cells $W$, which are zero; the
seat step at that level moves by the stride rather than by $2$, a group's
anchor being its first cell rather than two before its last.

The walk leaves the pointer on the $W$ of the selected group.  Resolve the
remaining $g$ bits by a decision tree over that group, entered and left on
$W$: a node reads its bit into $S_0$ and raises a flag in $S_1$, then
\[
  \texttt{[->-<<}\;\textit{high}\;\texttt{>]}\qquad
  \texttt{>[-<<}\;\textit{low}\;\texttt{>>]<<},
\]
where each subtree returns to $W$ with $S_0=S_1=0$, so both brackets close
on a zero.  A leaf steps right to its data cell, adds $48$, prints, clears
the cell and steps back; under the complement it instead holds $49$ on $W$
and drains the stored bit into it.  The tree is emitted once, after the
walk, not once per group, and is $O(k^2)$ characters.

Counting as in Lemma~\ref{lem:chain}, the span is
$(1+3/k)(1+\frac1{255})T$, the set entries cost at most $T/2$ under the
complement, and the hops $3/255$ of the span.  Taking $k=\lfloor\log
T\rfloor$ makes the tree $O(\log^2T)$ and $3/k=o(1)$, leaving
\[
  \Bigl(1+\tfrac1{255}\Bigr)\Bigl(1+\tfrac3{255}\Bigr)T+\frac T2+o(T)
  =1.51573\ldots T+o(T).\qedhere
\]
\end{proof}

\begin{lemma}[Packed lookup]\label{lem:pack}
Every $T$-bit truth table has a Brainfuck program of at most
$1.006\,T+o(T)$ characters.
\end{lemma}

\begin{proof}
A cell is a byte, so \texttt{-} writes $255$, that is $-1$, in one character,
and spelling $v$ costs $\min(v,256-v)$.  Store two entries to a cell and
spell the four patterns by an injection into $\{-1,0,1,2\}$, of costs
$\{1,0,1,2\}$, chosen by frequency: the commonest pattern gets $0$, the next
two get $\pm1$, the rarest gets $2$.  With frequencies
$f_1\ge f_2\ge f_3\ge f_4$ the cost per cell is $f_2+f_3+2f_4$, which under
that ordering is largest when all four are equally common, so it is at most
one character a cell and at most $T/2$ in all.  This subsumes the complement
of Lemma~\ref{lem:group}: complementing the table permutes the patterns and
leaves the frequencies alone.

Lay the cells out in groups $[W][S_0][S_1][c_0]\cdots[c_{k-1}]$, now
$k=2^{g-1}$ cells for $2^{g}$ entries, and run the chain of
Lemma~\ref{lem:chain} on the top $n-g$ bits with leaf stride $k+3$.  Resolve
the first $g-1$ of the remaining bits by the tree of Lemma~\ref{lem:group},
except that a leaf \emph{parks} its cell's byte on $W$,
\[
  \texttt{>}^{\,3+i}\,\texttt{[-}\,\texttt{<}^{\,3+i}\texttt{+}
  \texttt{>}^{\,3+i}\texttt{]}\,\texttt{<}^{\,3+i},
\]
rather than printing.  The tree's two branches reunite on $W$ with
$S_0=S_1=0$ and none of its brackets tests $W$, so afterwards the pointer is
on $W$ holding the selected byte.

Raise $W$ by one, so a stored $v$ arrives as $u=v+1\in\{0,1,2,3\}$, read the
last index bit into $S_0$, and branch on it as in Lemma~\ref{lem:group}.
Each branch is the same switch on $u$,
\[
  \sigma_j=\texttt{>+<[->-<}\;\sigma_{j+1}\;\texttt{]>[-<}\;\varepsilon_j\;
  \texttt{>]<},\qquad \sigma_3=\varepsilon_3,
\]
where $\varepsilon_j$ prints the bit that $j-1$ codes for and then clears $W$.
Entering the bracket means $u\ne0$; the body decrements $u$ once and
$\sigma_{j+1}$ drives it to zero, so the body runs exactly once and the
bracket closes on a zero.  Clearing after printing is what lets every
enclosing bracket retest a zero in turn.  The switch has four cases, so it is
$O(1)$, and it is emitted twice.

Each level of the chain adds two cells to a block of $256(k+3)$, so the span
is $\frac12(1+3/k)(1+o(1))T$; the hops are $3/255$ of the span and the
selector is $O(k^2)$.  Taking $k=\lfloor\log T\rfloor$,
\[
  \frac12\Bigl(1+\frac3{255}\Bigr)T+\frac T2+o(T)=1.00588\ldots T+o(T).
\]
Three entries to a cell ties this and four lose: $m$ entries need $2^m$
values, the cheapest of which cost $2^{2m-2}$ characters in all, so the price
per entry is $(1+2^{m-2})/m$, equal to $1$ at $m=2,3$ and rising on both
sides.\qedhere
\end{proof}

\begin{corollary}[Leading constant, improved]\label{cor:chain}
For every $\theta$ admissible in Lemma~\ref{lem:short},
\[
  \limsup_{T\to\infty}\;\frac{\mathcal C_F(T)}{T\log T}
  \le\frac{1.006}{(1-\theta)\log10},
\]
which is $1.05$ at $\theta=\frac7{12}$ and $0.874$ on GRH.
\end{corollary}

\begin{proof}
Repeat the proof of Corollary~\ref{cor:leading} with Lemma~\ref{lem:pack}
in place of Lemma~\ref{lem:tree}, so that $C\le1.006\,T+o(T)$ and
$\log N\le C\log Q\le C(1-\theta)^{-1}\log T\,(1+o(1))$.
\end{proof}

The construction's walk is quadratic in $T$ where the tree is linear, so it
is a statement about $\mathcal C_F(T)$ and not a replacement generator; the
implementation keeps the tree, whose per-arity ceilings Section~\ref{sec:grh}
makes explicit.

Packing stops at one character an entry because a cell spells its value
alone.  Spelling a whole group of entries as one vector, with a budget on the
marks shared across its cells, does better, and it does as well as any
program that carries the table as tape data can
(Proposition~\ref{prop:drawing}).

\begin{lemma}[Enumerative lookup]\label{lem:draw}
Every $T$-bit truth table has a Brainfuck program of at most
\[
  \Bigl(\frac{1}{\log_2(1+\sqrt2)}+o(1)\Bigr)T=(0.7865+o(1))\,T
\]
characters.
\end{lemma}

\begin{proof}
Let $D(S,M)$ be the number of integer vectors $(v_1,\ldots,v_S)$ with
$\sum_i|v_i|\le M$, a Delannoy number: $D(S,M)=D(S-1,M)+D(S,M-1)+D(S-1,M-1)$
with $D(S,0)=D(0,M)=1$, and $D(n,n)=(3+2\sqrt2)^{n-o(n)}$ with
$D(n,n)/D(n-1,n-1)\to3+2\sqrt2$.  Fix $k$, a power of two, and let $n_k$ be
least with $D(n_k,n_k)\ge2^k$; then
$2n_k\log_2(1+\sqrt2)\le k+\log_2(3+2\sqrt2)+o(1)$, that is
$2n_k/k\le1/\log_2(1+\sqrt2)+O(1/k)$.  Put $S=M=n_k$.

Number the vectors position by position, the values at a position in the
order $0,1,-1,2,-2,\ldots$: the rank of a vector is the number of vectors
that precede it, and a value's contribution at position $i$ is the number of
completions of the shorter prefixes, which the recurrence supplies, so that
ranking and unranking are $O(SM)$ table lookups each.  A group of $k$
entries $t_{gk},\ldots,t_{gk+k-1}$ is the integer $b_g=\sum_{j<k}t_{gk+j}2^j$,
and it is laid out as $[W][c_1]\cdots[c_S]$: a walk cell and the vector of
rank $b_g$, a negative entry stored as $256-|v|$.  Drawing a group costs
$S+1$ moves and at most $M$ marks, so the table costs at most $(S+1+M)T/k$
characters.

The top $n-\log_2k$ bits select the group by the chain of
Lemma~\ref{lem:chain}, with the groups as its leaf level and stride $S+1$.
The last $\log_2k$ bits are read by a decoder entered on $W$, which computes
the rank of the vector to its right by the recurrence and prints the
selected bit of it; its workspace is the cells to the right of the group,
which belong to other groups and are not needed by this run.  For fixed
$S,M,k$ the decoder is one program; ours spells the $SM$ table entries as
byte pairs and runs fixed multi-byte routines over them, $O(SMk)$ characters.

What remains is the chain's own cost: the hop at level $j$ is $3B_{j-1}$
characters of runs, $3T/255$ over all levels, which is $\Theta(T)$.  Replace
each stride-long run by a scan.  After its anchor pair give every block above
the groups one rail cell per level, $z_1,\ldots,z_L$, where $L=O(\log T)$ is
the number of levels; the rail $z_\ell$ of a level-$\ell$ block is $1$
unless the block is the last among its siblings, and every other rail is
$0$.  Moving by one level-$1$ block is a run of $B_1=256(S+1)+L+2$
characters.  Moving left by one level-$\ell$ block, $\ell\ge2$, from its
$z_\ell$: step to the $z_{\ell-1}$ of its last sub-block, move left by one
level-$(\ell-1)$ block, repeat that move while the cell reached is nonzero,
then step to $z_\ell$.  The loop runs over the sub-blocks, whose
$z_{\ell-1}$ are $1$ except on the last one, which it never tests, and on
into the parent's left neighbour, a level-$\ell$ block whose $z_{\ell-1}$
is $0$; the moves nested inside that last crossing land on the neighbour's
lower rails, which are $0$ too, so each stops where it should.  The
rightward move mirrors this and stops on the last sub-block, whose
$z_{\ell-1}$ is $0$.  A level-$\ell$ move is thus two level-$(\ell-1)$
moves and $O(L)$ characters, $O(2^\ell B_1)$ in all, and the hops of every
level together cost $O(2^LB_1)=O(T^{1/8}\log T)$.

Count.  The groups: $(S+1+M)T/k$.  The blocks above them number
$O(T/(256k))$ and cost $L+3$ cells and at most one mark each,
$O(T\log T/k)$.  The decoder: $O(k^3)$.  Hops and chunk reads: $o(T)$.
With $k$ the largest power of two below $\log^2T$ everything but the groups
is $O(T/\log T)$, and $(S+1+M)/k=2n_k/k+1/k\le1/\log_2(1+\sqrt2)+O(1/k)$.
\end{proof}

At a fixed group size the best pair need not be square: $k=16$ takes
$(S,M)=(6,9)$, $D(6,9)=75\,517\ge2^{16}$, at $(S+1+M)/k=1.000$; $k=32$
takes $(12,16)$ at $0.906$ and $k=64$ takes $(25,28)$ at $0.844$.  The
check runs the layout exhaustively at radix $4$, so that four levels of
nested scans execute, and the rank decoder at $(6,9,16)$ with two-byte
arithmetic; the closed form gives $1.002$ characters an entry at $n=40$ and
radix $256$, the excess being the rails.  Lemma~\ref{lem:walk} below then
removes the factor $1/(1-\theta)$ from Corollary~\ref{cor:chain};
Corollary~\ref{cor:final} collects the result.

The constant $O(1)$ above contains $x_0$, so the corollary does not say at
which $T$ the ceiling takes hold.  For the arities that can be generated in
practice a computation replaces it; Section~\ref{sec:grh} covers the rest,
on GRH and without.  The ineffectivity is an artifact of the quotation, not
of the modulus.

\begin{remark}[Effectivity at a fixed modulus]\label{rem:effective}
Lemma~\ref{lem:short} carries an ineffective $x_0$ only because it is quoted
from a theorem uniform in $q$.  At the fixed modulus $11$ the one ineffective
ingredient of a Hoheisel argument is Siegel's lower bound for $L(1,\chi)$ at a
real character, and the only real character modulo $11$ is the Legendre
symbol, odd because $11\equiv3\pmod 4$.  Its field $\mathbb Q(\sqrt{-11})$ has
class number $1$ and two units, so the class-number formula gives
\[
  L(1,\chi)=\frac{2\pi h}{w\sqrt{11}}=\frac{\pi}{\sqrt{11}}=0.94722\ldots,
\]
which excludes an exceptional zero outright.  So $x_0$ is effective in
principle at this modulus.  Lemma~\ref{lem:uncond} assembles a value from
the literature; under GRH a far smaller one is available.
\end{remark}

\begin{lemma}[Computed class gaps]\label{lem:computed}
Put $c=8.62$ and $X=10^{11}-10^4$.  For every real $0\le x\le X$ and every
$a\in\{1,\ldots,8\}$ there is a prime
\[
  p\equiv a\pmod{11},
  \qquad x<p\le x+c\log^2\max(x,37).
\]
\end{lemma}

\begin{proof}
A segmented sieve through $10^{11}$ records, for each class, every pair of
consecutive primes $q<p$ of the class.  On $q\le x<p$ the ratio
$(p-x)/\log^2\max(x,37)$ is nonincreasing, so its supremum is the value at
$x=q$; the largest such value is $8.6184$, attained by the class-$2$ pair
$4{,}160{,}719<4{,}162{,}721$.  Before a class's first prime, which is at
most $37$, the gap is at most $37<c\log^237$.  Every class has a prime in
$(X,10^{11}]$, so each $x\le X$ has its next class prime inside the sieved
range.
\end{proof}

\begin{proposition}[Computed ceiling]\label{prop:computed}
Let a table's program have $C$ instructions, and let $y\ge37$ satisfy
$37+(C-1)c\log^2y\le y\le X$.  Then $Q\le y$ and
\[
  D\le\lfloor C\log_{10}y\rfloor+1.
\]
\end{proposition}

\begin{proof}
The first selected prime is at most $37$.  By induction on $i\le m$,
$p_i\le37+(i-1)c\log^2y$: this is at most $y\le X$, so
Lemma~\ref{lem:computed} applies at $x=p_i$ and gives
$p_{i+1}\le p_i+c\log^2y$.  Hence $Q\le37+(m-1)c\log^2y\le y$ because
$m\le C$.  Finally $\log N\le C\log Q$.
\end{proof}

With $C\le\frac{35}{2}T+55n+25$ the least admissible $y$ is below $X$ for
every $n\le19$.  At $n=13$, for instance, $y=498{,}168{,}370$ and
$D\le1{,}253{,}292$, so $D/(T\log T)\le16.98$ over all $2^{8192}$ tables;
parity, which attains the tree bound, measures $966{,}568$ digits, or
$13.09$.  The ceiling falls to $14.19$ at $n=19$.  In this range each step
of the walk is polylogarithmic rather than a power of $p_i$, so the ceiling
tends towards $\frac{35}{2}/\log10\approx7.60$ rather than
Corollary~\ref{cor:leading}'s $18.25$, but slowly: $\log_{10}y$ exceeds
$\log_{10}C$ by $\log_{10}(c\log^2y)$.

\section{Effective thresholds}\label{sec:grh}

Lemma~\ref{lem:computed} stops at $10^{11}$, so Proposition~\ref{prop:computed}
stops at $n=19$.  The generalized Riemann hypothesis carries the walk the rest
of the way with constants that are still explicit, because the one
short-interval theorem for progressions that is explicit on GRH has, at
$q=11$, a threshold five orders of magnitude \emph{below} the sieved range.
The two therefore overlap, and no $x$ is left uncovered.

\begin{lemma}[Explicit short intervals on GRH]\label{lem:grh}
Assume GRH for $\zeta$ and for the Dirichlet $L$-functions of the characters
modulo $11$, and put
\[
  h(t)=10\bigl(\tfrac12\log t+\log11+12\bigr)\sqrt t .
\]
Then for every $a\in\{1,\ldots,8\}$ and every $x\ge10^{11}$ there is a prime
\[
  p\equiv a\pmod{11},\qquad x<p\le x+2h(2x).
\]
\end{lemma}

\begin{proof}
Dudek, Greni\'e and Molteni~\cite[Thm.~1.1]{dgm} prove on GRH that for
$q\ge3$, $(a,q)=1$, and the row $(\alpha,\delta,\rho,m)=(\frac12,1,12,23)$ of
their Table~1, every
\[
  h\ge\varphi(q)\bigl(\alpha\log x+\delta\log q+\rho\bigr)\sqrt x,
  \qquad x\ge(m\varphi(q)\log q)^2
\]
admits a prime $p\equiv a\pmod q$ with $|p-x|<h$.  At $q=11$ we have
$\varphi(q)=10$, the displayed $h$ is theirs, and the threshold is
$(230\log11)^2<3.05\cdot10^5$.

The quantity $h(2x)/x=10\sqrt2\bigl(\frac12\log2x+\log11+12\bigr)/\sqrt x$
decreases for $x\ge e^2$ and equals $1.23\cdot10^{-3}$ at $x=10^{11}$, so
$h(2x)\le x$ throughout $x\ge10^{11}$.  Put $c=x+h(2x)$, so that
$x\le c\le2x$.  Then $h(c)\le h(2x)$ because $h$ increases, whence
$c-h(c)\ge x$.  Applying the quoted theorem at $c\ge x\ge3.05\cdot10^5$ gives
a prime $p\equiv a\pmod{11}$ with $|p-c|<h(c)$, and therefore
\[
  x\le c-h(c)<p<c+h(c)\le x+2h(2x).\qedhere
\]
\end{proof}

\begin{proposition}[Effective ceiling on GRH]\label{prop:grh}
Assume the hypothesis of Lemma~\ref{lem:grh} and let a table's program have
$C$ instructions.  With $c=8.62$ and $X=10^{11}-10^4$ as in
Lemma~\ref{lem:computed}, put
\[
  K=\Bigl\lfloor\frac{X-37}{c\log^2X}\Bigr\rfloor=18\,083\,227 .
\]
For $C\le K$ use Proposition~\ref{prop:computed}.  Otherwise let
$U\ge\sqrt{10^{11}}$ satisfy
\[
  \sqrt{10^{11}}+(C-K)\bigl(10\sqrt2\log U+\beta\bigr)\le U,
  \qquad
  \beta=10\sqrt2\bigl(\tfrac12\log2+\log11+12\bigr)=208.52\ldots
\]
Then $Q\le U^2$ and $D\le\lfloor2C\log_{10}U\rfloor+1$.
\end{proposition}

\begin{proof}
Let $p_1<\cdots<p_m$ be the selected primes, $m\le C$.  The induction of
Proposition~\ref{prop:computed} gives $p_i\le37+(i-1)c\log^2X$ for as long as
the right side stays at or below $X$, which by the definition of $K$ covers
$i\le K$; so $p_K\le X<10^{11}$.

Put $B_0=10^{11}$ and $B_{j+1}=B_j+2h(2B_j)$.  If $p\le B_j$ then the least
prime of any reduced class exceeding $p$ is at most $B_{j+1}$: apply
Lemma~\ref{lem:grh} at $x=\max(p,10^{11})\le B_j$, which yields a class prime
in $(x,x+2h(2x)]\subseteq(p,B_{j+1}]$.  Hence $p_{K+j}\le B_j$ for every
$j\ge0$ by induction, the base being $p_K\le B_0$.

Write $u_j=\sqrt{B_j}$.  From $\sqrt{a+b}\le\sqrt a+b/(2\sqrt a)$ and
$\tfrac12\log B_j=\log u_j$,
\[
  u_{j+1}\le u_j+\frac{h(2B_j)}{\sqrt{B_j}}
         = u_j+10\sqrt2\log u_j+\beta .
\]
So if $u_j\le U$ then $u_{j+1}\le u_j+10\sqrt2\log U+\beta$, and induction
gives $u_j\le\sqrt{10^{11}}+j(10\sqrt2\log U+\beta)\le U$ for every
$j\le C-K$.  Since $m-K\le C-K$, we get $Q=p_m\le B_{m-K}\le U^2$, and
$\log N\le C\log Q\le2C\log U$.
\end{proof}

\begin{corollary}\label{cor:grh}
On the same hypothesis the generated sources satisfy
$D\le24.6\,T\log T$ for every $n\ge8$, and
\[
  \limsup_{T\to\infty}\;\max_{t\in\{0,1\}^T}\frac{D(t)}{T\log T}
  \le\frac{35}{\log10}<15.21 .
\]
\end{corollary}

\begin{proof}
The fixed point of Proposition~\ref{prop:grh} has
$U=(C-K)(10\sqrt2\log U+\beta)(1+o(1))$, so $\log U=\log C+O(\log\log C)$ and
$D\le2C\log_{10}U$ gives, with $C\le\frac{35}{2}T+55n+25$ and
$\log C=\log T+O(1)$, the stated limit superior; $\frac{35}{2}\cdot2=35$.
The uniform bound is the larger of the two rules' maxima over $n\ge8$: the
computed ceiling peaks at $24.56$ at $n=8$, and the GRH ceiling, which takes
over at $n=20$, peaks at $24.06$ at $n=22$ and decreases from there.
\end{proof}

Because $K$ runs are spent before Lemma~\ref{lem:grh} is invoked at all, the
GRH ceiling is weaker than the computed one wherever the latter applies, and
the crossover is exactly the sieve's edge:

\begin{center}
\begin{tabular}{r|cccc|cccccc}
$n$ & 13 & 16 & 19 & 20 & 22 & 25 & 30 & 60 & $10^3$ & $10^6$\\ \hline
$D/(T\log T)$ & 16.98 & 15.31 & 14.19 & 20.46 & 24.06 & 23.27 & 22.01 & 18.75
& 15.47 & 15.20
\end{tabular}
\end{center}

\noindent
The first three columns are Lemma~\ref{lem:computed}'s; the rest are
Proposition~\ref{prop:grh}'s.  The approach to $35/\log10$ is slow because
$\log U$ exceeds $\log C$ by $\log(10\sqrt2\log U+\beta)$.  GRH also improves
Corollary~\ref{cor:leading}'s leading constant, $18.25$ falling to $15.21$,
since a square-root gap bound is the case $\theta=\frac12$ of
Lemma~\ref{lem:short} and $\frac{35}{2(1-\theta)}=35$.

\subsection*{The walk pays one logarithm a run}

Corollaries~\ref{cor:leading} and~\ref{cor:grh} charge the walk
$\log Q=2\log U$ a run on GRH, twice what a prime walked past every $\log p$
would cost, because the short-interval theorem is applied at every step at
its worst case.  The walk does not meet the worst case at every step: it
crosses each gap between consecutive class primes at most once, so what it
advances in $m$ steps is at most $m$ typical gaps plus the total length of
the atypical ones, and a second moment makes that total $o(x)$.

\begin{lemma}[Almost all short intervals in progressions]\label{lem:almost}
Call an integer $x$ bad for the class $a$ and the length $h$ if $(x,x+h]$
contains no prime $p\equiv a\pmod{11}$.
\begin{enumerate}
\item[(i)] Assume GRH for the $L$-functions modulo $11$.  With
$h(X)=\lceil\log^3(2X)\rceil$, the integers of $[X,2X)$ bad for some class
$a\in\{1,\ldots,8\}$ and the length $h(X)$ number $O(X/\log X)$.
\item[(ii)] Unconditionally, for each $\varepsilon>0$ and
$h(X)=\lceil121\,(2X)^{1/15+\varepsilon}\rceil$ they number
$O_\varepsilon(X/\log X)$, with an ineffective constant.
\end{enumerate}
\end{lemma}

\begin{proof}
(i) Prachar's generalization of Selberg's theorem~\cite{prachar}, in the form
of Harm~\cite[Cor.~2.10]{harm}: on GRH, for $h'\in[q\log^{2+\varepsilon}(qX),X]$,
\[
  \sum_{a\bmod q}^{\ast}\int_X^{2X}\bigl|\Delta\pi(u,h',q,a)\bigr|^2\,du\ll h'X,
  \qquad
  \Delta\pi(u,h',q,a)=\sum_{\substack{u-h'<p\le u\\ p\equiv a\ (q)}}1
  -\frac1{\varphi(q)}\int_{u-h'}^{u}\frac{dt}{\log t},
\]
the sum over the reduced classes.  Take $q=11$ and $h'=h(X)-1$, which lies in
the range for large $X$.  If $x\in[X,2X)$ is bad for $a$ and $h(X)$, then
for every $u\in[x+h(X)-1,\,x+h(X))$ the window $(u-h',u]$ lies inside
$(x,x+h(X)]$ and holds no class prime, so
$|\Delta\pi(u,h',11,a)|\ge h'/(10\log3X)$ for large $X$.  Hence the bad
integers of $[X,2X)$ number at most
\[
  \frac{100\log^2(3X)}{h'^{\,2}}
  \Bigl(\int_X^{2X}+\int_{2X}^{4X}\Bigr)|\Delta\pi(u,h',11,a)|^2\,du
  \ll\frac{X\log^2X}{h'}\ll\frac{X}{\log X}.
\]

(ii) Koukoulopoulos~\cite[Thm.~1.3]{kouk}: fix $\varepsilon$; for $x\ge h\ge2$
and $1\le Q^2\le h/x^{1/15+\varepsilon}$ there is $c=c(\varepsilon)>0$ such
that, for every $A>0$, the pairs $(q,n)$ with $q\le Q$, $n\le x$ and
$\sum_{n<p\le n+h,\ p\equiv a\ (q)}\log p\ge ch/\varphi(q)$ for every $a$
coprime to $q$ number $Qx+O(Qx/\log^Ax)$.  With $Q=11$, $x=2X$ and $h=h(X)$
the hypothesis $121\le h/(2X)^{1/15+\varepsilon}$ holds, so the integers
$n\le2X$ at which the modulus $11$ fails, among them every bad integer of
$[X,2X)$, number $O(X/\log X)$.
\end{proof}

\begin{lemma}[One logarithm a run]\label{lem:walk}
Let $p_1<\cdots<p_m$ be the primes the encoder selects for a program of $m$
runs, whatever the runs' classes.  Then
\[
  p_m\le m\log^4m\ \text{ on GRH}\qquad\text{and}\qquad
  p_m\le m^{15/14+\varepsilon}\ \text{ unconditionally}
\]
for $m\ge m_0$, respectively $m\ge m_0(\varepsilon)$, the latter
ineffective, uniformly in the program.  Hence $\log Q\le(1+o(1))\log m$ on
GRH and $\log Q\le(\tfrac{15}{14}+o(1))\log m$ unconditionally.
\end{lemma}

\begin{proof}
Extend $h$ of Lemma~\ref{lem:almost} to all integers by $h(x)=h(X)$ for
$x\in[X,2X)$, $X$ a power of two; it is nondecreasing.  The encoder makes
$p_{i+1}$ the least prime of the class $a$ of the next run exceeding $p_i$,
so every integer $x$ with $p_i\le x$ and $x+h(x)<p_{i+1}$ is bad for $a$;
the exceptions in $[p_i,p_{i+1})$ satisfy $x\ge p_{i+1}-h(p_{i+1})$, so
\[
  p_{i+1}-p_i\le h(p_m)+1+\#\{x\in[p_i,p_{i+1}):x\text{ bad for }a\}.
\]
Summing over $i$ and over the eight classes,
$p_m-p_1\le m\,(h(p_m)+1)+\sum_a\#\{x<p_m:x\text{ bad for }a\}$, and by
Lemma~\ref{lem:almost} over the dyadic ranges below $p_m$ the last sum is
$O(p_m/\log p_m)$.  So $p_m\le3m\,h(p_m)$ once $m$ is large, the threshold
independent of the classes.  On GRH $h(p_m)\le\log^3(4p_m)+1$, so
$\log p_m\le\log m+3\log\log p_m+O(1)$, whence
$\log p_m\le\log m+3\log\log m+O(1)$ and $p_m\le m\log^4m$ for large $m$.
Unconditionally $h(p_m)\le121(4p_m)^{1/15+\varepsilon}+1$, so
$p_m^{14/15-\varepsilon}\le c\,m$ and $p_m\le m^{15/14+3\varepsilon}$ for
large $m$.  Below the threshold $Q$ is bounded by a constant.
\end{proof}

\begin{corollary}[Leading constant, final]\label{cor:final}
\[
  \limsup_{T\to\infty}\frac{\mathcal C_F(T)}{T\log T}
  \le\frac{1}{\log_2(1+\sqrt2)\,\log10}=0.34155\ldots\ \text{ on GRH},
\]
and unconditionally
\[
  \limsup_{T\to\infty}\frac{\mathcal C_F(T)}{T\log T}
  \le\frac{15}{14}\cdot\frac{1}{\log_2(1+\sqrt2)\,\log10}=0.36595\ldots
\]
\end{corollary}

\begin{proof}
The program of Lemma~\ref{lem:draw} has $C\le(1/\log_2(1+\sqrt2)+o(1))T$
characters and $m\le C$ runs, so by Lemma~\ref{lem:walk}
$\log N\le C\log Q\le(1+o(1))\,C\log T$ on GRH and
$(\tfrac{15}{14}+o(1))\,C\log T$ unconditionally; divide by $\log10$.
\end{proof}

The same lemma halves the earlier limits: the tree's is
$\frac{35}{2\log10}<7.61$ on GRH and Lemma~\ref{lem:pack}'s is $0.437$.  It
says nothing about thresholds; the per-arity ceilings of
Proposition~\ref{prop:grh} stand as the explicit statement.

Without GRH the ingredients are also in print, and they assemble into an
explicit threshold, though a far weaker one: the smoothed explicit formula
of Dudek, Greni\'e and Molteni is unconditional, Thorner and Zaman's explicit
log-free density estimate controls the zeros near $\sigma=1$, Kadiri's
zero-free regions cut them off, and an explicit zero count handles the rest.
Let $\mathcal Z$ be the multiset of nontrivial zeros $\rho=\beta+i\gamma$ of
$\zeta$ and of the nine $L(s,\chi)$ with $\chi$ nonprincipal modulo $11$,
all primitive since $11$ is prime, and let $N_{11}(t)$ count those with
$|\gamma|\le t$.

\begin{lemma}[Zeros of the ten $L$-functions]\label{lem:zeros}
For $t\ge e$,
$N_{11}(t)\le\frac{10t}{\pi}\log\frac{11t}{2\pi e}+3\log(11t)+81$.
Every $\rho\in\mathcal Z$ with $|\gamma|\le t$ has
$\beta\le1-1/(5.70\log(11t))$.  For $Q\ge11$ and $\sigma\ge\frac{39}{40}$,
at most $10^{88}(10^{421}Q^{99})^{1-\sigma}$ elements of $\mathcal Z$ have
$\beta>\sigma$ and $|\gamma|\le Q$.
\end{lemma}

\begin{proof}
Bennett, Martin, O'Bryant and Rechnitzer~\cite[Cor.~1.2]{bmor-count} give,
for a character of conductor $q>1$ and $t\ge5/7$, at most
$\frac t\pi\log\frac{qt}{2\pi e}+0.247\log(qt)+6.894$ zeros with
$|\gamma|\le t$; Hasanalizade, Shen and Wong~\cite[Cor.~1.2]{hsw} give, for
$t\ge e$, at most
$\frac t{2\pi}\log\frac t{2\pi e}+0.1038\log t+0.2573\log\log t+9.3675$
zeros of $\zeta$ with $0<\gamma\le t$, and the zeros of $\zeta$ come in
conjugate pairs.  Nine of the first and twice the second sum to at most the
stated bound, since $\log\log t\le\log t\le\log(11t)$ and
$2.946\log(11t)+80.79\le3\log(11t)+81$.

Kadiri~\cite[Thm.~1.1]{kadiri} proves $L(s,\chi)\ne0$ for
$\Re s\ge1-1/(5.60\log(q\max(1,|\Im s|)))$ when $\chi$ is a nonprincipal
primitive character modulo $3\le q\le400000$, with no exceptional zero,
and~\cite{kadiri-zeta} $\zeta(s)\ne0$ for $\Re s\ge1-1/(5.70\log|\Im s|)$,
$|\Im s|\ge2$; $\zeta$ has no zero with $|\gamma|<14$.  Both regions
contain $\Re s\ge1-1/(5.70\log(11t))$ on $|\Im s|\le t$.

Thorner and Zaman~\cite[Thm.~1.2]{tz-density} bound by
$10^{88}(10^{421}Q^{99})^{1-\sigma}$, for $Q\ge3$ and
$\sigma\ge\frac{39}{40}$, the number of zeros with $\beta>\sigma$ and
$|\gamma|\le Q$ of all primitive Dirichlet $L$-functions of modulus at most
$Q$; ours have moduli $1$ and $11$.
\end{proof}

\begin{lemma}[Unconditional explicit short intervals]\label{lem:uncond}
Put $A_0=2\bigl(99+5.70\log(4\cdot10^{88})\bigr)=2523.75\ldots$.  Let
$A>A_0$ and let $x$ satisfy
\begin{equation}\label{eq:uncond}
  \Bigl(1-\frac{A_0}{A}\Bigr)\log x\ge1262\log\log x+3758,
  \qquad
  \log x\ge\frac A5 .
\end{equation}
Then for every reduced residue $a$ modulo $11$ there is a prime
$p\equiv a\pmod{11}$ with $|p-x|<x^{1-1/A}$.
\end{lemma}

\begin{proof}
Put $h=x^{1-1/A}$, $X=x+h$, $T=x^{2/A}\log x$, $\eta=1/(5.70\log(11T))$,
$c=10^{88}$, $B=10^{421}T^{99}$ and $K(u)=\max(h-|u|,0)$.  The second
condition gives $h\le e^{-1/5}x\le\frac56x$, so $X\le2x$ and $x-h\ge x/6$;
the first, with $A>A_0$, forces $\log x\ge1262\log\log x+3758$, so
$\log x>15900$.

For $\chi$ modulo $11$ let
$\psi^{(1)}_\chi(y)=\sum_{n\le y}\chi(n)\Lambda(n)(y-n)$ and
$\Delta f(x)=f(x+h)-2f(x)+f(x-h)$.  Orthogonality gives
\[
  \sum_{n\equiv a\ (11)}\Lambda(n)K(x-n)
  =\frac1{10}\sum_\chi\bar\chi(a)\,\Delta\psi^{(1)}_\chi(x),
\]
and Lemmas 3.1 and 3.2 of Dudek, Greni\'e and Molteni~\cite{dgm}, which
assume only $x\ge100$ and $h\le\frac56x$, evaluate the right side as
\[
  \frac{h^2}{10}+\vartheta\Bigl[\frac1{10}\sum_\chi\Bigl|\Delta
  \sum_{\rho\in\mathcal Z_\chi}\frac{x^{\rho+1}}{\rho(\rho+1)}\Bigr|
  +1.36\,\frac{h^2}x+\frac{6h^2}{x(x-1)}+h\log2x\Bigr],
  \qquad|\vartheta|\le1,
\]
where $\mathcal Z_\chi$ is the zero set of the primitive character inducing
$\chi$, so of $\zeta$ for the principal one; the last term is their
Lemma~3.1 with $\omega(11)=1$, and $1.36$ bounds their
$1.7\,|\delta_{\pm1}(a)-\frac2{10}|$.

For $f(y)=y^{\rho+1}/(\rho(\rho+1))$ we have $f''(y)=y^{\rho-1}$ and
$\Delta f(x)=\int_0^h(h-u)\bigl(f''(x+u)+f''(x-u)\bigr)\,du$, so
$|\Delta f(x)|\le h^2X^{\beta-1}$; also
$|\Delta f(x)|\le4X^{\beta+1}/|\rho(\rho+1)|\le4X^2/\gamma^2$.  Using the
first bound for $|\gamma|\le T$ and the second beyond,
\[
  \sum_\chi\Bigl|\Delta\sum_{\rho\in\mathcal Z_\chi}
  \frac{x^{\rho+1}}{\rho(\rho+1)}\Bigr|
  \le h^2\sum_{\substack{\rho\in\mathcal Z\\|\gamma|\le T}}X^{\beta-1}
  +4X^2\sum_{\substack{\rho\in\mathcal Z\\|\gamma|>T}}\gamma^{-2}.
\]
Partial summation against Lemma~\ref{lem:zeros} bounds the tail by
$2\int_T^\infty N_{11}(t)t^{-3}\,dt
\le\frac{20}\pi\frac{\log(11T/2\pi)}T+\frac{3\log(11T)+82.5}{T^2}$.
For the near sum let $N(\sigma)$ count the $\rho\in\mathcal Z$ with
$\beta>\sigma$ and $|\gamma|\le T$; by Lemma~\ref{lem:zeros} at $Q=T\ge11$
it vanishes for $\sigma\ge1-\eta$ and is at most $cB^{1-\sigma}$ for
$\sigma\ge\frac{39}{40}$.  The zeros with $\beta\le\frac{39}{40}$
contribute at most $N_{11}(T)X^{-1/40}$, and partial summation over
$\sigma\in(\frac{39}{40},1]$ gives for the rest
\begin{multline*}
  X^{-1/40}N(\tfrac{39}{40})
  +\log X\int_{39/40}^{1-\eta}N(\sigma)X^{\sigma-1}\,d\sigma\\
  \le N_{11}(T)X^{-1/40}+c\log X\int_\eta^{\infty}\Bigl(\frac BX\Bigr)^u du
  \le N_{11}(T)X^{-1/40}+2c\Bigl(\frac BX\Bigr)^\eta,
\end{multline*}
the last step because \eqref{eq:uncond} gives $X\ge B^2$, so
$\log X\le2\log(X/B)$.

Prime powers $p^k$, $k\ge2$, in $(x-h,x+h)$ carry weight at most $h$ and
$\Lambda(p^k)\le\frac12\log X$; for each $k$ the primes $p$ lie in an
interval of length at most $2h/(k(x-h)^{1-1/k})$, so there are at most
$h/\sqrt{x-h}+\log_2X\,\bigl(1+2h/(3(x-h)^{2/3})\bigr)$ of them.  Removing
them, a prime $p\equiv a\pmod{11}$ with $|p-x|<h$ exists as soon as
\begin{multline*}
  2N_{11}(T)X^{-1/40}+2c\Bigl(\frac BX\Bigr)^\eta
  +\frac{4X^2}{h^2}\Bigl(\frac{20}\pi\frac{\log(11T/2\pi)}T
  +\frac{3\log(11T)+82.5}{T^2}\Bigr)\\
  +\frac{13.6}x+\frac{60}{x(x-1)}+\frac{10\log2x}h
  +5\log X\Bigl(\frac1{\sqrt{x-h}}+\log_2X\Bigl(\frac1h
  +\frac2{3(x-h)^{2/3}}\Bigr)\Bigr)<1 .
\end{multline*}
The second term is at most $\frac12$ when $(x/B)^\eta\ge4c$, that is,
$\log x-421\log10-99\log T\ge5.70\log(4c)\log(11T)$; with
$\log T=\frac2A\log x+\log\log x$ this is
$(1-A_0/A)\log x\ge1261.9\log\log x+3757.9$, which is the first
condition of \eqref{eq:uncond}, and it implies $X\ge B^2$.  In the third
term $4X^2/h^2\le4(1+x^{-1/A})^2x^{2/A}$ and $x^{2/A}/T=1/\log x$, so it is
at most
$4(1+x^{-1/A})^2\bigl(\frac{20}\pi\frac{0.57+\frac2A\log x+\log\log x}{\log x}
+\frac{3\log(11T)+82.5}{x^{2/A}\log^2x}\bigr)<0.13$, since
$x^{-1/A}\le e^{-1/5}$, $\frac2A<\frac1{1261}$, $\log x>15900$ and
$x^{2/A}\ge e^{2/5}$.  The first
term is $\exp\bigl(-\log x(\frac1{40}-\frac2A)+O(\log\log x)\bigr)<10^{-100}$,
and the remaining terms are smaller still.
\end{proof}

\begin{proposition}[Unconditional ceiling]\label{prop:uncond}
Let $A>A_0$ and let $x_0$ satisfy \eqref{eq:uncond}.  A program with $C$
instructions has $Q\le\bigl((2x_0)^{1/A}+4C/A\bigr)^A$ and
\[
  D\le\Bigl\lfloor CA\log_{10}\Bigl((2x_0)^{1/A}+\frac{4C}A\Bigr)\Bigr\rfloor+1 .
\]
\end{proposition}

\begin{proof}
Put $\theta=1-1/A$ and $r=1/A$.  Given $y\ge x_0$, apply
Lemma~\ref{lem:uncond} at $x=y+(2y)^\theta\le2y$: the prime found satisfies
$p>x-x^\theta\ge y$ and $p<x+x^\theta\le y+2(2y)^\theta<y+4y^\theta$.  So
every $y\ge x_0$ has a prime of each class in $(y,y+4y^\theta)$.  If no
selected prime exceeds $x_0$ then $Q\le x_0$.  Otherwise let $p_{i_0}$ be
the first that does; it is the least prime of its class above
$p_{i_0-1}<x_0$, hence $p_{i_0}<x_0+4x_0^\theta\le2x_0$, and for $i\ge i_0$
the bound $p_{i+1}\le p_i+4p_i^\theta$ gives
$p_{i+1}^r-p_i^r\le rp_i^{r-1}\cdot4p_i^\theta=4r$ by concavity.  Thus
$Q^r\le(2x_0)^r+4r(m-i_0)\le(2x_0)^r+4rC$, and $\log N\le C\log Q$.
\end{proof}

\begin{corollary}\label{cor:uncond}
Unconditionally, $D\le3.05\cdot10^4\,T\log T$ for every $n\ge8$, and
\[
  \limsup_{T\to\infty}\;\max_{t\in\{0,1\}^T}\frac{D(t)}{T\log T}
  \le\frac{35A_0}{2\log10}<19181 .
\]
\end{corollary}

\begin{proof}
For $n\le19$ the computed ceiling is at most $24.56$.  For $n\ge20$ take
$A=4000$, for which the least $\log x_0$ admitted by \eqref{eq:uncond} is
$46967$, so $(2x_0)^{1/A}<1.26\cdot10^5<T/4$, while
$4C/A\le0.0175\,T+0.0011\,T$; hence
$\log_{10}\bigl((2x_0)^{1/A}+4C/A\bigr)\le\log_{10}T-0.301$, and with
$C\le\frac{35}2T+55n+25$ and $(55n+25)/(\frac{35}2T)\le1/(2n)$ this gives
$D\le\frac{35}2\cdot4000\,T\log_{10}T+1$, which is the uniform bound.  For
the limit superior fix any $A>A_0$: $\log Q\le A\log(4C/A)+o(1)$, so
$D/(T\log T)\le\frac{35}2A/\log10+o(1)$, and $A\to A_0$.
\end{proof}

The threshold is astronomical, $x_0>e^{15900}$ at every $A$, and the
constant is three orders of magnitude above GRH's, so the practical
statement stays with Proposition~\ref{prop:grh}; what
Lemma~\ref{lem:uncond} settles is that Lemma~\ref{lem:short}'s $x_0$ and
$\theta$ have values.  Per arity, with the $A$ that minimizes
Proposition~\ref{prop:uncond} at the least admissible $x_0$:

\begin{center}
\begin{tabular}{r|ccccccc}
$n$ & 20 & 22 & 25 & 30 & 60 & $10^3$ & $10^6$\\ \hline
$D/(T\log T)$ & 24\,500 & 24\,050 & 23\,480 & 22\,800 & 21\,060 & 19\,330
& 19\,200\\
$A$ & 4339 & 4170 & 3879 & 3638 & 3035 & 2556 & 2525
\end{tabular}
\end{center}

\noindent
Nine tenths of $A_0$ is Thorner and Zaman's $10^{88}$ passed through
Kadiri's $5.70$, and the leading $2$ is the Fej\'er kernel, whose
$\gamma^{-2}$ decay makes the tail cost $T\approx x^{2/A}$ rather than
$x^{1/A}$: a sharper cutoff would halve $A_0$, and a Vinogradov--Korobov
region, explicit for Dirichlet $L$-functions since Khale~\cite{khale},
would let $A$ approach $2\cdot99$, a limit superior below $1505$, at a
larger threshold still.

\section{Language lower bound}

A language lower bound must count every integer that might encode a table.

\begin{lemma}[Run bound]\label{lem:runs}
If a Factor integer satisfies $\log N\le L$ and has $k$ useful prime factors,
then
\[
  k=O(L/\log(L+2)).
\]
\end{lemma}

\begin{proof}
The $i$th useful prime is at least $i+1$, and every useful exponent is at
least one.  Hence
\[
  L\ge\sum_{i=1}^{k}\log(i+1)=\log((k+1)!).
\]
Since $\log((k+1)!)\ge(k+1)\bigl(\log(k+1)-1\bigr)$, this gives
$k=O(L/\log(L+2))$.
\end{proof}

\begin{lemma}[Exponent vectors]\label{lem:vectors}
Fix $k$ and $L\ge2$.  The number of vectors
$(e_1,\ldots,e_k)\in\N_{>0}^k$ satisfying
\begin{equation}\label{eq:budget}
  \sum_{i=1}^{k}e_i\log(i+1)\le L
\end{equation}
is $\exp(O(L/\log L))$, uniformly for
$k=O(L/\log L)$.
\end{lemma}

\begin{proof}
Put $f_i=e_i-1\ge0$ and $s=1/\log(L+2)$.  Dropping the fixed contribution
of the ones only enlarges the set.  Markov's exponential bound and the
geometric series give
\begin{align}
 \#\Bigl\{f\in\N_{\ge0}^k:\sum_if_i\log(i+1)\le L\Bigr\}
 &\le e^{sL}
       \sum_{f_1,\ldots,f_k\ge0}
       \exp\!\left(-s\sum_i f_i\log(i+1)\right)\\
 &=e^{sL}\prod_{i=1}^{k}
       \left(1-(i+1)^{-s}\right)^{-1}.
\end{align}
The first factor has logarithm $L/\log(L+2)$.  To bound the product, split
at $i=\lfloor\sqrt L\rfloor$.  For $i$ below the split,
\[
 -\log\left(1-(i+1)^{-s}\right)=O(\log\log(L+2)),
\]
so these factors contribute
$O(\sqrt L\log\log(L+2))=O(L/\log L)$.  Above the split,
$(i+1)^{-s}\le\exp(-1/3)$ for all sufficiently large $L$, so each logarithm
is $O(1)$.  Lemma~\ref{lem:runs} bounds their number by $O(L/\log L)$.
Taking logarithms proves the claim; bounded $L$ is absorbed in the constant.
\end{proof}

\begin{proposition}[Behavior count]\label{prop:count}
Factor sources whose digit integers satisfy $\log N\le L$ realize at most
\[
  \exp(O(L/\log L))
\]
distinct behaviors.
\end{proposition}

\begin{proof}
Discard ignored-residue prime factors: they do not alter the decoded
Brainfuck program.  For $k$ useful primes, their increasing order fixes the
instruction order once their residue classes are chosen.  There are at most
$8^k$ class words.  Replacing the actual $i$th prime by its lower bound
$i+1$ relaxes the size constraint to \eqref{eq:budget}, so
Lemma~\ref{lem:vectors} bounds the run lengths.  Finally sum over the
$O(L/\log L)$ possible values of $k$.  The factors $8^k$ and the number of
summands are both absorbed by $\exp(O(L/\log L))$.
\end{proof}

\begin{proposition}[Lower bound]\label{prop:lower}
For all sufficiently large $T$, some $T$-bit truth table requires
$\Omega(T\log T)$ Factor digits.
\end{proposition}

\begin{proof}
Every nonzero digit integer spelled with at most $D$ digits has
$\log N=O(D)$, so Proposition~\ref{prop:count} bounds the number of its
behaviors by
\[
  \exp(O(D/\log D)).
\]
Zero-valued sources add only the empty behavior, which is absorbed by this
bound.
There are $2^T$ Boolean truth tables.  If every table had a source of at most $D$ digits,
then $D/\log D=\Omega(T)$, which implies $D=\Omega(T\log T)$.
Ignored factors, comments, and leading zeros cannot invalidate the count:
they add spellings of an already-counted decoded program, not behaviors.
\end{proof}

Propositions~\ref{prop:upper} and~\ref{prop:lower} prove
Theorem~\ref{thm:main}.

Proposition~\ref{prop:lower} leaves its constant inside the $\Omega$.  What
hides it is the Markov parameter of Lemma~\ref{lem:vectors}, chosen there
only to make the exponent $O(L/\log L)$; placing it at the saddle instead
makes the constant explicit, and it is $\log8$ --- one instruction letter per
unit of run length.  We state the count with the instruction primes
themselves, writing $q_i$ for the $i$th prime whose residue modulo $11$ lies
in $\{1,\ldots,8\}$, so that $q_1,q_2,\ldots=2,3,5,7,13,\ldots$ and, by the
prime number theorem for progressions, $q_i=\frac54 i\log i\,(1+o(1))$.  The
crude bound $p_i\ge i+1$ of Lemma~\ref{lem:runs} yields the same constant,
since $\log(i+1)$ and $\log q_i$ agree to leading order; it only approaches
it more slowly.

\begin{lemma}[Refined behavior count]\label{lem:count8}
Factor sources whose digit integers satisfy $\log N\le L$ realize at most
$\exp\bigl((\log8+o(1))L/\log L\bigr)$ distinct behaviors.
\end{lemma}

\begin{proof}
Discard the ignored-residue factors; they do not alter the decoded program.
A behavior is determined by that program, a string over the eight instruction
letters, whose maximal runs we write $a_1^{e_1}\cdots a_k^{e_k}$ with
$a_i\ne a_{i+1}$.  The primes carrying the runs increase and are useful, so
the $i$th is at least $q_i$ and
\begin{equation}\label{eq:qbudget}
  L\;\ge\;\sum_{i=1}^{k}e_i\log q_i .
\end{equation}
There are at most $8\cdot7^{k-1}$ class words, and $k\le K$, where $K$ is
the largest index with $\sum_{i\le K}\log q_i\le L$.  Hence the number of
behaviors is at most
$\sum_{k\le K}8\cdot7^{k-1}\,\#\{e\in\N_{>0}^k:\eqref{eq:qbudget}\}$.
For $s>0$, Markov's exponential bound and the geometric series give
\[
  \#\{e\in\N_{>0}^k:\eqref{eq:qbudget}\}
  \le e^{sL}\prod_{i=1}^{k}\bigl(q_i^{\,s}-1\bigr)^{-1}.
\]
Choose $s=\log8/\log q_K$.  Then $q_i^{\,s}\le8$ for every $i\le K$, so each
factor $7/(q_i^{\,s}-1)$ is at least $1$ and the sum over $k$ is at most $K$
times its $k=K$ term:
\begin{equation}\label{eq:saddle}
  \log\#\text{behaviors}
  \;\le\;\log\tfrac{8K}{7}+sL
      +\sum_{i=1}^{K}\Bigl(\log7-\log\bigl(q_i^{\,s}-1\bigr)\Bigr).
\end{equation}
From $\log q_i=\log i+O(\log\log i)$ and
$\sum_{i\le K}\log q_i=K\log K\,(1+o(1))$ we get $K=(1+o(1))L/\log L$ and
$\log q_K=(1+o(1))\log L$, so $sL=(\log8+o(1))L/\log L$.  For the sum, fix
$\varepsilon>0$.  When $i\ge K^{1-\varepsilon}$ we have
$\log q_i\ge(1-\varepsilon+o(1))\log q_K$, hence
$q_i^{\,s}\ge8^{1-\varepsilon+o(1)}$ and the $i$th term is at most
$\delta(\varepsilon):=\log\bigl(7/(8^{1-\varepsilon}-1)\bigr)$, which tends
to $0$ with $\varepsilon$.  The remaining $K^{1-\varepsilon}=o(K)$ terms are
each at most $\log7-\log(s\log q_i)=O(\log\log L)$.  The sum is therefore at
most $K\delta(\varepsilon)+o(K)$; letting $L\to\infty$ and then
$\varepsilon\to0$ makes it $o(L/\log L)$.  Substituting into
\eqref{eq:saddle} proves the claim.
\end{proof}

\begin{proposition}[Explicit floor]\label{prop:floor}
\[
  \liminf_{T\to\infty}\;\frac{\mathcal C_F(T)}{T\log T}
  \;\ge\;\frac{1}{3\log10}=0.14476\ldots
\]
\end{proposition}

\begin{proof}
Suppose every $T$-bit table has a source of at most $D$ digits.  Counting
decimal strings alone gives $2^T\le10^D$, so $D\ge T\log2/\log10$ and
$\log D=\log T+O(1)$.  A source of $D$ digits has $\log N\le D\log10$, so
Lemma~\ref{lem:count8} gives
\[
  T\log2\;\le\;\bigl(\log8+o(1)\bigr)\frac{D\log10}{\log(D\log10)}
  \;=\;\bigl(\log8+o(1)\bigr)\frac{D\log10}{\log T}.
\]
Rearranging and using $\log2/\log8=\frac13$ gives
$D\ge(1-o(1))\,T\log T/(3\log10)$.
\end{proof}

The exponent $\log8$ is the right one for spellings: there are $8^\ell$
strings of length $\ell$, and by Lemma~\ref{lem:walk} each is spelled for
$(1+o(1))\ell\log\ell$ on GRH, so Lemma~\ref{lem:count8} is tight to the
factor $1+o(1)$.  The floor moves only by counting behaviors rather than
spellings.  The first step of that is free: a shortest source never contains
a cancelling pair.

\begin{proposition}[Reduced words]\label{prop:reduced}
Let $\lambda=6.3877\ldots$ be the largest root of $x^3-4x^2-14x-8$.  Then
\[
  \liminf_{T\to\infty}\;\frac{\mathcal C_F(T)}{T\log T}
  \;\ge\;\frac{1}{\log_2(1+\lambda)\,\log10}=0.15052\ldots
\]
\end{proposition}

\begin{proof}
A shortest source for a table decodes to a program containing none of the
adjacent pairs \texttt{+-}, \texttt{-+}, \texttt{><}, \texttt{][},
\texttt{[]}.  The first three are identities, \texttt{><} because a move
right always succeeds (\texttt{<>} is not one at the leftmost cell).  A
\texttt{]} is left on a zero cell, so a \texttt{[} that follows it skips
its bracket, which is dead together with its body.  An entered \texttt{[]}
never terminates, so in a program that terminates on every input it is
never entered and is dead too.  Deleting characters never raises the cost:
each surviving run is a union of consecutive old runs, and giving it the
prime of its first old run keeps the primes increasing and in class, with
run lengths at most the old sums.  In the count of Lemma~\ref{lem:count8}
the class words are therefore walks in the graph on the eight instructions
without loops and without these five arcs; those of length $k-1$ number
$O(k^8\lambda^{k})$ with $\lambda$ the Perron root of its adjacency matrix,
whose characteristic polynomial is
$x^2(x+1)^2(x+2)(x^3-4x^2-14x-8)$.  With $s=\log(1+\lambda)/\log q_K$ in
place of $\log8/\log q_K$ every factor $\lambda/(q_i^{\,s}-1)$ is at least
$1$ and the proof of Lemma~\ref{lem:count8} goes through with
$\log(1+\lambda)$ for $\log8$: the sources with $\log N\le L$ realize at
most $\exp\bigl((\log(1+\lambda)+o(1))L/\log L\bigr)$ behaviors, and the
proof of Proposition~\ref{prop:floor} gives
$D\ge(1-o(1))\,T\log T/(\log_2(1+\lambda)\log10)$.
\end{proof}

On the other side, the construction of Lemma~\ref{lem:draw} is as short as
any program of its kind.

\begin{proposition}[Drawing floor]\label{prop:drawing}
Let a family of programs computing every $T$-bit table consist of a
table-dependent word $X$ over $\{\texttt{>},\texttt{<},\texttt{+},\texttt{-}\}$
followed by a program drawn from a set of at most $2^{o(T)}$ programs.  Then
some table needs $|X|\ge(1-o(1))\,T/\log_2(1+\sqrt2)$.
\end{proposition}

\begin{proof}
On every input $X$ reads and prints nothing and leaves the same state: cells
$0,\ldots,c$ holding bytes $u_0,\ldots,u_c$, zeros beyond, and the pointer
at some $\pi\le|X|$.  The state and the program after $X$ determine the
behavior, so the tables number at most $2^{o(T)}$ times the number of states
reachable with $|X|\le C$.  Reaching a state costs at least $c$ moves and
$|u_j|=\min(u_j,256-u_j)$ marks on cell $j$, so $c+\sum_j|u_j|\le C$.  For
$0<z<1$, since $\sum_{u\bmod256}z^{|u|}\le(1+z)/(1-z)$, the states number at
most
\[
  (C+1)\sum_{c\le C}z^{-(C-c)}\Bigl(\frac{1+z}{1-z}\Bigr)^{c+1}
  \le(C+1)\,z^{-C}\,\frac{1+z}{1-z}\sum_{c\ge0}\Bigl(z\,\frac{1+z}{1-z}\Bigr)^{c},
\]
and the series converges when $z(1+z)<1-z$, that is $z<\sqrt2-1$.  Taking
$z=\sqrt2-1-\delta$ gives $2^T\le2^{o(T)}\,K_\delta\,(\sqrt2-1-\delta)^{-C}$,
so $C\ge(1-o(1))\,T/\log_2\bigl((\sqrt2-1-\delta)^{-1}\bigr)$ for every
$\delta>0$.
\end{proof}

\begin{remark}[Where the constant stands]\label{rem:gap}
On GRH,
\[
  0.1505\;\le\;\liminf_{T\to\infty}\frac{\mathcal C_F(T)}{T\log T}
  \;\le\;\limsup_{T\to\infty}\frac{\mathcal C_F(T)}{T\log T}\;\le\;0.3416,
\]
a ratio of $2.27$; without GRH the upper bound is $0.3660$, with an
ineffective threshold where Corollary~\ref{cor:uncond} is explicit at $19181$.  Number theory
no longer separates the two.  Lemma~\ref{lem:walk} charges the walk what
the count charges a run, one logarithm, and the unconditional loss of
$15/14$ is the exponent $1/15$ of the best almost-all result in
progressions.  Nor does the tape: a program that carries the table as data
behind a fixed decoder spends $T/\log_2(1+\sqrt2)$ characters on it by
Proposition~\ref{prop:drawing}, and Lemma~\ref{lem:draw} spends no more, so
in that model the character count is settled.  Its digit count is not quite:
a run of length $e$ on the prime $q_i$ costs $e\log q_i$, less than
$e\log T$ when $i$ is small, and the count of Lemma~\ref{lem:count8} with
the four drawing letters has exponent $\log4$, a digit floor of
$1/(2\log10)=0.217$ within the model.

What separates $0.1505$ from $0.3416$ is a question about Brainfuck.  The
behaviors of programs of $C$ characters number between $(1+\sqrt2)^{C}$,
the tapes a drawing reaches, and $(1+\lambda)^{C}$, the reduced words; the
floor rises exactly as far as that count falls.  The ceiling falls only if
control flow can carry data denser than a drawing, at more than
$\log_2(1+\sqrt2)=1.27$ bits a character, where the decision tree carries
$1/17.5$.
\end{remark}

\section{Scope and reproducibility}

The theorem concerns source length.  It does not claim that factoring an
arbitrary $D$-digit integer is polynomial in $D$.  Generated programs form a
special family whose factors are enumerated directly; arbitrary balanced
semiprimes remain outside that guarantee.

The reference implementation uses segmented Eratosthenes enumeration and a
smallest-first product tree.  Executable checks cover generated-program
semantics, source sizes, and the finite identities used in the construction;
none is a premise of the language lower bound.

\paragraph{Data availability.}
No datasets were generated or analyzed in this study.
