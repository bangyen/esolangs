\begin{abstract}
A Factor source denotes a decimal integer whose prime
factorization encodes a Brainfuck program: a prime's residue modulo $11$
selects an instruction and its exponent gives the run length.  We prove that
the worst-case Factor source length for a Boolean truth table of length $T$ is
$\Theta(T\log T)$.  The upper bound combines a linear-size Brainfuck
construction with a fixed-modulus short-interval theorem for primes.  The
lower bound counts every integer encoding of at most $D$ digits and remains
valid in the presence of ignored prime factors, comments, and leading zeros;
these encodings realize only $\exp(O(D/\log D))$ behaviors.  The tree's
constant is exact, the walk's leading constant is explicit, and a sieve of
the classes modulo $11$ through $10^{11}$ gives a proven digit ceiling at
every arity up to $19$.  Beyond that arity the threshold is effective in
principle, the modulus admitting no exceptional zero, and an explicit
short-interval theorem on GRH makes it numerical: the ceiling is then
$24.6\,T\log T$ at every arity, falling to $35/\log 10<15.21$.  Carrying the
table as tape data and chaining one byte-sized index digit per level beats
the tree's constant, and letting one walk cell serve a whole group of
entries beats it again, giving $1.516\,T$ characters and a limit superior
of $1.32$ on GRH.  Running the count with the instruction primes
themselves makes the lower bound explicit too, at $1/(3\log10)$, so the
constant is bracketed within a factor of $9.1$, of which a factor of $2$ is
number theory and the rest is the construction.
\end{abstract}

\noindent\textbf{Keywords.} Descriptional complexity; Boolean functions;
Brainfuck; prime encoding; esoteric programming languages.

\section{Encoding model}

Let
\[
  N=\prod_p p^{e_p}
\]
be the positive integer spelled by the decimal digits of a Factor source;
every other character is a comment.  A source with no digits is read as
$N=1$, which decodes to the empty program.  An all-zero digit string also
decodes to the empty program; it is one exceptional behavior and is excluded
from the logarithmic notation below.
For a prime $p$, the residue $p\bmod 11$ selects the Brainfuck instruction
according to
\[
\begin{array}{c|cccccccc}
p\bmod 11&1&2&3&4&5&6&7&8\\ \hline
\text{instruction}&>&<&+&-&.&,&[&]
\end{array}
\]
and the exponent $e_p$ is its run length.  Residues $0,9,10$ are ignored.
The selected primes are read in increasing order.

For example, $45=3^2\cdot5$.  Since $3\bmod11=3$ and
$5\bmod11=5$, the source \texttt{45} decodes to \texttt{++.}: two
increments followed by output.  Starting from a zero cell, it emits the byte
of value $2$.  This example also illustrates that source order is irrelevant:
instruction order comes from increasing prime factors.

Write $C=\sum_{p\bmod 11\in\{1,\ldots,8\}}e_p$ for the length of the decoded
Brainfuck program, $m$ for its number of maximal runs, $Q$ for its largest
selected prime, and $D$ for the number of decimal digits of $N$.  Then
\begin{equation}\label{eq:digits}
  \log N=\sum_p e_p\log p,
  \qquad D=\lfloor\log_{10}N\rfloor+1.
\end{equation}
Comments and leading zeros change the literal source length but not $N$;
they can never help a shortest encoding.

Execution uses the standard Brainfuck machine: byte cells wrap modulo $256$,
the tape grows to the right, a move left from its initial cell stays there,
and matched brackets have their usual while-loop semantics.  For $n\ge1$ put
$T=2^n$.  Each input bit is supplied as a separate line containing its ASCII
digit.  A program
\emph{computes} a table $t=(t_0,\ldots,t_{T-1})\in\{0,1\}^{2^n}$ if, for every
$b_1\cdots b_n\in\{0,1\}^n$, a separate run on the input lines
$b_1,\ldots,b_n$ terminates and emits exactly the ASCII digit of
$t_{(b_1\cdots b_n)_2}$, with zero-based subscripts.
Define
\[
 \mathcal C_F(T)=\max_{t\in\{0,1\}^T}
 \min\{\text{total source characters of }P:P\text{ computes }t\}.
\]
Deleting comments and leading zeros never changes execution, so the minimum
source length over programs computing $t$ equals the minimum decimal-digit
count of a positive integer whose decoded program computes $t$.  All
unqualified logarithms below are natural.

\begin{theorem}\label{thm:main}
Every $T$-bit truth table has a Factor program of
$O(T\log(T+1))$ decimal digits.  Some $T$-bit truth tables require
$\Omega(T\log T)$ digits.  Hence $\mathcal C_F(T)=\Theta(T\log T)$.
\end{theorem}

Factor was introduced in 2020 as a prime-factor encoding of
Brainfuck~\cite{factor-spec}.  Its specification invokes Dirichlet's theorem
to ensure an unlimited supply of instruction primes.  We instead study
decimal description length.  The upper bound requires quantitative control
of successive instruction primes, while the lower bound counts all encodings,
including those with ignored factors.

\section{Upper bound}

The construction first emits a Brainfuck decision tree and then replaces each
maximal run by one prime power.  We begin by bounding the size of the decision
tree.

\begin{lemma}[Decision-tree size]\label{lem:tree}
For $n\ge2$, every $T$-bit truth table has a Brainfuck decision-tree program
of length
\[
  C\le\tfrac{35}{2}T+55n+25,
\]
with equality for parity.
\end{lemma}

\begin{proof}
Use the following identity-order construction.  For each input in turn, a
preamble reads its ASCII digit into cell $2i$ with \texttt{,} and subtracts
$48$ to obtain bit $b_i$, leaving cell $2i+1$ as a zero flag.  A node at depth
$i$ is entered at cell $2i$ and left at cell $2i+1$, both zero on exit:
\[
  \texttt{>+<[->-}\;A\;\texttt{]>[-}\;B\;\texttt{]}.
\]
The first loop runs on $b_i$ and clears it and the flag, so the one-branch
$A$ runs exactly when $b_i=1$; the second runs on the surviving flag, so the
zero-branch $B$ runs exactly when $b_i=0$.  The branch $A$ must end at cell
$2i$ and $B$ at cell $2i+1$.  A nonconstant child is
$A=\texttt{>}S\texttt{<<<}$ or $B=\texttt{>}S\texttt{<<}$, where $S$ is its
node.  A constant-one child moves to the result cell $2n$, increments it and
returns, costing $4(n-i)$ in $A$ and $4(n-i)-1$ in $B$; a constant-zero child
costs one \texttt{<} in $A$ and nothing in $B$.  After the root, one final
gadget moves to the result cell, adds the ASCII-zero offset and prints.

Let $F(k)$ bound the length of a node of height $k=n-i$ that is not the
root.  Its own characters number $12$.  At height $1$ both children are
single rows, and they differ because the node's subtree is not constant, so
$F(1)=12+4+0=12+1+3=16$.  At height $k\ge2$ a child costs at most
$\max\{F(k-1)+4,4k\}$ in $A$ and $\max\{F(k-1)+3,4k-1\}$ in $B$.  By
induction $F(k-1)+19=35\cdot2^{k-2}$, and then $F(k-1)\ge4k-4$, so
\[
  F(k)\le12+2F(k-1)+7,
  \qquad
  F(k)\le35\cdot2^{k-1}-19.
\]
The root obeys the same bound unless the table is constant, when it costs at
most $12+8n-1\le35\cdot2^{n-1}-19$ for $n\ge2$.  The preamble costs
$49n+2(n-1)$, the return to cell $0$ costs $2(n-1)$, and the final gadget
costs $(2n-1)+48+1$.  Adding $35\cdot2^{n-1}-19$ gives the displayed bound.
Parity has no constant subtree above the leaves, so every inequality is an
equality.
\end{proof}

The implementation returns the shorter of this identity-order program and one
built for a reordered set of variables, so its $C$ is no larger.  At $n=1$ the
constant-one table costs $118$ characters, three above the displayed formula.

The encoder replaces each maximal run by one prime power.  It scans
primes upward and chooses the first prime in the residue class required by
the next run.  The following standard consequence of the prime number theorem
in short arithmetic progressions controls this adaptive sequence.

\begin{lemma}[Fixed-modulus short intervals]\label{lem:short}
There are constants $x_0$ and $\theta<1$ such that for every reduced
residue class $a\pmod{11}$, every $x\ge x_0$ has a prime
\[
  p\equiv a\pmod {11},
  \qquad x<p\le x+x^\theta.
\]
\end{lemma}

\begin{proof}
The Hoheisel theorem for arithmetic progressions gives the expected
asymptotic number of primes in $(X-h,X]$ in every reduced class modulo $q$
when $q\le(\log X)^A$ and
$h\ge X^{7/12+\varepsilon}(\log X)^A$; see Thorner and
Zaman~\cite[Section~1.2]{thorner-zaman}.  Fix
$7/12+\varepsilon<\theta<1$, put
$X=x+x^\theta$ and $h=x^\theta$.  Since $X\sim x$, the displayed size
condition holds for all sufficiently large $x$, while
$(X-h,X]=(x,x+x^\theta]$.  Taking $q=11$, the count in each of the ten
reduced classes is $(1+o(1))\,h/(10\log X)$, which is positive for large
$x$; one $x_0$ serves all eight classes used below.  The constants $x_0$ and
$\theta$ are not made explicit, and only their existence is used.
\end{proof}

\begin{lemma}\label{lem:adaptive}
If $p_i$ is the prime selected for the $i$th run, then
$p_i=O\bigl(i^{1/(1-\theta)}\bigr)$.  In particular,
$\log Q=O(\log(m+1))$.
\end{lemma}

\begin{proof}
Let $i_0$ be the first index with $p_{i_0}\ge x_0$.  Then
$i_0\le\pi(x_0)+1$, and $p_{i_0}\le x_0+x_0^\theta$ by Lemma~\ref{lem:short}
at $x=x_0$, so the indices before $i_0$ change only the implied constant.
From $i_0$ on, Lemma~\ref{lem:short} gives
\[
  p_{i+1}\le p_i+p_i^\theta.
\]
Put $r=1-\theta>0$.  Concavity of $x^r$ gives
\[
  p_{i+1}^r-p_i^r
  \le r p_i^{r-1}(p_{i+1}-p_i)\le r.
\]
Thus $p_i^r=O(i)$ and $p_i=O(i^{1/r})$.
\end{proof}

\begin{proposition}[Upper bound]\label{prop:upper}
The generated Factor source has $D=O(T\log(T+1))$ digits.
\end{proposition}

\begin{proof}
By Lemma~\ref{lem:tree}, $C=O(T)$, and there are at most $C$ runs.  By
Lemma~\ref{lem:adaptive},
$\log Q=O(\log(m+1))$.  Equation~\eqref{eq:digits} yields
\[
  \log N\le C\log Q
  =O\bigl(C\log(m+1)\bigr)
  =O\bigl(T\log(T+1)\bigr).
\]
Changing logarithm bases proves the digit bound.
\end{proof}

\section{Explicit constants}

Proposition~\ref{prop:upper} hides two constants: the tree's, which
Lemma~\ref{lem:tree} makes exact, and the prime walk's, which depends on the
unstated $x_0$ and $\theta$ of Lemma~\ref{lem:short}.  The walk's leading
constant is explicit even so; its threshold is not.

\begin{corollary}[Leading constant]\label{cor:leading}
For every $\theta$ admissible in Lemma~\ref{lem:short}, the generated
sources satisfy
\[
  \limsup_{T\to\infty}\;\max_{t\in\{0,1\}^T}\frac{D(t)}{T\log T}
  \le\frac{35}{2(1-\theta)\log10}.
\]
Every $\theta>7/12$ is admissible, so the limit superior is at most
$42/\log10<18.25$.
\end{corollary}

\begin{proof}
The proof of Lemma~\ref{lem:adaptive} gives
$p_i^{1-\theta}\le p_{i_0}^{1-\theta}+(1-\theta)i$, hence
$\log Q\le(1-\theta)^{-1}\log m+O(1)$.  With $m\le C$ and
Lemma~\ref{lem:tree},
$\log N\le C\log Q\le\frac{35}{2}T\bigl((1-\theta)^{-1}\log T+O(1)\bigr)
+O(n\log T)$.  Divide by $\log10$.  The proof of Lemma~\ref{lem:short}
accepts every $\theta>7/12$, and $\frac{35}{2}\cdot\frac{12}{5}=42$.
\end{proof}

The constant $\frac{35}{2}$ above is the decision tree's, and the tree is not
the cheapest program.  A table can be carried as data on the tape and indexed,
which trades execution time for length; since $\mathcal C_F(T)$ minimizes over
all programs, that trade is free here.  The obstacle is that a Brainfuck cell
holds one byte, so an index into $T$ cells does not fit in a cell once
$n>8$.  Chaining removes it: split the index into chunks of at most eight
bits, one per level of a tree of blocks, and read each chunk from the input at
the moment and the place its level needs it, so no counter is ever carried.

\begin{lemma}[Chained lookup]\label{lem:chain}
Every $T$-bit truth table has a Brainfuck program of at most
$2.532\,T+O(\log T)$ characters.
\end{lemma}

\begin{proof}
Let the chunk sizes be eight bits at every level, with the remainder placed at
the second level from the top, and put $r=2^{8}=256$.  Define block widths by
$B_{-1}=2$ and $B_j=rB_{j-1}+2$; a level-$j$ block holds $r$ sub-blocks
followed by two scratch cells, its \emph{anchor}, and a leaf block holds $r$
pairs of a walk cell and a data cell.  Unfolding the recursion,
$B_{m-1}=2T+2(T-1)/(r-1)$ for $T=r^m$.

Emit the table by walking the whole span once, writing a \texttt{+} at each
data cell whose entry is set; storing the complement when the set entries are
in the majority caps that at $T/2$.  This leaves the pointer on the top
anchor.  At each level in turn, accumulate the level's chunk from the input
into the anchor by $a\mapsto2a+b$, move it two cells left onto the last
sub-block's anchor, and run
\[
  \texttt{[[-}\,\underbrace{\texttt{<}\cdots\texttt{<}}_{B_{j-1}}
  \texttt{+}\underbrace{\texttt{>}\cdots\texttt{>}}_{B_{j-1}}
  \texttt{]}\underbrace{\texttt{<}\cdots\texttt{<}}_{B_{j-1}}\texttt{-]},
\]
which hops one sub-block left per unit and lands on the anchor of sub-block
$r-1-d$, where $d$ is the chunk.  The hop touches only anchors, which are
scratch, so the data is undisturbed, and the landing cell is left zero.  The
data is therefore laid out reversed at each level.  At the leaf the same step
with $B_{-1}=2$ lands on a walk cell, and one \texttt{>} reaches the answer,
which is printed after adding $48$.

For the count: the walk is $B_{m-1}-2$ characters, the set entries at most
$T/2$, the hop loops $3\sum_{j<m-1}B_j+O(m)$, and reading the chunks
$O(n)$.  Since $\sum_{j\le m-2}B_j=2(T-1)/(r-1)+O(T/r^2)$, the total is
\[
  \Bigl(2+\frac{2}{r-1}\Bigr)T+\frac{T}{2}
  +\frac{6T}{r-1}+O\!\left(\frac{T}{r^2}\right)+O(n)
  =\Bigl(\frac52+\frac{8}{255}\Bigr)T+O\!\left(\frac{T}{r^2}\right)+O(n).
\]
Here $\frac52+\frac{8}{255}=2.53137\ldots$ and the $r^{-2}$ terms contribute
a further $9.3\cdot10^{-5}\,T$, so the total is below $2.532\,T$.
\end{proof}

Two cells an entry is more than the hop needs.  The counter hop requires a
zero cell beside what it addresses, but only at the granularity it
addresses, so the leaf level can address \emph{groups} and let a decision
tree finish the job.

\begin{lemma}[Grouped lookup]\label{lem:group}
Every $T$-bit truth table has a Brainfuck program of at most
$1.516\,T+o(T)$ characters.
\end{lemma}

\begin{proof}
Fix $k=2^{g}$ and lay the table out in groups
\[
  [W][S_0][S_1][d_0]\cdots[d_{k-1}],
\]
of $k+3$ cells for $k$ entries.  Run the chain of Lemma~\ref{lem:chain} on
the top $n-g$ index bits with the groups as its leaf level, so its hop
stride there is $k+3$ and it touches only the cells $W$, which are zero; the
seat step at that level moves by the stride rather than by $2$, a group's
anchor being its first cell rather than two before its last.

The walk leaves the pointer on the $W$ of the selected group.  Resolve the
remaining $g$ bits by a decision tree over that group, entered and left on
$W$: a node reads its bit into $S_0$ and raises a flag in $S_1$, then
\[
  \texttt{[->-<<}\;\textit{high}\;\texttt{>]}\qquad
  \texttt{>[-<<}\;\textit{low}\;\texttt{>>]<<},
\]
where each subtree returns to $W$ with $S_0=S_1=0$, so both brackets close
on a zero.  A leaf steps right to its data cell, adds $48$, prints, clears
the cell and steps back; under the complement it instead holds $49$ on $W$
and drains the stored bit into it.  The tree is emitted once, after the
walk, not once per group, and is $O(k^2)$ characters.

Counting as in Lemma~\ref{lem:chain}, the span is
$(1+3/k)(1+\frac1{255})T$, the set entries cost at most $T/2$ under the
complement, and the hops $3/255$ of the span.  Taking $k=\lfloor\log
T\rfloor$ makes the tree $O(\log^2T)$ and $3/k=o(1)$, leaving
\[
  \Bigl(1+\tfrac1{255}\Bigr)\Bigl(1+\tfrac3{255}\Bigr)T+\frac T2+o(T)
  =1.51573\ldots T+o(T).\qedhere
\]
\end{proof}

\begin{corollary}[Leading constant, improved]\label{cor:chain}
For every $\theta$ admissible in Lemma~\ref{lem:short},
\[
  \limsup_{T\to\infty}\;\frac{\mathcal C_F(T)}{T\log T}
  \le\frac{1.516}{(1-\theta)\log10},
\]
which is $1.58$ at $\theta=\frac7{12}$ and $1.32$ on GRH.
\end{corollary}

\begin{proof}
Repeat the proof of Corollary~\ref{cor:leading} with Lemma~\ref{lem:group}
in place of Lemma~\ref{lem:tree}, so that $C\le1.516\,T+o(T)$ and
$\log N\le C\log Q\le C(1-\theta)^{-1}\log T\,(1+o(1))$.
\end{proof}

The construction's walk is quadratic in $T$ where the tree is linear, so it
is a statement about $\mathcal C_F(T)$ and not a replacement generator; the
implementation keeps the tree, whose per-arity ceilings Section~\ref{sec:grh}
makes explicit.

The constant $O(1)$ above contains $x_0$, so the corollary does not say at
which $T$ the ceiling takes hold.  For the arities that can be generated in
practice a computation replaces it; Section~\ref{sec:grh} covers the rest on
GRH.  The ineffectivity is an artifact of the quotation, not of the modulus.

\begin{remark}[Effectivity at a fixed modulus]\label{rem:effective}
Lemma~\ref{lem:short} carries an ineffective $x_0$ only because it is quoted
from a theorem uniform in $q$.  At the fixed modulus $11$ the one ineffective
ingredient of a Hoheisel argument is Siegel's lower bound for $L(1,\chi)$ at a
real character, and the only real character modulo $11$ is the Legendre
symbol, odd because $11\equiv3\pmod 4$.  Its field $\mathbb Q(\sqrt{-11})$ has
class number $1$ and two units, so the class-number formula gives
\[
  L(1,\chi)=\frac{2\pi h}{w\sqrt{11}}=\frac{\pi}{\sqrt{11}}=0.94722\ldots,
\]
which excludes an exceptional zero outright.  So $x_0$ is effective in
principle at this modulus; what the literature does not supply is a value for
it.  Under GRH one is available.
\end{remark}

\begin{lemma}[Computed class gaps]\label{lem:computed}
Put $c=8.62$ and $X=10^{11}-10^4$.  For every real $0\le x\le X$ and every
$a\in\{1,\ldots,8\}$ there is a prime
\[
  p\equiv a\pmod{11},
  \qquad x<p\le x+c\log^2\max(x,37).
\]
\end{lemma}

\begin{proof}
A segmented sieve through $10^{11}$ records, for each class, every pair of
consecutive primes $q<p$ of the class.  On $q\le x<p$ the ratio
$(p-x)/\log^2\max(x,37)$ is nonincreasing, so its supremum is the value at
$x=q$; the largest such value is $8.6184$, attained by the class-$2$ pair
$4{,}160{,}719<4{,}162{,}721$.  Before a class's first prime, which is at
most $37$, the gap is at most $37<c\log^237$.  Every class has a prime in
$(X,10^{11}]$, so each $x\le X$ has its next class prime inside the sieved
range.
\end{proof}

\begin{proposition}[Computed ceiling]\label{prop:computed}
Let a table's program have $C$ instructions, and let $y\ge37$ satisfy
$37+(C-1)c\log^2y\le y\le X$.  Then $Q\le y$ and
\[
  D\le\lfloor C\log_{10}y\rfloor+1.
\]
\end{proposition}

\begin{proof}
The first selected prime is at most $37$.  By induction on $i\le m$,
$p_i\le37+(i-1)c\log^2y$: this is at most $y\le X$, so
Lemma~\ref{lem:computed} applies at $x=p_i$ and gives
$p_{i+1}\le p_i+c\log^2y$.  Hence $Q\le37+(m-1)c\log^2y\le y$ because
$m\le C$.  Finally $\log N\le C\log Q$.
\end{proof}

With $C\le\frac{35}{2}T+55n+25$ the least admissible $y$ is below $X$ for
every $n\le19$.  At $n=13$, for instance, $y=498{,}168{,}370$ and
$D\le1{,}253{,}292$, so $D/(T\log T)\le16.98$ over all $2^{8192}$ tables;
parity, which attains the tree bound, measures $966{,}568$ digits, or
$13.09$.  The ceiling falls to $14.19$ at $n=19$.  In this range each step
of the walk is polylogarithmic rather than a power of $p_i$, so the ceiling
tends towards $\frac{35}{2}/\log10\approx7.60$ rather than
Corollary~\ref{cor:leading}'s $18.25$, but slowly: $\log_{10}y$ exceeds
$\log_{10}C$ by $\log_{10}(c\log^2y)$.

\section{An effective threshold on GRH}\label{sec:grh}

Lemma~\ref{lem:computed} stops at $10^{11}$, so Proposition~\ref{prop:computed}
stops at $n=19$.  The generalized Riemann hypothesis carries the walk the rest
of the way with constants that are still explicit, because the one
short-interval theorem for progressions that is explicit on GRH has, at
$q=11$, a threshold five orders of magnitude \emph{below} the sieved range.
The two therefore overlap, and no $x$ is left uncovered.

\begin{lemma}[Explicit short intervals on GRH]\label{lem:grh}
Assume GRH for $\zeta$ and for the Dirichlet $L$-functions of the characters
modulo $11$, and put
\[
  h(t)=10\bigl(\tfrac12\log t+\log11+12\bigr)\sqrt t .
\]
Then for every $a\in\{1,\ldots,8\}$ and every $x\ge10^{11}$ there is a prime
\[
  p\equiv a\pmod{11},\qquad x<p\le x+2h(2x).
\]
\end{lemma}

\begin{proof}
Dudek, Greni\'e and Molteni~\cite[Thm.~1.1]{dgm} prove on GRH that for
$q\ge3$, $(a,q)=1$, and the row $(\alpha,\delta,\rho,m)=(\frac12,1,12,23)$ of
their Table~1, every
\[
  h\ge\varphi(q)\bigl(\alpha\log x+\delta\log q+\rho\bigr)\sqrt x,
  \qquad x\ge(m\varphi(q)\log q)^2
\]
admits a prime $p\equiv a\pmod q$ with $|p-x|<h$.  At $q=11$ we have
$\varphi(q)=10$, the displayed $h$ is theirs, and the threshold is
$(230\log11)^2<3.05\cdot10^5$.

The quantity $h(2x)/x=10\sqrt2\bigl(\frac12\log2x+\log11+12\bigr)/\sqrt x$
decreases for $x\ge e^2$ and equals $1.23\cdot10^{-3}$ at $x=10^{11}$, so
$h(2x)\le x$ throughout $x\ge10^{11}$.  Put $c=x+h(2x)$, so that
$x\le c\le2x$.  Then $h(c)\le h(2x)$ because $h$ increases, whence
$c-h(c)\ge x$.  Applying the quoted theorem at $c\ge x\ge3.05\cdot10^5$ gives
a prime $p\equiv a\pmod{11}$ with $|p-c|<h(c)$, and therefore
\[
  x\le c-h(c)<p<c+h(c)\le x+2h(2x).\qedhere
\]
\end{proof}

\begin{proposition}[Effective ceiling on GRH]\label{prop:grh}
Assume the hypothesis of Lemma~\ref{lem:grh} and let a table's program have
$C$ instructions.  With $c=8.62$ and $X=10^{11}-10^4$ as in
Lemma~\ref{lem:computed}, put
\[
  K=\Bigl\lfloor\frac{X-37}{c\log^2X}\Bigr\rfloor=18\,083\,227 .
\]
For $C\le K$ use Proposition~\ref{prop:computed}.  Otherwise let
$U\ge\sqrt{10^{11}}$ satisfy
\[
  \sqrt{10^{11}}+(C-K)\bigl(10\sqrt2\log U+\beta\bigr)\le U,
  \qquad
  \beta=10\sqrt2\bigl(\tfrac12\log2+\log11+12\bigr)=208.52\ldots
\]
Then $Q\le U^2$ and $D\le\lfloor2C\log_{10}U\rfloor+1$.
\end{proposition}

\begin{proof}
Let $p_1<\cdots<p_m$ be the selected primes, $m\le C$.  The induction of
Proposition~\ref{prop:computed} gives $p_i\le37+(i-1)c\log^2X$ for as long as
the right side stays at or below $X$, which by the definition of $K$ covers
$i\le K$; so $p_K\le X<10^{11}$.

Put $B_0=10^{11}$ and $B_{j+1}=B_j+2h(2B_j)$.  If $p\le B_j$ then the least
prime of any reduced class exceeding $p$ is at most $B_{j+1}$: apply
Lemma~\ref{lem:grh} at $x=\max(p,10^{11})\le B_j$, which yields a class prime
in $(x,x+2h(2x)]\subseteq(p,B_{j+1}]$.  Hence $p_{K+j}\le B_j$ for every
$j\ge0$ by induction, the base being $p_K\le B_0$.

Write $u_j=\sqrt{B_j}$.  From $\sqrt{a+b}\le\sqrt a+b/(2\sqrt a)$ and
$\tfrac12\log B_j=\log u_j$,
\[
  u_{j+1}\le u_j+\frac{h(2B_j)}{\sqrt{B_j}}
         = u_j+10\sqrt2\log u_j+\beta .
\]
So if $u_j\le U$ then $u_{j+1}\le u_j+10\sqrt2\log U+\beta$, and induction
gives $u_j\le\sqrt{10^{11}}+j(10\sqrt2\log U+\beta)\le U$ for every
$j\le C-K$.  Since $m-K\le C-K$, we get $Q=p_m\le B_{m-K}\le U^2$, and
$\log N\le C\log Q\le2C\log U$.
\end{proof}

\begin{corollary}\label{cor:grh}
On the same hypothesis the generated sources satisfy
$D\le24.6\,T\log T$ for every $n\ge8$, and
\[
  \limsup_{T\to\infty}\;\max_{t\in\{0,1\}^T}\frac{D(t)}{T\log T}
  \le\frac{35}{\log10}<15.21 .
\]
\end{corollary}

\begin{proof}
The fixed point of Proposition~\ref{prop:grh} has
$U=(C-K)(10\sqrt2\log U+\beta)(1+o(1))$, so $\log U=\log C+O(\log\log C)$ and
$D\le2C\log_{10}U$ gives, with $C\le\frac{35}{2}T+55n+25$ and
$\log C=\log T+O(1)$, the stated limit superior; $\frac{35}{2}\cdot2=35$.
The uniform bound is the larger of the two rules' maxima over $n\ge8$: the
computed ceiling peaks at $24.56$ at $n=8$, and the GRH ceiling, which takes
over at $n=20$, peaks at $24.06$ at $n=22$ and decreases from there.
\end{proof}

Because $K$ runs are spent before Lemma~\ref{lem:grh} is invoked at all, the
GRH ceiling is weaker than the computed one wherever the latter applies, and
the crossover is exactly the sieve's edge:

\begin{center}
\begin{tabular}{r|cccc|cccccc}
$n$ & 13 & 16 & 19 & 20 & 22 & 25 & 30 & 60 & $10^3$ & $10^6$\\ \hline
$D/(T\log T)$ & 16.98 & 15.31 & 14.19 & 20.46 & 24.06 & 23.27 & 22.01 & 18.75
& 15.47 & 15.20
\end{tabular}
\end{center}

\noindent
The first three columns are Lemma~\ref{lem:computed}'s; the rest are
Proposition~\ref{prop:grh}'s.  The approach to $35/\log10$ is slow because
$\log U$ exceeds $\log C$ by $\log(10\sqrt2\log U+\beta)$.  GRH also improves
Corollary~\ref{cor:leading}'s leading constant, $18.25$ falling to $15.21$,
since a square-root gap bound is the case $\theta=\frac12$ of
Lemma~\ref{lem:short} and $\frac{35}{2(1-\theta)}=35$.

\begin{remark}[Removing GRH]\label{rem:unconditional}
The ingredients for an unconditional explicit $\theta$ are in print, though we
have not assembled them.  Thorner and Zaman~\cite[Thm.~1.2]{tz-density} prove
the explicit log-free density estimate
\[
  N(\sigma,Q)\le10^{88}\bigl(10^{421}Q^{99}\bigr)^{1-\sigma},
  \qquad Q\ge3,\quad \sigma\ge\tfrac{39}{40},
\]
in which $N(\sigma,Q)$ counts the zeros with $|\gamma|\le Q$ of every
primitive $L$-function of modulus at most $Q$; taking $Q=\max(T,11)$ bounds
the zeros of our ten characters, wastefully but validly.
Kadiri~\cite{kadiri} gives an explicit zero-free region for Dirichlet
$L$-functions over $3\le q\le400000$, and Remark~\ref{rem:effective} disposes
of the exceptional zero at $q=11$.  Ingham's argument turns a density
exponent $A$ into primes in $(x,x+x^\theta]$ for every $\theta>1-1/A$, so
Corollary~\ref{cor:leading} would read
\[
  \limsup_{T\to\infty}\;\max_{t\in\{0,1\}^T}\frac{D(t)}{T\log T}
  \le\frac{35A}{2\log10}.
\]
At $A=99$ this is $\theta=\frac{98}{99}$ and a constant of $752.5$, against
$18.25$ for Huxley's ineffective $A=\frac{12}{5}$ and $15.21$ for GRH's
$A=2$.  The constant is not the whole cost: the $10^{88}$ and $10^{421}$ put
$x_0$ far above $10^{11}$, so Lemma~\ref{lem:computed} could not bridge to it
and the assembled statement would be a limit superior past an astronomical
arity rather than a ceiling at every arity, which is what
Proposition~\ref{prop:grh} already gives.
\end{remark}

\section{Language lower bound}

A language lower bound must count every integer that might encode a table.

\begin{lemma}[Run bound]\label{lem:runs}
If a Factor integer satisfies $\log N\le L$ and has $k$ useful prime factors,
then
\[
  k=O(L/\log(L+2)).
\]
\end{lemma}

\begin{proof}
The $i$th useful prime is at least $i+1$, and every useful exponent is at
least one.  Hence
\[
  L\ge\sum_{i=1}^{k}\log(i+1)=\log((k+1)!).
\]
Since $\log((k+1)!)\ge(k+1)\bigl(\log(k+1)-1\bigr)$, this gives
$k=O(L/\log(L+2))$.
\end{proof}

\begin{lemma}[Exponent vectors]\label{lem:vectors}
Fix $k$ and $L\ge2$.  The number of vectors
$(e_1,\ldots,e_k)\in\N_{>0}^k$ satisfying
\begin{equation}\label{eq:budget}
  \sum_{i=1}^{k}e_i\log(i+1)\le L
\end{equation}
is $\exp(O(L/\log L))$, uniformly for
$k=O(L/\log L)$.
\end{lemma}

\begin{proof}
Put $f_i=e_i-1\ge0$ and $s=1/\log(L+2)$.  Dropping the fixed contribution
of the ones only enlarges the set.  Markov's exponential bound and the
geometric series give
\begin{align}
 \#\Bigl\{f\in\N_{\ge0}^k:\sum_if_i\log(i+1)\le L\Bigr\}
 &\le e^{sL}
       \sum_{f_1,\ldots,f_k\ge0}
       \exp\!\left(-s\sum_i f_i\log(i+1)\right)\\
 &=e^{sL}\prod_{i=1}^{k}
       \left(1-(i+1)^{-s}\right)^{-1}.
\end{align}
The first factor has logarithm $L/\log(L+2)$.  To bound the product, split
at $i=\lfloor\sqrt L\rfloor$.  For $i$ below the split,
\[
 -\log\left(1-(i+1)^{-s}\right)=O(\log\log(L+2)),
\]
so these factors contribute
$O(\sqrt L\log\log(L+2))=O(L/\log L)$.  Above the split,
$(i+1)^{-s}\le\exp(-1/3)$ for all sufficiently large $L$, so each logarithm
is $O(1)$.  Lemma~\ref{lem:runs} bounds their number by $O(L/\log L)$.
Taking logarithms proves the claim; bounded $L$ is absorbed in the constant.
\end{proof}

\begin{proposition}[Behavior count]\label{prop:count}
Factor sources whose digit integers satisfy $\log N\le L$ realize at most
\[
  \exp(O(L/\log L))
\]
distinct behaviors.
\end{proposition}

\begin{proof}
Discard ignored-residue prime factors: they do not alter the decoded
Brainfuck program.  For $k$ useful primes, their increasing order fixes the
instruction order once their residue classes are chosen.  There are at most
$8^k$ class words.  Replacing the actual $i$th prime by its lower bound
$i+1$ relaxes the size constraint to \eqref{eq:budget}, so
Lemma~\ref{lem:vectors} bounds the run lengths.  Finally sum over the
$O(L/\log L)$ possible values of $k$.  The factors $8^k$ and the number of
summands are both absorbed by $\exp(O(L/\log L))$.
\end{proof}

\begin{proposition}[Lower bound]\label{prop:lower}
For all sufficiently large $T$, some $T$-bit truth table requires
$\Omega(T\log T)$ Factor digits.
\end{proposition}

\begin{proof}
Every nonzero digit integer spelled with at most $D$ digits has
$\log N=O(D)$, so Proposition~\ref{prop:count} bounds the number of its
behaviors by
\[
  \exp(O(D/\log D)).
\]
Zero-valued sources add only the empty behavior, which is absorbed by this
bound.
There are $2^T$ Boolean truth tables.  If every table had a source of at most $D$ digits,
then $D/\log D=\Omega(T)$, which implies $D=\Omega(T\log T)$.
Ignored factors, comments, and leading zeros cannot invalidate the count:
they add spellings of an already-counted decoded program, not behaviors.
\end{proof}

Propositions~\ref{prop:upper} and~\ref{prop:lower} prove
Theorem~\ref{thm:main}.

Proposition~\ref{prop:lower} leaves its constant inside the $\Omega$.  What
hides it is the Markov parameter of Lemma~\ref{lem:vectors}, chosen there
only to make the exponent $O(L/\log L)$; placing it at the saddle instead
makes the constant explicit, and it is $\log8$ --- one instruction letter per
unit of run length.  We state the count with the instruction primes
themselves, writing $q_i$ for the $i$th prime whose residue modulo $11$ lies
in $\{1,\ldots,8\}$, so that $q_1,q_2,\ldots=2,3,5,7,13,\ldots$ and, by the
prime number theorem for progressions, $q_i=\frac54 i\log i\,(1+o(1))$.  The
crude bound $p_i\ge i+1$ of Lemma~\ref{lem:runs} yields the same constant,
since $\log(i+1)$ and $\log q_i$ agree to leading order; it only approaches
it more slowly.

\begin{lemma}[Refined behavior count]\label{lem:count8}
Factor sources whose digit integers satisfy $\log N\le L$ realize at most
$\exp\bigl((\log8+o(1))L/\log L\bigr)$ distinct behaviors.
\end{lemma}

\begin{proof}
Discard the ignored-residue factors; they do not alter the decoded program.
A behavior is determined by that program, a string over the eight instruction
letters, whose maximal runs we write $a_1^{e_1}\cdots a_k^{e_k}$ with
$a_i\ne a_{i+1}$.  The primes carrying the runs increase and are useful, so
the $i$th is at least $q_i$ and
\begin{equation}\label{eq:qbudget}
  L\;\ge\;\sum_{i=1}^{k}e_i\log q_i .
\end{equation}
There are at most $8\cdot7^{k-1}$ class words, and $k\le K$, where $K$ is
the largest index with $\sum_{i\le K}\log q_i\le L$.  Hence the number of
behaviors is at most
$\sum_{k\le K}8\cdot7^{k-1}\,\#\{e\in\N_{>0}^k:\eqref{eq:qbudget}\}$.
For $s>0$, Markov's exponential bound and the geometric series give
\[
  \#\{e\in\N_{>0}^k:\eqref{eq:qbudget}\}
  \le e^{sL}\prod_{i=1}^{k}\bigl(q_i^{\,s}-1\bigr)^{-1}.
\]
Choose $s=\log8/\log q_K$.  Then $q_i^{\,s}\le8$ for every $i\le K$, so each
factor $7/(q_i^{\,s}-1)$ is at least $1$ and the sum over $k$ is at most $K$
times its $k=K$ term:
\begin{equation}\label{eq:saddle}
  \log\#\text{behaviors}
  \;\le\;\log\tfrac{8K}{7}+sL
      +\sum_{i=1}^{K}\Bigl(\log7-\log\bigl(q_i^{\,s}-1\bigr)\Bigr).
\end{equation}
From $\log q_i=\log i+O(\log\log i)$ and
$\sum_{i\le K}\log q_i=K\log K\,(1+o(1))$ we get $K=(1+o(1))L/\log L$ and
$\log q_K=(1+o(1))\log L$, so $sL=(\log8+o(1))L/\log L$.  For the sum, fix
$\varepsilon>0$.  When $i\ge K^{1-\varepsilon}$ we have
$\log q_i\ge(1-\varepsilon+o(1))\log q_K$, hence
$q_i^{\,s}\ge8^{1-\varepsilon+o(1)}$ and the $i$th term is at most
$\delta(\varepsilon):=\log\bigl(7/(8^{1-\varepsilon}-1)\bigr)$, which tends
to $0$ with $\varepsilon$.  The remaining $K^{1-\varepsilon}=o(K)$ terms are
each at most $\log7-\log(s\log q_i)=O(\log\log L)$.  The sum is therefore at
most $K\delta(\varepsilon)+o(K)$; letting $L\to\infty$ and then
$\varepsilon\to0$ makes it $o(L/\log L)$.  Substituting into
\eqref{eq:saddle} proves the claim.
\end{proof}

\begin{proposition}[Explicit floor]\label{prop:floor}
\[
  \liminf_{T\to\infty}\;\frac{\mathcal C_F(T)}{T\log T}
  \;\ge\;\frac{1}{3\log10}=0.14476\ldots
\]
\end{proposition}

\begin{proof}
Suppose every $T$-bit table has a source of at most $D$ digits.  Counting
decimal strings alone gives $2^T\le10^D$, so $D\ge T\log2/\log10$ and
$\log D=\log T+O(1)$.  A source of $D$ digits has $\log N\le D\log10$, so
Lemma~\ref{lem:count8} gives
\[
  T\log2\;\le\;\bigl(\log8+o(1)\bigr)\frac{D\log10}{\log(D\log10)}
  \;=\;\bigl(\log8+o(1)\bigr)\frac{D\log10}{\log T}.
\]
Rearranging and using $\log2/\log8=\frac13$ gives
$D\ge(1-o(1))\,T\log T/(3\log10)$.
\end{proof}

The exponent $\log8$ is the right one, which caps what this route can ever
prove.

\begin{remark}[The counting route is nearly exhausted]\label{rem:cap}
There are $8^{\ell}$ strings of length $\ell$, and Lemma~\ref{lem:adaptive}
spells any of them with at most $\ell$ runs and largest prime
$Q=O(\ell^{1/(1-\theta)})$, so each costs at most
$\ell\log Q=(1+o(1))\ell\log\ell/(1-\theta)$.  Hence at least
$\exp\bigl((1-\theta+o(1))\log8\cdot L/\log L\bigr)$ strings have cost at
most $L$, and Lemma~\ref{lem:count8} is tight to the factor $1-\theta$.  Any
argument that bounds behaviors by counting spellings is therefore capped at
\[
  \frac{1}{3(1-\theta)\log10},
\]
namely $0.2895$ on GRH and $0.3474$ at $\theta=\frac7{12}$.  Passing that
requires counting behaviors rather than spellings, that is, exploiting the
distinct Brainfuck programs that compute the same function.
\end{remark}

\begin{remark}[Where the two orders of magnitude are]\label{rem:gap}
Corollary~\ref{cor:chain} and Proposition~\ref{prop:floor} bracket the
constant of $\mathcal C_F(T)/(T\log T)$ between $1/(3\log10)=0.1447\ldots$
and $1.516/\log10=0.6583\ldots$ on GRH, a ratio of $9.1$.  It factors.
Since there are only $8^{\ell}$ programs of length $\ell$, a $T$-bit table
needs at least $T/3$ instructions, while Lemma~\ref{lem:group} emits
$1.516\,T$ of them: a factor of $4.5$.  The remaining factor of $2$ is
Lemma~\ref{lem:grh}: the walk pays $\log Q=2\log U$ per run because a
square-root gap squares the last prime, where gaps of size $\log p$ would
pay $\log U$.  Against the decision tree the first factor was $52.5$, so
the lookup takes most of what separated the two bounds.  Of the $1.516$,
one unit is the move onto each entry's cell and a half is the mark on each
set entry; nothing else reaches a fiftieth.  Lowering it further therefore
means storing more than one entry per cell, which costs a unary write, and
the remaining factor of $2$ is number theory.
\end{remark}

\section{Scope and reproducibility}

The theorem concerns source length.  It does not claim that factoring an
arbitrary $D$-digit integer is polynomial in $D$.  Generated programs form a
special family whose factors are enumerated directly; arbitrary balanced
semiprimes remain outside that guarantee.

The reference implementation uses segmented Eratosthenes enumeration and a
smallest-first product tree.  Executable checks cover generated-program
semantics, source sizes, and the finite identities used in the construction;
none is a premise of the language lower bound.

\paragraph{Data availability.}
No datasets were generated or analyzed in this study.
