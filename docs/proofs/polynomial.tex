\begin{abstract}
In the Polynomial esoteric programming language, the roots of an
integer polynomial encode the instructions of a one-register machine, while
the source text lists the polynomial's expanded coefficients.  We prove that
the worst-case text complexity of $n$-input Boolean functions is
$\Theta(T^2/\log T)$, where $T=2^n$ is the truth-table length: every table
has a Polynomial program of length $O(T^2/\log T)$, and some tables require
$\Omega(T^2/\log T)$ source characters in every program, independently of the
program's degree, operand signs, and additional roots.  The upper bound is
an explicit residual-DAG construction.  For the lower bound, a routing
argument forces $\Omega(T/\log T)$ distinct positive real roots in every
program for a suitable table, with no assumption on the number of reads, and
a coefficient-mass theorem, proved separately, shows that a real polynomial
divisible by $L$ distinct prime-power roots and having leading coefficient
of absolute value at least one has logarithmic coefficient mass
$\Omega(L^2\log L)$.  Tracking the constants, the worst-case length $C_P(n)$
satisfies
$3\log_{10}2\le\liminf C_P(n)\,n/T^2\le\limsup C_P(n)\,n/T^2\le\tfrac{325}8\log_{10}2$:
the order is settled, but the constant is determined only up to a factor of
about $13.5$.
\end{abstract}

\noindent\textbf{Keywords.} Descriptional complexity; Boolean functions;
ordered binary decision diagrams; polynomial roots; esoteric programming
languages.

\section{The language and the result}\label{sec:model}

A Polynomial source is the expanded form
\[
  f(x)=\sum_{j=0}^{D} f_jx^j,\qquad f_j\in\Z.
\]
It is serialized as \texttt{f(x) = } followed by nonzero monomials in
descending degree, with decimal coefficients and exponents, as in the
language specification~\cite{polynomial-spec}; whitespace is permitted
between tokens.  Throughout, ``program'' means a source in this specified
expanded form; permissive implementation extensions are outside the model.
The interpreter factors $f$ over the integers and orders the recognized
roots by their associated primes.  A positive real root $p^v$ encodes a
control-flow instruction; a conjugate pair $a\pm p^b i$ encodes a register
instruction.  Unrecognized roots are ignored, so a source may be any integer
multiple of the product of its instruction factors.  Repeated recognized
roots produce repeated instructions.

As a minimal example, $f(x)=x^2+4$ has roots $\pm2i$.  The imaginary
magnitude $2=2^1$ selects the first register instruction for the prime $2$,
while the real part $0$ supplies its operand.  This instruction outputs the
initial register value, the zero byte.  In general the interpreter follows
the same pipeline:
\[
 \text{expanded coefficients}\longrightarrow
 \text{recognized roots}\longrightarrow
 \text{sorted instructions}\longrightarrow
 \text{execution}.
\]

The machine has an integer register and an instruction cursor.  Its input
instruction overwrites the register with the next input symbol, $48+b$ for a
Boolean bit $b$.  Real-root instructions are the bracket-like control-flow
operations; complex-root instructions update the register.  The upper bound
uses input, output, addition and multiplication by an integer, integer floor
division, and ``if positive'' with its closing instruction; the sharper
constants of Section~\ref{sec:constants} also use the remainder, the tests
``negative'' and ``zero'', and a loop.  The lower bound
uses only the following structural properties.

\begin{enumerate}
\item Input is consumed as an ordered stream: the $j$-th read instruction
receives the $j$-th input bit, whatever the path taken.
\item Between two input reads the complete state is the pair consisting of
the register and the instruction cursor.
\item Each real instruction root is one of the first eight positive powers of
its associated prime.  One prime may supply several consecutive positions.
\item Equal real roots occur in one contiguous block after root sorting.
\item The bracket matching is noncrossing.
\item An input instruction has the purely imaginary roots $\pm ci$ with
$c=p^b$, $p$ prime, $2\le b\le6$, and equal roots of every kind, not only
real ones, occur in one contiguous block after root sorting.
\end{enumerate}

For Boolean computation, put $T=2^n$ and supply each bit as a separate line
containing its ASCII digit.  A program computes
$t=(t_0,\ldots,t_{T-1})\in\{0,1\}^{2^n}$ if, on every
$b_1\cdots b_n\in\{0,1\}^n$ in lexicographic order, it terminates and emits
exactly the character $t_{(b_1\cdots b_n)_2}$, with zero-based subscripts.
Reads consume the input stream in order; a read past its end stores $-1$.
A program may perform different numbers of reads on different inputs, and
may read past the end.  The upper-bound construction reads exactly $n$ bits
on every input, but the lower bound does not assume this.

The length $|f|$ is the total
number of characters in the shortest valid expanded serialization of $f$;
fixed punctuation and optional whitespace affect only lower-order terms.
Its coefficient-digit mass is
\[
  M(f)=\sum_{j:f_j\ne0}\bigl(1+\lfloor\log_{10}|f_j|\rfloor\bigr).
\]
Every nonzero coefficient appears in a monomial whose serialization supplies
at least $1+\lfloor\log_{10}|f_j|\rfloor$ characters, so $|f|\ge M(f)$.
The worst-case text complexity $C_P(n)$ is the maximum, over these tables, of
the minimum $|f|$ of a program computing the table.
All unqualified logarithms are natural.

\begin{theorem}[Main theorem]\label{thm:main}
Every $n$-input Boolean function has a Polynomial program of length
$O(T^2/\log T)$, and there are $n$-input Boolean functions for which every
program has length $\Omega(T^2/\log T)$.  Hence the
worst-case text complexity in the model of Section~\ref{sec:model} is
$C_P(n)=\Theta(T^2/\log T)$.
\end{theorem}

The theorem concerns source length, not the running time of polynomial
factorization or of source generation.  It allows arbitrary degrees,
arbitrary operand signs, repeated roots, and arbitrary unrecognized cofactor
roots, and its upper half is an existence statement for the uncapped
residual-DAG construction; implementation resource limits do not affect it.

The lower bound has two independent parts.  Section~\ref{sec:routing} shows
that a short instruction alphabet cannot distinguish enough residual truth
tables, so a suitable table forces $\Omega(T/\log T)$ distinct positive real
roots.  Section~\ref{sec:mass} applies the coefficient-mass theorem
of~\cite{coefficient-mass}: supporting that many roots forces
$\Omega(T^2/\log T)$ coefficient digits.  Section~\ref{sec:upper} supplies
the matching construction, and Section~\ref{sec:constants} tracks the
constants through both halves (Proposition~\ref{prop:bracket}):
\[
  3\log_{10}2\le\liminf_{n\to\infty}\frac{C_P(n)\,n}{T^2}
  \le\limsup_{n\to\infty}\frac{C_P(n)\,n}{T^2}
  \le\frac{325}{8}\log_{10}2 .
\]
Remark~\ref{rem:bracket} locates the gap between the two sides.

Residual DAGs are reduced ordered binary decision diagrams under a fixed
variable order~\cite{bryant}; classical results place the size of an optimal
diagram for almost every Boolean function at the same
$\Theta(T/\log T)$ scale~\cite{wegener,gps}.  Here the input stream fixes the
order, and Lemma~\ref{lem:maximal-width} uses a tailored width statistic,
the number of first-essential residuals at one level, which the
next-read argument (Theorem~\ref{thm:count}) translates into distinct
Polynomial roots.  The
certificate machinery relates the displaced-zero comparison and
coefficient-order statistics to the reduced-height
literature~\cite{coefficient-mass}.

\section{Routing forces distinct roots}\label{sec:routing}

The $k$th read of every execution receives the $k$th input bit $b_k$.  After
$k$ reads the prefix $b_1\cdots b_k$ therefore determines a residual Boolean
function of the remaining $n-k$ bits: in the truth table, the block of
$2^{n-k}$ consecutive entries indexed by the prefix.  Only this natural
variable order matters.  Call a function $g(y_1,\ldots,y_m)$
\emph{first-essential} if it depends on $y_1$ and is not a function of $y_1$
alone, and write $N^*(k)$ for the number of distinct first-essential
residuals at level $k$.

\begin{lemma}[Maximal-width tables]\label{lem:maximal-width}
Let $n\ge2$.  For $2\le j\le n$ put $q_j=2^{n-j}$ and
$E_j=2^{2^j}-2^{2^{j-1}}-2$, and let
$N_n=\max_{2\le j\le n}\min(q_j,E_j)$.  Some $n$-input truth table has
$N^*(K)=N_n$ at a level $K\le n-2$, and
\begin{equation}\label{eq:residual-width}
  N_n\ge\frac{T}{4n}=\Omega\!\left(\frac{T}{\log T}\right).
\end{equation}
\end{lemma}

\begin{proof}
Fix a maximizing $j$ and put $K=n-j\le n-2$.  The level-$K$ residuals are
the $q_j$ consecutive blocks of length $2^j$, and they may be prescribed
independently.  A string of that length fails to be first-essential exactly
when its halves are equal ($2^{2^{j-1}}$ strings) or are distinct constants
(two strings), so $E_j$ strings are first-essential.  Prescribing
$\min(q_j,E_j)$ distinct first-essential blocks, and the remaining blocks
arbitrarily, gives $N^*(K)=N_n$.

For~\eqref{eq:residual-width} take $j=\lceil\log_2n\rceil+1$, which lies in
$[2,n]$.  Since $2^j\ge2n$,
$E_j\ge2^{2^j-1}-2\ge2^{2n-1}-2\ge2^n\ge q_j$, so
$N_n\ge q_j\ge2^{n-\log_2n-2}=T/(4n)$.
\end{proof}

We call such a table, together with its level $K$, \emph{maximal-width}.
Since $q_j$ doubles with $n$, $N_n$ is nondecreasing in $n$; for instance
$N_6=10$.

Besides the properties listed in Section~\ref{sec:model} we use two facts about the
decoded instruction list.  A \emph{register instruction} (a conjugate pair
$a\pm p^bi$) never moves the cursor except by one step; among them, the
\emph{reads} ($a=0$, $b\ge2$) overwrite the register with the next input
symbol and the \emph{prints} ($a=0$, $b=1$) emit a character.  Equal roots
sort into consecutive positions, so the positions of one input root value
form a run of consecutive reads, and the positions of one real root value a
run of consecutive control-flow instructions.  Call a maximal run of
consecutive register instructions a \emph{gap}, and a maximal run of
consecutive real instructions a \emph{real run}.  Gaps and real runs
alternate along the list.

For a cursor $c$ holding a read and $m\ge0$, let $H^{(m)}_c$ be the function
of $y\in\{0,1\}^m$ that the machine prints when started at $c$ on the input
stream $y$ followed by end of input, with any register value.  It does not
depend on that value, because the read at $c$ overwrites it.

\begin{lemma}[Next read]\label{lem:nextread}
Let $k\le n-2$, and let the residual $g$ after the prefix $b_1\cdots b_k$ be
first-essential.  Then
\begin{enumerate}
\item every input extending the prefix makes a $(k+1)$st read, at one
common cursor $c$, and prints nothing before it;
\item $g=H^{(n-k)}_c$;
\item $c$ is the last read of its gap, and a real instruction follows that
gap.
\end{enumerate}
\end{lemma}

\begin{proof}
Between the $k$th and the $(k+1)$st read the run consumes no input, so up to
the $(k+1)$st read it is the same for every extension of the prefix.  If it
halted or printed there, $g$ would be constant, since a program computing
the table prints exactly one character.  This proves~(1), and~(2) follows
because the state before the read at $c$ is $(c,r)$ for some register $r$,
which the read overwrites.

For~(3), let $y_1,y_2$ be the next two input bits, which exist as
$k\le n-2$.  After the read at $c$ the state is $(c+1,48+y_1)$.  Suppose the
instructions $c+1,c+2,\ldots$ are register instructions up to a read $c'$ or
to the end of the list.  They are executed in order for both values of
$y_1$; a fault among them would occur on a reachable input, so there is
none.  If one of them prints, that character is the program's output, and
$g$ is a function of $y_1$ alone.  Otherwise the run reaches $c'$, whose
read overwrites the register, and $g(y_1,\ldots)=H^{(n-k-1)}_{c'}$ does not
depend on $y_1$; or it reaches the end without printing, which a program
computing the table does not do.  Each case contradicts first-essentiality.
So a real instruction occurs after $c$, and no read lies between them.
\end{proof}

\begin{theorem}[First-essential count]\label{thm:count}
Let a decoded program contain $K_{\mathrm{in}}$ distinct input root values and $L$
distinct real root values, and let $G$ be the number of gaps that contain a
read and are followed by a real instruction.  Then for every $k\le n-2$
\[
  N^*(k)\ \le\ G\ \le\ \min(K_{\mathrm{in}},L).
\]
\end{theorem}

\begin{proof}
By Lemma~\ref{lem:nextread}(2) the first-essential residual after a prefix
of length $k$ is determined by the cursor $c$ of the $(k+1)$st read, so
distinct first-essential residuals at level $k$ have distinct cursors.  By
part~(3) each such cursor is the last read of a gap of the kind counted by
$G$, and a gap has only one last read.  This proves $N^*(k)\le G$.

The last read of a gap lies in a run of equal input roots, and that run lies
inside the gap; different gaps therefore give different input root values,
so $G\le K_{\mathrm{in}}$.  The real instruction after a counted gap begins a real run,
which consists of whole runs of equal real roots; different gaps are
followed by different real runs, so $G\le L$.
\end{proof}

\begin{corollary}\label{cor:roots}
Every Polynomial program for a maximal-width truth table has at least $N_n$
distinct input root values and at least $N_n$ distinct positive real
instruction roots.
\end{corollary}

\begin{proof}
Lemma~\ref{lem:maximal-width} gives a level $K\le n-2$ with $N^*(K)=N_n$;
apply Theorem~\ref{thm:count}.
\end{proof}

Indexing a residual by the cursor of the $k$th read instead would lose a
factor: the register still carries the bit just read, so one cursor could
carry two residuals, and the reads before it one more.  The $(k+1)$st read
erases that bit.  Noncrossing of the brackets is not used.

\begin{remark}[Gaps]\label{rem:gaps}
The first gap of the list can be entered only from the initial state, since
every jump lands just after a real instruction.  Its reads are therefore
the first reads of every input, and if the $(k+1)$st read lies there, then
$N^*(k)\le1$.  So $N^*(k)\le G-1$ whenever $N^*(k)\ge2$ and the first gap
contains a read.  A loop that reads an input-dependent number of bits is
covered too: its first-essential residuals are indexed by the next read, not
by the offset of the current one.
\end{remark}

\begin{lemma}[Prime powers]\label{lem:ppow}
Let $v_1<v_2<\cdots$ enumerate $\{p^b:p\text{ prime},\ b\ge2\}$.  Then
$v_j\ge(j+2)^2/4$ for every $j$.
\end{lemma}

\begin{proof}
The map $p^b\mapsto(p^{\lfloor b/2\rfloor},\,b\bmod2)$ is injective, since
$p^{\lfloor b/2\rfloor}$ is a prime power with exponent at least $1$ and so
determines $p$ and $\lfloor b/2\rfloor$.  Its first component lies in
$[2,\sqrt{p^b}]$.  So at most $2(\lfloor\sqrt X\rfloor-1)$ elements are at
most $X$.  Taking $X=v_j$ gives $j\le2(\sqrt{v_j}-1)$.
\end{proof}

The bound of Theorem~\ref{thm:count} is attained exactly, at the width
$\Theta(T/\log T)$ that matters for the bracket.  The same example shows
that one input root can carry first-essential residuals at many levels.

\begin{proposition}[Sharpness]\label{prop:sharp}
Let $K\ge6$, $Z=2^K-1$, let $W=2^m$ be the least power of two with
$W\ge3K+6$, and $n=K+m$.  There is a labelling
$\lambda:\Z/Z\Z\to\{0,1\}$ such that the table
\[
  f(X)=\lambda(X\bmod Z),\qquad X\in\{0,\dots,2^n-1\}\text{ read in binary},
\]
has a Polynomial program with exactly $Z$ input instructions, and
\[
  N^*(K)=Z=K_{\mathrm{in}},\qquad N^*(k)=2^k\ (k<K),\qquad
  \sum_{k\le K}N^*(k)=2K_{\mathrm{in}} .
\]
Moreover $N^*(K)>T/(6n)-1$.
\end{proposition}

\begin{proof}
\emph{The automaton.}  On the states $\Z/Z\Z$ let
$\delta(s,b)=2s+b\bmod Z$.  From $s_0=0$ the prefix $x$ of an input leads
to $x\bmod Z$, where $x$ is read as a binary number, and after all $n$ bits
the label $\lambda$ of the final state is $f$.  For $k\le K$ the prefixes
of length $k$ reach the $2^k$ states $0,\ldots,2^k-1$ when $k<K$, and every
state when $k=K$ (the prefixes $0^K$ and $1^K$ both reach $0$).  The
residual at a state $s$ reached at level $K$ is the window
$\omega_s(z)=\lambda(2^ms+z)$, $0\le z<W$, indices mod~$Z$.

\emph{The program.}  Keep the register equal to $-(s+1)$ while state $s$ is
active, inside a loop $\text{while}<0\,\{B_0\cdots B_{Z-1}\}$ entered after
$\mathord{+}\!=-1$.  Block $B_i$ is
\[
  \mathord{+}\!=1,\ \text{if}{=}0\,\{\ \text{input},\
  \text{if}<0\{\mathord{\%}\!=1,\ \mathord{+}\!=P_i\},\
  \mathord{-}\!=50,\ \text{if}<0\{\mathord{*}\!=A_i,\ \mathord{+}\!=B_i\}\ \},
\]
and after the loop come $\mathord{\%}\!=2$, $\mathord{+}\!=48$ and a print
(an operand-zero update is omitted).  Entering the loop body with
register $-(s+1)$, the register before the test of $B_i$ is $i-s$, so only
$B_s$ fires.  A bit $b$ becomes $-2$ or $-1$ after $\mathord{-}\!=50$, and
$A_i,B_i$ are chosen so that it becomes
$w_b=-(\delta(i,b)+1)-(Z-1-i)$ (if $\delta(i,0)=\delta(i,1)$, use
$\mathord{\%}\!=1$ and add the common value).  The later blocks add
$Z-1-i$ and never see zero, so the loop restarts with $-(\delta(i,b)+1)$.
End of input stores $-1$, which the inner test replaces by
$P_i=M+\varepsilon_i$ with $M>50$ and $\varepsilon_i\in\{0,1\}$ chosen so
that $P_i-50+Z-1-i\equiv\lambda(i)\pmod2$.  That value stays positive, skips
every later block, leaves the loop, and prints $48+\lambda(i)$.  There is one
input instruction per block, in different gaps, so $K_{\mathrm{in}}=Z$.

\emph{The labels.}  Take $\lambda$ uniformly at random.  Since $2^m$ is
invertible mod the odd number $Z$, the starts $a_s=2^ms$ are distinct.  For
$s\ne s'$ put $d=a_{s'}-a_s\ne0$.  The event $\omega_s=\omega_{s'}$ imposes
$\lambda(v)=\lambda(v+d)$ for the $W\le Z$ vertices $v=a_s+z$.  These are
$W$ distinct edges of the graph $\{v,v+d\}$ on $\Z/Z\Z$, a disjoint union
of cycles of length $Z/\gcd(d,Z)\ge3$.  A set of edges has rank equal to its
size minus the number of whole cycles it contains, so the rank is at least
$\frac23W$ and the probability is at most $2^{-2W/3}$.  In the same way a
window has equal halves with probability at most $2^{-W/3}$, and two
constant halves with probability $2^{2-W}$.  With $Z<2^K$ and
$W\ge3K+6$,
\[
  \binom Z2 2^{-2W/3}+Z\bigl(2^{-W/3}+2^{2-W}\bigr)
  <2^{-5}+2^{-2}+2^{-4}<1,
\]
so some $\lambda$ makes all $Z$ windows distinct and first-essential; the
condition $W\le Z$ holds because $W<6K+12\le2^K-1$ for $K\ge6$.  Then
$N^*(K)=Z$.

For $k<K$ the residual at $y\in\{0,\ldots,2^k-1\}$ is the concatenation,
in order of $z\in\{0,1\}^{K-k}$, of the windows at the states
$2^{K-k}y+z\bmod Z$.  For $y\ne y'$ and each $z$ these states differ, since
$2^{K-k}(y-y')\not\equiv0\pmod Z$, so the windows differ and so do the
residuals.  The two halves of the residual at $y$ are those at $2y$ and
$2y+1$ (single windows when $k=K-1$), which differ and are nonconstant, so
the residual is first-essential.  Hence $N^*(k)=2^k$ and
$\sum_{k\le K}N^*(k)=2^K-1+Z=2Z$.  Finally $K\le n-2$, and
$T=2^K W<(Z+1)(6K+12)\le6n(Z+1)$.
\end{proof}

Call a gap that contains a read a \emph{read gap}.  The first read reached
after any configuration is the first read of some read gap: every jump, and
every step past a real instruction, lands on the instruction after a real
instruction, so a gap is always entered at its first instruction and then
run straight through.

\begin{lemma}[Gap automaton]\label{lem:gapauto}
Let $\Gamma$ be the set of read gaps of a program that computes an
$n$-input table, and put $\mathrm{Out}=\{\mathtt0,\mathtt1,\bot\}$.  The table
is determined by the following data: an entry $e\in\Gamma\cup\mathrm{Out}$,
and for each $g\in\Gamma$ a number $m_g\in\{1,\dots,n+1\}$, two targets
$\delta_g(0),\delta_g(1)\in\Gamma\cup\mathrm{Out}$ and a label
$\lambda_g\in\mathrm{Out}$.  The semantics: at a gap $g$ with $\pi$ bits
consumed, move to $\delta_g(b)$ with $\pi+m_g$ bits consumed, where
$b=b_{\pi+m_g}$, if $\pi+m_g\le n$; otherwise stop with output $\lambda_g$.
\end{lemma}

\begin{proof}
Let $r_1<\dots<r_k$ be the reads of $g$.  Let $m_g$ be the least $i$ such
that a print lies between $r_i$ and $r_{i+1}$ (or after $r_k$ in the gap), and
$m_g=k$ if there is none; replace it by $\min(m_g,n+1)$.  If $m_g<k$, the
print after $r_{m_g}$ is executed on every path through it, so the output is
decided there: set $\delta_g(b)$ and $\lambda_g$ to the character it prints
from the read values $48+b$ and $-1$ ($\bot$ on a fault).  If $m_g=k$, run
the program from the instruction after $r_k$ with register $48+b$ (or $-1$)
until the first read or print: $\delta_g(b)$ (or $\lambda_g$) is the read
gap whose first read is reached, or the printed character, or $\bot$.  The
entry $e$ is defined in the same way from the initial configuration.

A read overwrites the register, and the reads before $r_{m_g}$ are followed
by straight-line code without prints, so from the first read of $g$ the run
depends only on the value read at $r_{m_g}$; that is the value
$48+b_{\pi+m_g}$, or $-1$ once the input is exhausted.  A program that
computes the table never faults and prints exactly once on an input, so
every configuration it reaches is described correctly by these data, and
its output is the first printed character.
\end{proof}

\begin{proposition}[Counting]\label{prop:counting}
For $n\ge7$ some $n$-input table has no program with fewer than $T/(n+4)$
distinct input root values.  More precisely, let $Z_n$ be the largest $Z$ with
\[
  B_n(Z)=\frac{(Z+1)(Z+3)\,\bigl(3(n+1)\bigr)^Z(Z+3)^{2Z}}{Z!}<2^T;
\]
then some table needs at least $Z_n+1$ input root values, and
$Z_n+1>T/(n+4)$.
\end{proposition}

\begin{proof}
Restrict the data of Lemma~\ref{lem:gapauto} to the read gaps reachable from
$e$ through the $\delta_g$; the table is still determined.  With $z$
reachable gaps numbered $1,\dots,z$ there are at most
$t_z=(z+3)\bigl(3(n+1)(z+3)^2\bigr)^z$ such data.  Renumbering the gaps
does not change the table, and a renumbering that fixes the data fixes every
gap reachable from $e$, hence is the identity; so the $z!$ renumberings of
one set of data are distinct, and at most $t_z/z!$ tables arise from $z$
reachable gaps.  The ratio of consecutive terms is at least
$3(n+1)(z+4)^2/(z+1)>1$, so programs with at most $Z$ read gaps compute at
most $B_n(Z)$ tables.  If $B_n(Z)<2^T$, some table needs more than $Z$ read
gaps.  The last reads of distinct read gaps have distinct root values, as in
the proof of Theorem~\ref{thm:count}, so that table needs at least $Z+1$
input root values.

For the estimate let $Z=\lfloor T/(n+4)\rfloor$.  From $Z!\ge(Z/e)^Z$ and
$(1+3/Z)^{2Z}\le e^6$,
\[
  \log_2B_n(Z)\le 2\log_2(Z+3)+6\log_2e+Z\log_2\bigl(3e(n+1)Z\bigr).
\]
Here $3e(n+1)Z\le3e\,2^n(n+1)/(n+4)<3e\,2^n$, so the last term is less than
$Z(n+\log_2 3e)\le T-(4-\log_23e)\,T/(n+4)$, and $4-\log_23e>0.97$.  For
$n\ge9$, $0.97\,T/(n+4)>2n+6\log_2e\ge2\log_2(Z+3)+6\log_2e$, so
$B_n(Z)<2^T$ and $Z_n\ge Z$.  For $n=7,8$ exact computation gives
$Z_7=12$ and $Z_8=22$, above $128/11$ and $256/12$.
\end{proof}

Proposition~\ref{prop:counting} needs neither Lemma~\ref{lem:maximal-width}
nor Theorem~\ref{thm:count}; it is the counting argument with the
relabelling symmetry.  Asymptotically $Z_n=T/(n+\log_23e+o(1))$, and exact
values are $Z_{12}=274$ and $Z_{16}=3470$, against $N_{12}=256$ and
$N_{16}=4096$.  Since $N_n=\nu_nT/n\,(1+o(1))$ with $\nu_n\in(\frac12,1+o(1)]$,
the counting bound is the larger one for most $n$, by up to a factor $2$.

\begin{remark}[Levels]\label{rem:levels}
In Proposition~\ref{prop:sharp} the state $s$ is reached at every level
from the bit length of $s$ up to $n$, and it carries a first-essential
residual at every such level up to $K$ (and, when its shorter windows are
distinct, beyond).  For instance the state $1$ is reached at every level $k\ge1$, by
$0^{k-1}1$, and carries a first-essential residual at each $k\le K$: a single
input root serves $K=n-\Theta(\log n)$ levels, and no inequality
$\sum_{k\le K}N^*(k)\le cK_{\mathrm{in}}$ with $c<2$ holds in general.  The same
happens for the maximal-width tables that the lower bound uses: a SAT
search for the smallest automaton that agrees with the table on
$\{0,1\}^n$, compiled as above and run on every input, gives programs with
$K_{\mathrm{in}}=9$ against $\sum_kN^*(k)=15$ and a leveled residual DAG of $21$
states ($n=5$, minimum proved), and $K_{\mathrm{in}}=15$ against $24$ and $33$
($n=6$).  The minimum input count of a table therefore lies between its
largest first-essential width and the size of its smallest such automaton,
and it is the latter, not the leveled DAG of the construction, that a
multi-level lower bound would have to reach.
\end{remark}

\begin{remark}[Levels and counting]\label{rem:levels-count}
Counting automata with $Z$ states gives about $2Z\log_2Z$ bits, but the
$Z!$ renumberings of one automaton compute the same table, and removing
them leaves $Z\log_2Z+O(Z\log n)$ bits.  So counting certifies about
$T/n$ read gaps (Proposition~\ref{prop:counting}), not $T/(2n)$.  This is
$N_n/\nu_n\ge N_n$, and the automata of Lemmas~\ref{lem:trieband}
and~\ref{lem:bandtrie} match it up to a factor $1+O((\log n)^2/n)$, for every table
(Proposition~\ref{prop:bracket}).
\end{remark}

\section{Coefficient mass from prescribed roots}\label{sec:mass}

Write
\[
  \Lambda(F)=\sum_{j:f_j\ne0}\log^+|f_j|,\qquad \log^+x=\max(0,\log x).
\]
The exponential-sum certificate machinery yields the following
degree-independent statement~\cite[Corollary~3.4]{coefficient-mass}.

\begin{theorem}[Coefficient-mass theorem]\label{thm:mass}
Let
\[
  P(x)=\prod_{i=1}^{L}(x-r_i),
  \qquad 2\le r_1\le\cdots\le r_L,
\]
with repetitions allowed, and let \(F(x)=\sum_{j=0}^{D}f_jx^j\in\R[x]\) be a
nonzero multiple of \(P\) with \(|f_D|\ge1\).  Then
\begin{equation}\label{eq:mass-general}
  \Lambda(F)
  \ge (L+1)\log|f_D| + \sum_{u=0}^{L-1}
       \sum_{i=u+1}^{L}\log(r_i-1).
\end{equation}
\end{theorem}

Each \(\log(r_i-1)\) occurs \(i\) times on the right.  For the first \(L\)
primes, or for increasing roots bounded below by them, \(r_i\ge i+1\) and
the right side is at least \((1/2+o(1))L^2\log L\).  This is asymptotically
sharp: \(\Lambda(P_L)\le(1/2+o(1))L^2\log L\) for
\(P_L=\prod_{i=1}^L(x-p_i)\).  The theorem applies to every real multiple,
independently of its degree and additional roots.

\begin{corollary}[Polynomial lower bound]\label{cor:lower}
Every Polynomial source for a maximal-width truth table has
\[
  |f|=\Omega(T^2/\log T).
\]
\end{corollary}

\begin{proof}
By Corollary~\ref{cor:roots}, the program contains
\(L=\Omega(T/\log T)\) distinct positive real instruction roots.  They are
distinct integers \(\ge2\), so after sorting \(r_i\ge i+1\), and the weighted
sum in Theorem~\ref{thm:mass} is at least
\(\sum_{i\le L}i\log i=(1/2+o(1))L^2\log L\).  The source polynomial
is an integer multiple of their distinct-root product and its leading
coefficient has absolute value at least one.  Theorem~\ref{thm:mass} gives
\[
 \Lambda(f)=\Omega(L^2\log L)
           =\Omega\!\left(\frac{T^2}{\log T}\right).
\]
Since integer coefficients satisfy
$M(f)\ge\Lambda(f)/\log 10$ and $|f|\ge M(f)$, the result follows.
\end{proof}

\begin{remark}[Repeated roots]
Repeated real roots do not weaken Corollary~\ref{cor:lower}:
Theorem~\ref{thm:count} already forces the stated number of distinct values,
and Theorem~\ref{thm:mass} is stated for roots counted with multiplicity.
\end{remark}

\section{The matching construction}\label{sec:upper}

The residual DAG of a truth table has at most
\[
  s_k=\min\bigl(2^k,2^{2^{n-k}}\bigr)
\]
states after $k$ reads: the first term counts input prefixes, and the second
counts Boolean residuals of the remaining width.  Put
$h=\lfloor\log_2 n\rfloor-1$.  The levels with $n-k\le h$ contribute
$O(\sqrt T)=O(T/n)$ states; the earlier levels form a geometric tail
of size $O(T/2^h)=O(T/n)$.  Hence
\[
  S\coloneqq\sum_k s_k=O(T/\log T).
\]

Label the states at every level by $0,\ldots,s_k-1$.  Enter level $k$ with
register $-j$ when state $j$ is active.  Its blocks are scanned in label
order: block $j$ increments the register and opens an ``if positive'', so
exactly block $j$ fires.  That block reads the next bit, overwriting the
register with $48+b$.  If its child labels are $z,o$, multiply by $z-o$ and
add $-(z+r)-48(z-o)$, where $r$ is the number of blocks remaining at that
level.  This sends $48$ to $-(z+r)$ and $49$ to $-(o+r)$.  The skipped blocks
each increment once, leaving $-z$ or $-o$ at the next level.  Equal children
instead floor-divide $48+b$ by $50$, obtaining zero, then add $-(z+r)$.  At
the leaf level the unique active block adjusts the register to $48$ or $49$,
prints, and leaves the register negative.

Thus induction on the levels proves that
the machine follows exactly the residual selected by the input and prints its
table value.  Each state block uses at most six instructions, its brackets
are local and therefore properly matched, and every operand is $O(S)$.  An
update whose operand would be zero is omitted: the language spells a zero
operand as I/O, and dropping it leaves the register unchanged, which is what
a zero update does.

Encode the resulting $m=O(S)$ instructions in order, using one fresh prime
per instruction.  Real instructions give linear factors and register
instructions conjugate quadratic factors; multiplying them gives an integer
polynomial decoded back to that list.  Instruction exponents are bounded
constants.  The prime number theorem~\cite{rs} gives the standard estimate
$p_m=O(m\log m)$ for the largest assigned prime.  Every
linear or quadratic factor therefore has
coefficient $\ell^1$ norm $m^{O(1)}$.  Submultiplicativity gives coefficient
norm $m^{O(m)}$ for their product, so each expanded coefficient has
$O(m\log m)$ decimal digits.  There are at most $2m+1$ coefficients, while
exponents and separators contribute only $O(m\log m)$.  Therefore
\[
  |f|=O(m^2\log m)
      =O\!\left(\frac{T^2}{\log T}\right).
\]
Together with Corollary~\ref{cor:lower}, this proves
Theorem~\ref{thm:main}.

The construction of Section~\ref{sec:upper} spends one state per residual
at every level.  A program can share states across levels, because its
state between reads is only the cursor of the next read.  The next lemma
is an explicit way to share them for every table.

Fix $d\ge1$ and a word $c\in\{0,1\}^d$.  Call a word \emph{canonical} if it
does not begin with $c$, and let $\operatorname{st}(w)$ be $w$ with its
leading copies of $c$ removed, so that $w=c^i\operatorname{st}(w)$ with
$\operatorname{st}(w)$ canonical and $i$ unique.  For a canonical $u$ with
$|u|\le n$ let $V(u)$ be the tuple of residuals of the table after the
prefixes $c^iu$, $0\le i\le(n-|u|)/d$: the $i$-th entry is a Boolean
function of $n-|u|-di$ bits, or a single table value when that number is
$0$.

\begin{lemma}[Stripped automaton]\label{lem:strip}
Let $d\le L\le n$.  For a word $w$ with $|w|\le n$ and $u=\operatorname{st}(w)$,
put $\sigma(w)=u$ if $|u|\le L$ and $\sigma(w)=(|u|,V(u))$ otherwise.  Then
$\sigma(wb)$ depends only on $\sigma(w)$ and $b$, and $\sigma(w)$ with
$|w|=n$ determines the table value at $w$.  So the values of $\sigma$ are
the states of an automaton that computes the table.  At level $\ell=|u|$
there are
\[
  \kappa_\ell=2^\ell-[\ell\ge d]\,2^{\ell-d}
\]
states $u$ with $\ell\le L$, and at most $\min\bigl(\kappa_\ell,2^{E_d(n-\ell)}\bigr)$
states $(\ell,V)$ with $\ell>L$, where
$E_d(m)=\sum_{0\le i\le m/d}2^{m-di}$.  A state at level $\ell$ is reached
only after $\ell+di$ bits, $i\ge0$, so only states with $d\mid n-\ell$ are
reached after $n$ bits.
\end{lemma}

\begin{proof}
Write $w=c^iu$.  If $|u|\ge d$, then $ub$ does not begin with $c$, since its
first $d$ letters are those of $u$; so $\operatorname{st}(wb)=ub$.  If
$|u|<d$, then $ub$ begins with $c$ only if $ub=c$, and then
$\operatorname{st}(wb)$ is empty; otherwise it is $ub$.  So
$\operatorname{st}(wb)$ is a function of $u$ and $b$, which settles the
states with $|u|\le L$ (note $L\ge d$).  If $|u|>L$, then
$\operatorname{st}(wb)=ub$ with $|ub|>L$, and the $i$-th entry of $V(ub)$,
the residual after $c^iub$, is the $i$-th entry of $V(u)$ restricted to
first bit $b$ (entries of length $0$ are dropped).  So
$(|ub|,V(ub))$ is a function of $(|u|,V(u))$ and $b$.  For $|w|=n$ we have
$i=(n-|u|)/d$, so $u$ determines $w$, and $V(u)$ contains the value at $w$
as its entry of length~$0$.  The counts are the number of canonical words
of length $\ell$ and the number of tuples of functions of
$n-\ell-di$ bits.
\end{proof}


In Lemma~\ref{lem:strip} a canonical word $u$ is reached after $|u|+di$ bits
for every $i$, so about a fraction $1/d$ of the tree can see the end of the
input.  Bounding the number of stripped copies removes this: the few words
that begin with many copies of $c$ are sent to a separate residual DAG.

\begin{lemma}[Bounded stripped automaton]\label{lem:bstrip}
Let $d\ge1$, $c\in\{0,1\}^d$, and let $L,I\ge0$ be integers with
$d\le L$ and $L+dI<n$.  For a word $w$ with $|w|\le n$ define $\tau(w)$ as follows.
\begin{enumerate}
\item If $w=c^ic'$ with $i\le I$ and $c'$ a proper prefix of $c$, then
$\tau(w)=(\mathrm{copy},i,|c'|)$.
\item If $w$ begins with $c^{I+1}$, then $\tau(w)=(\mathrm{tail},|w|,r_w)$, where $r_w$ is
the residual of the table after $w$.
\item Otherwise write $w=c^iu$ with $i\le I$ maximal; then $u$ is nonempty, does not
begin with $c$ and is not a prefix of $c$.  Put $\tau(w)=u$ if $|u|\le L$ (a
\emph{tree state}), and $\tau(w)=(|u|,V_I(u))$ if $|u|>L$ (a \emph{deep state}),
where $V_I(u)$ is the tuple of residuals after the prefixes $c^iu$, $0\le i\le I$,
$|c^iu|\le n$.
\end{enumerate}
Then $\tau(wb)$ depends only on $\tau(w)$ and $b$, and $\tau(w)$ with $|w|=n$ determines
the table value at $w$; so the values of $\tau$ are the states of an automaton that
computes the table.  Moreover:
\begin{enumerate}
\item[(a)] no tree state is $\tau(w)$ for a word $w$ of length $n$;
\item[(b)] if $u$ is a tree state with $|u|\ge2$ whose prefix $u^-$ of length $|u|-1$
is not a prefix of $c$, then $u^-$ is a tree state and $(u^-,b)$, with $b$ the last
letter of $u$, is the only pair of a state and a bit that the automaton sends to $u$;
and no pair is sent to the start state $\tau(\varepsilon)=(\mathrm{copy},0,0)$;
\item[(c)] there are at most $\kappa_\ell=2^\ell-[\ell\ge d]\,2^{\ell-d}$ tree states and
at most $\min\bigl(\kappa_\ell,2^{E_{d,I}(n-\ell)}\bigr)$ deep states $(\ell,V)$ at level
$\ell$, with $E_{d,I}(m)=\sum_{0\le i\le\min(I,m/d)}2^{m-di}\le E_d(m)$; there are
$d(I+1)$ copy states, and at most $S_{n'}+2$ tail states, where $n'=n-d(I+1)$ and
$S_m=\sum_{k<m}\min(2^k,2^{2^{m-k}})$.
\end{enumerate}
\end{lemma}

\begin{proof}
The three cases are disjoint: in case~1, $|w|<d(I+1)$, and in case~3, $u$ is not a
proper prefix of $c$ by exclusion of case~1 and is not empty, since $w=c^i$ with
$i\le I$ is in case~1.

\emph{Transitions.}  Let $w=c^ic'$ be in case~1, $|c'|=k$, and let $\gamma$ be the
$(k+1)$st letter of $c$.  If $b=\gamma$ and $k+1<d$, then $\tau(wb)=(\mathrm{copy},i,k+1)$;
if $b=\gamma$ and $k+1=d$, then $wb=c^{i+1}$, which is $(\mathrm{copy},i+1,0)$ for
$i<I$ and a tail state for $i=I$.  If $b\ne\gamma$, then $c'b$ is not a prefix of
$c$, does not begin with $c$, and has length at most $d\le L$, so
$\tau(wb)=c'b$.  In case~2, $wb$ is in case~2 and $r_{wb}$ is the half of $r_w$
selected by $b$.  In case~3, $wb=c^i(ub)$: if $|u|\ge d$, then $ub$ begins with
$c$ exactly when $u$ does, and if $|u|<d$, then $u$ differs from the prefix of $c$
of its length, and so does $ub$; either way $ub$ neither begins with $c$ nor is
a prefix of $c$, so $i$ is still the number of leading copies of $c$ in $wb$.
Hence $\tau(wb)=ub$ if $|u|<L$, and otherwise $\tau(wb)=(|u|+1,V_I(ub))$, where
$V_I(ub)$ arises from $V_I(u)$ by restricting every entry to first bit $b$ and
dropping the entries of length $0$.  In every case $\tau(wb)$ is a function of
$\tau(w)$ and $b$.

\emph{Values.}  Let $|w|=n$.  In case~1 the state determines $w$.  In case~2
the residual $r_w$ is the value.  In case~3, $|u|=n-di\ge n-dI>L$, which proves~(a),
and the entry of $V_I(u)$ with $|c^iu|=n$ is the value; it is identified by its
index $i=(n-|u|)/d$.

(b)  If the automaton sends $(s,b')$ to $u$, then $s=\tau(w')$ and
$\tau(w'b')=u$ for some $w'$, so $w'b'=c^iu$ with $i$ maximal, $b'=b$ and
$w'=c^iu^-$.  The word $u^-$ is nonempty, is not a prefix of $c$ by hypothesis,
and does not begin with $c$ (if $|u^-|\ge d$ it begins with $c$ exactly when $u$
does); so $\tau(w')=u^-$.  No word $w'b'$ has $\tau(w'b')=\tau(\varepsilon)$,
since $\tau(v)=(\mathrm{copy},0,0)$ only for $v=\varepsilon$.

(c)  Tree states at level $\ell$ are words of length $\ell$ that do not begin with
$c$.  A deep state at level $\ell$ is determined by a word $u$ of that kind, and also
by a tuple of Boolean functions of $n-\ell-di$ bits.  A tail state $(k,r)$ has
$k\ge d(I+1)$, and $r$ is determined by the last $k-d(I+1)$ letters of the word and
is a function of $n-k$ bits; so there are at most
$\min(2^{k-d(I+1)},2^{2^{n-k}})$ of them at each $k$, which sums to at most
$S_{n'}+2$.
\end{proof}

Lemma~\ref{lem:bstrip} lets one tree stand for the prefixes $c^iu$, $i\le I$.  A deep
state just below the tree then records $2^{n-L-1}(1-2^{-d(I+1)})/(1-2^{-d})$ bits, and the
tree must be deep enough that this number stays below $L$.  Few such numbers are
available, and where none of them lies just below $L$ the tree is up to twice as deep as
needed; this is why the bracket used $\frac32T/n$ states when $N_n$ is close to $T/n$.
The next lemma lets any leaves of a trie share one tree, as long as their lengths differ.
The number of recorded bits is then a sum of distinct powers of two, which can be placed
just below the depth of the tree for every $n$.

\begin{lemma}[Trie-banded automaton]\label{lem:trieband}
Let $\mathcal T$ be a finite set of words of length less than $n$ that contains the empty
word and, with every nonempty word, its prefix of length one less.  A \emph{leaf} is a
word $\ell\notin\mathcal T$ whose prefix of length $|\ell|-1$ lies in $\mathcal T$.  Let
the leaves be split into a set $\Lambda_0$ of \emph{tail roots} and \emph{bands}
$\Lambda_1,\dots,\Lambda_K$, where the leaves of one band have distinct lengths, and let
$L_1,\dots,L_K\ge0$ satisfy $|\ell|+L_k<n$ for $\ell\in\Lambda_k$.  Every word
$w\notin\mathcal T$ has exactly one leaf as a prefix; write $w=\ell v$.  For $|w|\le n$ put
\[
 \tau(w)=\begin{cases}
 w & \text{if }w\in\mathcal T\ \text{(a \emph{trie state})},\\
 (\mathrm{tail},|w|,r_w) & \text{if }\ell\in\Lambda_0,\\
 (k,v) & \text{if }\ell\in\Lambda_k,\ |v|\le L_k\ \text{(a \emph{tree state})},\\
 (k,|v|,V_k(v)) & \text{if }\ell\in\Lambda_k,\ |v|>L_k\ \text{(a \emph{deep state})},
 \end{cases}
\]
where $r_x$ is the residual of the table after $x$, and $V_k(v)$ is the tuple of the
residuals $r_{\ell'v}$, indexed by the leaves $\ell'\in\Lambda_k$ with $|\ell'v|\le n$.
Then $\tau(wb)$ depends only on $\tau(w)$ and $b$, and $\tau(w)$ with $|w|=n$ determines
the table value at $w$; so the values of $\tau$ are the states of an automaton that
computes the table.  Moreover:
\begin{enumerate}
\item[(a)] no trie or tree state is $\tau(w)$ for a word $w$ of length $n$;
\item[(b)] if $u$ is a trie state other than the start state $\tau(\varepsilon)=\varepsilon$,
or a tree state $(k,v)$ with $|v|\ge1$, then exactly one pair of a state and a bit is sent
to $u$, namely $(u^-,b)$, respectively $((k,v^-),b)$, where $x^-$ is $x$ without its last
letter $b$; and no pair is sent to $\varepsilon$;
\item[(c)] for $\lambda\le L_k$ there are $2^\lambda$ tree states $(k,v)$ with
$|v|=\lambda$; for $\lambda>L_k$ there are at most $\min\bigl(2^\lambda,2^{e_k(\lambda)}\bigr)$
deep states $(k,\lambda,V)$; and for every $\lambda$ there are at most
$\min\bigl(t(\lambda),2^{2^{n-\lambda}}\bigr)$ tail states $(\mathrm{tail},\lambda,r)$, where
\[
 e_k(\lambda)=\sum_{\ell\in\Lambda_k,\ |\ell|+\lambda\le n}2^{\,n-|\ell|-\lambda},
 \qquad
 t(\lambda)=\sum_{\ell\in\Lambda_0,\ |\ell|\le\lambda}2^{\lambda-|\ell|}.
\]
\end{enumerate}
\end{lemma}

\begin{proof}
\emph{Leaf prefixes.}  The prefixes of $w$ that lie in $\mathcal T$ are those of length at
most some $t$, because $\mathcal T$ contains $\varepsilon$ and is closed under deleting the
last letter, and $t<|w|$ as $w\notin\mathcal T$.  A leaf that is a prefix of $w$ is not in
$\mathcal T$ while its prefix of length one less is, so its length is $t+1$; and the
prefix of length $t+1$ is a leaf.

\emph{Transitions.}  Let $w\in\mathcal T$.  Then $wb$ is a trie state or a leaf, and in
the second case $\tau(wb)$ is $(\mathrm{tail},|wb|,r_{wb})$ or $(k,\varepsilon)$; either
way it is a function of $w$ and $b$.  Let $w=\ell v\notin\mathcal T$; then $wb=\ell(vb)$
has the same leaf.  If $\ell\in\Lambda_0$, then $r_{wb}$ is the half of $r_w$ selected by
$b$.  If $\ell\in\Lambda_k$ and $|v|<L_k$, then $\tau(wb)=(k,vb)$.  If $|v|\ge L_k$, then
$\tau(wb)=(k,|v|+1,V_k(vb))$, and $V_k(vb)$ arises from the residuals $r_{\ell'v}$ by
restricting each to first bit $b$ and dropping those with $|\ell'v|=n$; these residuals
are the entries of $V_k(v)$ if $|v|>L_k$, and are determined by $v$ if $|v|=L_k$, where
the state is $(k,v)$.

\emph{Values.}  Let $|w|=n$; then $w\notin\mathcal T$.  If $\ell\in\Lambda_0$, the
residual $r_w$ is the value.  If $\ell\in\Lambda_k$, then $|v|=n-|\ell|>L_k$, so $\tau(w)$
is a deep state.  Its tuple contains the value $r_{\ell v}$ at the index $\ell$, and $\ell$
is the only leaf of $\Lambda_k$ of length $n-|v|$, because the leaves of a band have
distinct lengths.  This proves the claim and~(a).

(b)  If $\tau(w'b')=u\in\mathcal T$, then $w'b'=u$, so $b'=b$ and $\tau(w')=u^-$.  If
$\tau(w'b')=(k,v)$ with $|v|\ge1$, then $w'b'=\ell v$ with $\ell\in\Lambda_k$, so $b'=b$
and $w'=\ell v^-$, whose leaf is $\ell$; hence $\tau(w')=(k,v^-)$.  Finally
$\tau(x)=\varepsilon$ only for $x=\varepsilon$.

(c)  The tree states of band $k$ at level $\lambda$ are the pairs $(k,v)$ with
$|v|=\lambda$.  A deep state $(k,\lambda,V)$ is determined by a word $v$ of length
$\lambda$, and also by $V$, a tuple of Boolean functions of $n-|\ell|-\lambda$ bits,
$\ell\in\Lambda_k$.  A tail state $(\mathrm{tail},\lambda,r)$ is determined by a word of
length $\lambda$ that begins with a tail root, the tail roots being no prefixes of each
other, and also by $r$, a function of $n-\lambda$ bits.
\end{proof}

The bands are filled by building the trie level by level.

\begin{lemma}[Band tries]\label{lem:bandtrie}
Let $r\ge1$, $J\subseteq\{1,\dots,r\}$ and $m=|J|+1$, and let $t_0\ge1$ and
$A\ge t_0+r+1$ be integers.  There are a set $\mathcal T$ as in Lemma~\ref{lem:trieband},
whose words have length less than $A$, and a split of its leaves into tail roots and
bands, such that
\begin{enumerate}
\item every band consists of one leaf of some length $s$ with $t_0<s\le A-r$ and, for
every $j\in J$, one leaf of length $s+j$;
\item the tail roots have length $A$, and their number $N_A$ satisfies
$2^{-A}N_A<\bigl(1-\frac1{2m}\bigr)^{A-r-t_0}+2^{-t_0}$;
\item $|\mathcal T|<2^A$, and there are fewer than $2^A$ bands.
\end{enumerate}
\end{lemma}

\begin{proof}
Put $N_0=1$, and for $s=1,\dots,A$ in turn let $B_s=D_s=0$ if $s\le t_0$, and otherwise
\[
 D_s=\sum_{j\in J,\ s-j>t_0}B_{s-j},\qquad
 B_s=\begin{cases}\lfloor N_{s-1}/m\rfloor&\text{if }s\le A-r,\\0&\text{if }s>A-r,\end{cases}
\]
and in all cases $N_s=2N_{s-1}-B_s-D_s$.  We claim $N_s\ge N_{s-1}$.  This is clear for
$s\le t_0$.  If it holds below some $s>t_0$, then $B_{s-j}\le N_{s-j-1}/m\le N_{s-1}/m$
for $j\in J$, so $B_s+D_s\le(1+|J|)N_{s-1}/m=N_{s-1}$, which is the claim at $s$.

Build $\mathcal T$ by levels.  It contains $\varepsilon$.  For $1\le s\le A$ the $N_{s-1}$
words of $\mathcal T$ of length $s-1$ have $2N_{s-1}=N_s+B_s+D_s$ one-letter extensions.
If $s<A$, put $N_s$ of them into $\mathcal T$; the other $B_s+D_s$ are leaves, $B_s$ of
them \emph{anchors} and $D_s$ \emph{digits}.  If $s=A$, all $2N_{A-1}$ extensions are
leaves: $B_A=0$ anchors, $D_A$ digits and $N_A$ tail roots.  Every anchor of length $s$
opens a band.  By the definition of $D_s$, the digits of length $s$ can be matched
one-to-one with the pairs (an anchor of length $s-j$, $j\in J$); each digit joins the band
of its anchor.  This gives item~1, since anchors have lengths $t_0<s\le A-r$.  The words of
$\mathcal T$ have length less than $A$, and number $\sum_{s<A}N_s\le\sum_{s<A}2^s<2^A$; the
bands number $\sum_sB_s\le\sum_{s\le A}2^{s-1}<2^A$.

For item~2 let $M_s=2^{-s}N_s$.  Then $M_{t_0}=1$ and
$M_s=M_{s-1}-2^{-s}(B_s+D_s)\le M_{s-1}$.  For $t_0<s\le A-r$ we have
$B_s>N_{s-1}/m-1$, so $M_s<(1-\frac1{2m})M_{s-1}+2^{-s}$, and by induction
$M_s<(1-\frac1{2m})^{s-t_0}+\sum_{t_0<s'\le s}2^{-s'}$.  Hence
$2^{-A}N_A=M_A\le M_{A-r}<(1-\frac1{2m})^{A-r-t_0}+2^{-t_0}$.
\end{proof}



For $d$ large, Lemma~\ref{lem:strip} is the residual DAG.  The program for an
automaton needs a way to turn the bit read into the next state that does
not depend on the order of the states.  A single multiplication does it,
followed by a shared decoder.

\begin{lemma}[Threshold decoder]\label{lem:decoder}
Let $W,R\ge1$, $G=\lfloor(R+48)/48\rfloor+1$,
$M=48\bigl((W^2-1)G+1\bigr)+R+1$ and $\alpha^+=M+(W^2-1)G+1$.  For
$0\le z,o<W$ and $\varepsilon\in\{0,1\}$ put
$\alpha(z,o,\varepsilon)=M+(zW+o)G+\varepsilon$.  There is a fixed list
$\mathrm{Dec}_{W,R}$ of $17$ instructions, with operands of size
$O(W^2R)$ and no zero operand, that sends every register value
$y=-\alpha(z,o,\varepsilon)(48+b)+D$ with $b\in\{0,1\}$ and $0\le D\le R$
to $-z$ if $b=0$ and to $-o$ if $b=1$.
\end{lemma}

\begin{proof}
Let $t=48\alpha^+$.  The list is
\[
\begin{aligned}
 &\mathord{+}\!=t,\ \text{if}<0\,\{\ \mathord{*}\!=-1,\ \mathord{+}\!=-1,\
   /\!/\!=49G,\ \mathord{\%}\!=W,\ \mathord{*}\!=-1,\ \mathord{+}\!=-1\ \},\\
 &\mathord{+}\!=1,\ \text{if}>0\,\{\ \mathord{*}\!=-1,\
   \mathord{+}\!=t+1-48M+R,\ /\!/\!=48G,\ /\!/\!=W,\ \mathord{*}\!=-1\ \}.
\end{aligned}
\]
Put $\alpha=\alpha(z,o,\varepsilon)\in[M,\alpha^+]$, $k=zW+o$, and
$v=y+t$.  If $b=1$ then $v\le-49M+R+48\alpha^+<0$, by the choice of $M$;
if $b=0$ then $v\ge-48\alpha^++t=0$.  In the first branch
$-v-1=49\alpha-D-t-1$, and $t-49M+R=-1$ by the choice of $M$, so the
register becomes $49(\alpha-M)+R-D=49kG+(49\varepsilon+R-D)$.  The
bracket lies in $[0,49+R]\subset[0,49G)$, so floor division by $49G$ gives
$k$, the remainder by $W$ gives $o$, and the branch leaves $-o-1$.  Then
$\mathord{+}\!=1$ gives $-o\le0$ and the second test fails.  If $b=0$ the
first test fails, $\mathord{+}\!=1$ gives $v+1\ge1$, and the second branch
makes $48(\alpha-M)+R-D=48kG+(48\varepsilon+R-D)$ with the bracket in
$[0,48G)$, then $k$, then $z$, then $-z$.  Every operand is nonzero, since
$t+1-48M+R=48\bigl((W^2-1)G+1\bigr)+R+1$.  Python's floor division and
remainder agree with these values because the operands are nonnegative
there.
\end{proof}

\begin{proposition}[Automaton programs]\label{prop:dfaprog}
Let an automaton with state set $Q$, start $q_0$, transitions $\delta$ and
labels $\lambda$ compute an $n$-input table, and let $E\subseteq Q$ contain
every state reached after $n$ bits.  Then the table has a program whose
instructions are $O(1)$ fixed ones plus
\begin{itemize}
\item for each pair of states of $Q\setminus E$ (and one leftover state):
 $\mathord{+}\!=2$, $\text{if}>0$, input, $\mathord{*}\!=A$, endif,
 $\text{if}=0$, input, $\mathord{*}\!=A'$, endif;
\item for each state of $E$: $\mathord{+}\!=1$, $\text{if}=0$, input,
 $\mathord{*}\!=A$, endif,
\end{itemize}
with all operands $O(|Q|^3)$.  For the residual DAG of
Section~\ref{sec:upper}, read level by level, the same holds with $E$ empty
and $O(n)$ fixed instructions.
\end{proposition}

\begin{proof}
Order the states with $Q\setminus E$ first, grouped in pairs, then $E$.  The
groups add $2$ (a pair or the leftover state) or $1$ (a state of $E$); let
$C_i$ be the running sum up to group $i$ and $C$ the total.  Give the first
state of a pair, and the leftover state, the code $C_i-1$; give the second
state of a pair, and a state of $E$, the code $C_i$.  Put $W=C+1$, $R=C$,
and take $G,M,\alpha$ from Lemma~\ref{lem:decoder}.  A state $q$ with
children $q^0,q^1$ gets $A=-\alpha(c(q^0),c(q^1),\varepsilon_q)$.  The
program is
\[
  \mathord{+}\!=-48\alpha(c(q_0),c(q_0),0),\quad
  \text{while}<0\,\{\ \mathrm{Dec}_{W,R},\ \text{groups}\ \},\quad
  \mathord{\%}\!=2,\ \mathord{+}\!=48,\ \text{output}.
\]

If the register is $-c(q)$ before the groups, the value tested in group
$i$ is $C_i-c(q)$.  It is at most $-1$ before the group of $q$, and in that
group it is $1$ for the $\text{if}>0$ of a first or leftover state and $0$
for an $\text{if}=0$.  So exactly the block of $q$ fires.  It reads; a bit
$b$ gives $-\alpha_q(48+b)\le-48M$, which no later test fires on, and the
groups after it add $D\in[0,R]$.  The value stays negative, the loop
repeats, and Lemma~\ref{lem:decoder} turns it into $-c(q^b)$.  The first
pass starts from the value that Lemma~\ref{lem:decoder} decodes to
$-c(q_0)$.  So after $j$ bits the register selects the state reached by
those bits.  A state outside $E$ never reads past the input.  A state
$q\in E$ that reads the end of input gets $-1$ and then $\alpha_q>0$.  All
later groups belong to $E$ and test only $=0$, so none fires, and the loop
ends with $\alpha_q+D$.  Choosing $\varepsilon_q$ makes its parity
$\lambda(q)$, so the program prints $48+\lambda(q)$.  The operands are
$O(W^2R)=O(|Q|^3)$.

For the residual DAG, run the levels in order without the loop.  Level $k$
has only paired groups, $\mathrm{Dec}_{W_k,R_k}$ follows it, and after the
last level the codes of the two leaves are their labels.  The register then
holds $-\lambda$, and $\mathord{*}\!=-1$, $\mathord{+}\!=48$ and an output
print it.  The start value is $-1$, the code of the root.
\end{proof}


The programs of Proposition~\ref{prop:dfaprog} spend a multiplication (exponent
$3$) and half an increment per state.  The next construction spends neither on
most states.  A state whose two successors have no other predecessor branches to
them in place, inside its own block, and a state that hands its successors to the
loop encodes both of them in one addition; the bit read then enters only through
its parity, which a shared decoder reads.

\begin{lemma}[Additive decoder]\label{lem:adddec}
Let $W\ge2$ and $G=28$.  For $0\le z,o<W$ and $\rho\in\{1,2\}$ put
$m(z,o,\rho)=(zW+o+W)G+\rho$, and let $m^*=(W^2+W)G$, $N=2m^*+51$ and
$N'=m^*+27$.  The list $\mathrm{Dec}_W$ of $34$ instructions
\[
\begin{aligned}
 &\mathord{*}\!=-1,\ \mathord{*}\!=N+1,\ \mathord{\%}\!=2N,\ \mathord{+}\!=-N,\\
 &\text{if}<0\,\{\ \mathord{+}\!=N,\ /\!/\!=2,\ /\!/\!=G,\ \mathord{+}\!=-W,\
   /\!/\!=W,\ \mathord{*}\!=-1,\ \mathord{+}\!=-1\ \},\\
 &\text{if}>0\,\{\ \mathord{+}\!=1,\ /\!/\!=2,\ \mathord{*}\!=N'+1,\
   \mathord{\%}\!=GN',\ \mathord{+}\!=-26N',\\
 &\qquad\text{if}<0\,\{\ \mathord{+}\!=26N',\ \mathord{\%}\!=N',\ /\!/\!=G,\
   \mathord{+}\!=-W,\ \mathord{\%}\!=W,\ \mathord{*}\!=-1,\ \mathord{+}\!=-1\ \},\\
 &\qquad\text{if}>0\,\{\ /\!/\!=N',\ \mathord{+}\!=1\ \}\ \},\\
 &\mathord{+}\!=1
\end{aligned}
\]
has operands of size $O(W^2)$ and no zero operand, and with $m=m(z,o,\rho)$ it sends
the register value $-(2m-b)$, $b\in\{0,1\}$, to $-z$ if $b=0$ and to $-o$ if $b=1$, and
the value $-(2m+49)$ to $\rho+1$.
\end{lemma}

\begin{proof}
For integers $0\le x<N$ and $k\ge1$ we have $x(N+1)\bmod kN=x+N\,(x\bmod k)$, since
$xN\bmod kN=N(x\bmod k)$ and $x+N(x\bmod k)<kN$.  The three kinds of input are
$-w$ with $w=2m'-\beta$, where $(m',\beta)=(m,b)$ for $-(2m-b)$ and
$(m',\beta)=(m+25,1)$ for $-(2m+49)$.  Since $m\equiv\rho\pmod G$, the residue
$m'\bmod G$ is $\rho\in\{1,2\}$ in the first two cases and $\rho+25\in\{26,27\}$ in
the third, and $1\le w\le2m^*+49<N$ and $m'<m^*+25<N'$.

The first line gives $w+N\beta-N$.  If $\beta=0$ this is $w-N<0$, and the first
bracket computes $w$, $m'=w/2$, $m'/\!/G=zW+o+W$, then $zW+o$, $z$, and ends with
$-z-1<0$, so the second test fails.  If $\beta=1$ the value is $w>0$: the first test
fails, and the second bracket computes $w+1=2m'$, $m'$ and
$m'+N'(m'\bmod G)-26N'$.  For the residues $1,2$ this is negative, and the inner
first bracket computes $m'+N'(m'\bmod G)$, $m'$, $zW+o+W$, $zW+o$, $o$, and ends
with $-o-1<0$, so the inner second test fails.  For the residues $26,27$ it is at
least $m'>0$, the inner first test fails, and the inner second bracket computes
$\rho-1$ and then $\rho$.  The last addition gives $-z$, $-o$ or $\rho+1$.  All
divisions and remainders act on nonnegative values, where Python's semantics are
the arithmetic ones.
\end{proof}

\begin{proposition}[Embedded automaton programs]\label{prop:embprog}
Let an automaton with states $Q$, start $q_0$ and transitions $\delta$ compute an
$n$-input table, where $Q$ is the set of states reached after at most $n$ bits and
$\delta(q,b)$ is defined whenever $q$ is reached after fewer than $n$ bits.  Let
$E\subseteq Q$ contain every state reached after $n$ bits, with its label $\lambda$.
Let $F\subseteq Q\setminus E$ be a set of states such that for $q\in F$ and
$b\in\{0,1\}$ the state $\delta(q,b)$ is defined, differs from $q_0$, and $(q,b)$ is
the only pair that $\delta$ sends to it.  Call the states $\delta(q,b)$, $q\in F$,
\emph{embedded} and the others \emph{dispatched}.  Then the table has a program
consisting of $O(1)$ fixed instructions and, for every state $q$,
\begin{itemize}
\item an input, followed by $\mathord{+}\!=-48$ if $q\in F$ and by one addition
$\mathord{+}\!=a_q$ with $|a_q|=O(W^2)$ otherwise, $W$ as below;
\item one opener, $\text{if}>0$ or $\text{if}=0$, and one closing bracket, where the
two successors of a state of $F$ get one opener of each kind, and so do the two
members of each group below;
\end{itemize}
and one $\mathord{+}\!=2$ for each group of two dispatched states (the last group may
have one member).  Here $W=2\lceil D/2\rceil+1$ with $D$ the number of dispatched states.
\end{proposition}

\begin{proof}
\emph{Structure.}  An embedded state has exactly one predecessor pair, from a state of
$F$.  A cycle of such edges contains no state reached from $q_0$ through an edge
entering the cycle from outside, since every state on it has its only predecessor on
the cycle; as every state is reached from $q_0$ and $q_0$ is dispatched, there is no
such cycle.  So the edges from $F$ form a forest whose roots are dispatched, and
every embedded state lies below exactly one dispatched root.  If $q\notin F$ then
$\delta(q,b)$, when defined, is dispatched: an embedded state has its only
predecessor pair in $F\times\{0,1\}$.

\emph{Program.}  Number the dispatched states $1,\dots,D$; the number of $q$ is its
code $c(q)$.  Group the codes as $(1,2),(3,4),\dots$, and let $R=2\lceil D/2\rceil$ and
$W=R+1$.  For a dispatched $q$ in group $g$ put $D_q=R-2g$, and let an embedded state
inherit $D_q$ from its root.  Put $c(\cdot)=0$ for an undefined successor, and for
$q\notin F$ put
\[
  m_q=m\bigl(c(\delta(q,0)),\,c(\delta(q,1)),\,1+[q\in E]\,\lambda(q)\bigr)
\]
with $m$ from Lemma~\ref{lem:adddec}.  The block of $q$ is
\[
 B(q)=\begin{cases}
 \text{input},\ \mathord{+}\!=-48,\ \text{if}>0\,\{B(\delta(q,1))\},\
   \text{if}=0\,\{B(\delta(q,0))\}, & q\in F,\\
 \text{input},\ \mathord{+}\!=-48-2m_q-D_q, & q\notin F,
 \end{cases}
\]
finite because the forest is.  Group $g$ is
$\mathord{+}\!=2,\ \text{if}>0\,\{B(q)\},\ \text{if}=0\,\{B(q')\}$ with
$c(q)=2g-1$, $c(q')=2g$, and the program is
\[
 \mathord{+}\!=-c(q_0),\quad
 \text{while}<0\,\{\ \text{group }1,\ \dots,\ \text{group }\lceil D/2\rceil,\
   \mathrm{Dec}_W\ \},\quad
 \mathord{\%}\!=2,\ \mathord{+}\!=48,\ \text{output}.
\]
Every operand is nonzero, and $|48+2m_q+D_q|=O(W^2)$.

\emph{Run.}  Fix an input and let $q_k$ be the state after its first $k$ bits.  We
show: if a pass of the loop starts with register $-c(q_k)$, $q_k$ dispatched, then it
reads the bits $k+1,\dots,k'+1$ for the first $k'\ge k$ with $q_{k'}\notin F$ (and, if
$k'=n$, the end of input instead of bit $n+1$), and ends with register
$-c(q_{k'+1})$ if $k'<n$, or with $\lambda(q_n)+2$ if $k'=n$.  In group $g$ the
tested value is $2g-c(q_k)$.  It is at most $-1$ before the group of $q_k$; in that
group it is $1$ at the $\text{if}>0$ when $c(q_k)=2g-1$, and $0$ at the $\text{if}=0$
when $c(q_k)=2g$; so exactly the block of $q_k$ is entered.  Inside, a state
$q_j\in F$ is not in $E$, so $j<n$ and it reads bit $j+1=b$; the register becomes
$b$ after $\mathord{+}\!=-48$, and exactly the block of $q_{j+1}=\delta(q_j,b)$ is
entered.  The state $q_{k'}\notin F$ reads bit $k'+1$, or the end of input, which
happens only when $k'=n$; since $F\cap E=\emptyset$ and $q_n\in E$, the end of input
is never read inside a state of $F$.  The register becomes $-2m_q+b-D_q$, or
$-2m_q-49-D_q$ at the end of input.  From there on the pass executes only
the tests $\text{if}=0$ of the enclosing blocks (after the block of a
$1$-successor comes the test of the $0$-successor, and after that nothing inside
the enclosing block), the $D_q$ remaining increments and the later
group tests.  The value stays at most $-2m_q+1<0$, so nothing fires, and the decoder
receives $-(2m_q-b)$ or $-(2m_q+49)$.  By Lemma~\ref{lem:adddec} it returns
$-c(\delta(q_{k'},b))=-c(q_{k'+1})$, whose state is dispatched as shown above and
has code at least $1$, or $1+[q_n\in E]\lambda(q_n)+1=\lambda(q_n)+2$.

The first pass starts with $-c(q_0)$.  So the passes consume the input from left to
right; after the pass that reads the end of input the register is
$\lambda(q_n)+2>0$, the loop ends, and the program prints $48+\lambda(q_n)$, the
table value.  Before that every pass ends with a negative register, and the loop
repeats.
\end{proof}

Every construction of this section, and Lemmas~\ref{lem:bstrip} and~\ref{lem:trieband}
with Proposition~\ref{prop:embprog}, was compiled and run with the interpreter's
\texttt{\_advance} on all $2^n$ inputs for $n\le11$: random, maximal-width, parity,
constant and last-two-bits tables; for Lemma~\ref{lem:bstrip} $d=1,2,3$ with several $L$
and $I$ (including $I=0$ and the largest $I$), and the leveled form; for
Lemma~\ref{lem:trieband} the tries of Lemma~\ref{lem:bandtrie} with several $r$, $J$,
$t_0$, $A$ and the depths $L_k$ of Proposition~\ref{prop:bracket}, and random tries with
random bands and depths.  The transition and uniqueness properties, (a) and (b) of both
lemmas, were checked on the same runs.  Several programs were also expanded to source,
parsed back to the same list, and run through the public entry point.


\section{Explicit constants}\label{sec:constants}

Theorem~\ref{thm:main} is a statement of order.  This section tracks the
constants through both halves, normalizing $C_P(n)$ by
$T^2/n=T^2/\log_2T$.  The lower side charges the input roots:
Corollary~\ref{cor:roots} and Proposition~\ref{prop:counting} force
$\max(N_n,\lceil T/(n+4)\rceil)$ of them, and the imaginary-pair form
of the coefficient-mass theorem~\cite[Corollary~5.3]{coefficient-mass}
prices each pair $\pm ci$ as one real root $c^2$.  This beats the
real roots with Theorem~\ref{thm:mass} by a factor $4$.
For even and odd sources the forced real roots can be charged as well
(Lemma~\ref{lem:evensigns}), and sources that are neither even nor odd pay the input
charge twice (Remark~\ref{rem:parity}); together this gives the lower constant $3$.
The upper side
counts the effective exponents of the roots of the automaton programs of
Proposition~\ref{prop:embprog}.

For a multiset of positive root exponents let $\Phi=\sum_ii\,b_{(i)}$, taken
in increasing order.

\begin{lemma}[Profiles]\label{lem:profile}
Let a program have, besides $O(n)$ further roots, $h$ paired states and
$e$ states of $E$ in the sense of Proposition~\ref{prop:dfaprog}.  Put
$\varphi=e/(h+e)$ and $S=h+e$.  Then
\[
  \Phi=f(\varphi)\,S^2+O(nS),\qquad
  f(\varphi)=\tfrac12\Bigl(4(7+\varphi)^2-\tfrac14\bigl((3+\varphi)^2+(9+\varphi)^2+(13+\varphi)^2\bigr)\Bigr).
\]
In particular $f(0)=\frac{525}8$, $f(\frac13)=\frac{1315}{18}$ and
$f(\frac23)=\frac{5821}{72}$.
\end{lemma}

\begin{proof}
An addition has the exponent $1$, a multiplication $3$ and a read $2$ (each
a conjugate pair, so two roots); the tests ``positive'' and ``zero'' and the
closing bracket are real roots of exponent $1$, $4$ and $2$.  So a pair has
the exponents $1,1$ ($\mathord{+}\!=2$), $1$ ($\text{if}>0$), $4$
($\text{if}=0$), $2,2$ (the two endifs), $2,2,2,2$ (the reads) and
$3,3,3,3$ (the multiplications), and a state of $E$ has $1,1,4,2,2,2,3,3$.
Per state there are $c_1=\frac{3+\varphi}2$, $c_2=3$, $c_3=2$ and
$c_4=\frac{1+\varphi}2$ roots of exponent $b$.  Sorting puts the
exponent-$b$ roots at ranks $C_{b-1}S<i\le C_bS$, with
$C_b=\sum_{b'\le b}c_{b'}$.  So $\Phi=\frac{S^2}2\sum_bb\,(C_b^2-C_{b-1}^2)+O(S)$,
and this equals $\frac{S^2}2\bigl(4C_4^2-C_1^2-C_2^2-C_3^2\bigr)$.  The
$O(n)$ other roots shift ranks by $O(n)$.
\end{proof}


For the programs of Proposition~\ref{prop:embprog} the multiplications are gone,
but the additions $\mathord{+}\!=a_q$ carry operands of size $W^2$, and a root
$a\pm p^bi$ has modulus at most $2\max(|a|,p^b)$.  We therefore assign to every root an
\emph{effective exponent}: $v$ for a real root $p^v$; $b$ for a root $a\pm p^bi$ of an
input or of an addition with operand $O(1)$; $2$ for the root of an addition
$\mathord{+}\!=a_q$; and $8$ for every root of the $O(1)$ fixed instructions.
Let $\Phi_{\rm e}=\sum_ii\,e_{(i)}$, taken over the effective exponents in increasing
order.

\begin{lemma}[Effective profile]\label{lem:effprofile}
Let a program of Proposition~\ref{prop:embprog} have $S$ states, of which $aS$ are not
in $F$ and $xS$ are dispatched.  Then
\[
  \Phi_{\rm e}=g(a,x)\,S^2+O(S),\qquad
  g(a,x)=\tfrac12\Bigl(4(6+x)^2-2\bigl(\tfrac{11}2+x\bigr)^2-\bigl(\tfrac52-2a+x\bigr)^2\Bigr).
\]
In particular $g(\frac12,0)=\frac{325}8$, and $g\bigl(\frac{1+\delta}2,\delta\bigr)=\frac{325}8+13\delta+\delta^2$.
\end{lemma}

\begin{proof}
Every state has an input (two roots of effective exponent $2$), a closing bracket
($2$), an opener, and two roots of effective exponent $1$ (from $\mathord{+}\!=-48$)
if it lies in $F$ and $2$ (from $\mathord{+}\!=a_q$) otherwise.  Every state has
exactly one opener, and the openers come in pairs $\{\text{if}>0,\text{if}=0\}$, of
exponents $1$ and $4$, except for at most one.  Every dispatched state has one root
$1$ from the $\mathord{+}\!=2$ of its group, except for $O(1)$.  So, per state, there
are $c_1=\frac12+2(1-a)+x$ roots of effective exponent $1$, $c_2=3+2a$ of exponent
$2$ and $c_4=\frac12$ of exponent $4$, up to $O(1/S)$, and $O(1)$ further roots of
effective exponent at most $8$ come from the fixed instructions.  With
$C_1=c_1$, $C_2=c_1+c_2=\frac{11}2+x$ and $C_4=6+x$, sorting puts the exponent-$b$
roots at the consecutive ranks $C_{b'}S<i\le C_bS$, $b'$ the next smaller exponent,
and summing $i$ over these blocks gives
\[
 \Phi_{\rm e}=\tfrac{S^2}2\bigl(C_1^2+2(C_2^2-C_1^2)+4(C_4^2-C_2^2)\bigr)+O(S)
 =\tfrac{S^2}2\bigl(4C_4^2-2C_2^2-C_1^2\bigr)+O(S);
\]
the $O(1)$ further roots change ranks by $O(1)$.
\end{proof}



For an even or odd source the real instruction roots can be charged together with the
input pairs.  For a polynomial $F$ write $\beta_k(F)$ for the $k$th largest of the
magnitudes of its nonleading coefficients.

\begin{lemma}[Real roots of even and odd sources]\label{lem:evensigns}
Let $f$ be an even or odd source whose decoded program has at least $Q\ge1$ distinct
input root values and at least $Q$ distinct real instruction roots, and let $v_j$ be as
in Lemma~\ref{lem:ppow}.  Then
\[
  \Lambda(f)\ \ge\ \sum_{j=1}^{Q}(Q+1-j)\log\frac{v_j^2(j+1)^2}4-\frac{\log2}2\,Q(Q+3)
  \ \ge\ 3Q^2\log Q-7Q(Q+1).
\]
\end{lemma}

\begin{proof}
Write $f(x)=x^\varepsilon E(x^2)$ with $\varepsilon\in\{0,1\}$ and $E\in\Z[y]$.  The
nonzero coefficients of $f$ and $E$ are the same, so $\Lambda(f)=\Lambda(E)$, and the
leading coefficient of $E$ has absolute value at least $1$.  If $\pm ci$, $c=p^b$, is an
input root, then $f(ci)=0$ and $ci\ne0$ give $E(-c^2)=0$; if $r=p^v$ is a real
instruction root, $f(r)=0$ gives $E(r^2)=0$.  Choose $Q$ distinct input values and $Q$
distinct real instruction roots.  Squaring is injective on positive numbers, so $E$ is
divisible by $\prod_{i=1}^Q(y-a_i)\prod_{i=1}^Q(y+c_i)$, where $a_1>\cdots>a_Q$ are the
squares of the chosen real roots and $c_1>\cdots>c_Q$ the squares of the chosen input
values.  All $a_i\ge4$ and all $c_i\ge16$.

Apply the rows at real roots of both signs~\cite[Theorem~5.10]{coefficient-mass} to $E$,
with $\rho=\frac12$; as the leading coefficient of $E$ has absolute value at least $1$,
for $1\le k\le Q$
\[
  \beta_k(E)\ \ge\ \frac{\Pi_k-1}{2^k-1},\qquad
  \Pi_k=\prod_{i=k}^{Q}\frac{a_i}2\prod_{i=k}^{Q}\frac{c_i}2\ \ge\ 16 .
\]
So $\Pi_k-1\ge\Pi_k/2$ and $\log\beta_k(E)\ge\log\Pi_k-(k+1)\log2$.  The $Q$ largest
nonleading magnitudes sit at distinct positions, so
\[
  \Lambda(E)\ \ge\ \sum_{k=1}^Q\log\beta_k(E)
  \ \ge\ \sum_{i=1}^Q i\Bigl(\log\frac{a_i}2+\log\frac{c_i}2\Bigr)-\frac{\log2}2\,Q(Q+3),
\]
because $\log(a_i/2)$ and $\log(c_i/2)$ occur in the rows $k\le i$.  Now $a_i$ is the
$i$th largest of $Q$ distinct squares of integers at least $2$, so
$a_i\ge(Q+2-i)^2$, and $c_i$ is the square of the $i$th largest of $Q$ distinct elements
of $\{p^b:b\ge2\}$, so $c_i\ge v_{Q+1-i}^2$.  Substituting $j=Q+1-i$ gives the first
inequality.

For the second, $v_j\ge(j+2)^2/4$ (Lemma~\ref{lem:ppow}) gives
$\log\bigl(v_j^2(j+1)^2/4\bigr)\ge6\log j-6\log2$.  Also
$\sum_{j=1}^{Q}(Q+1-j)\log j=\sum_{m=1}^{Q}\log m!$, and
$\log m!\ge\int_1^m\log x\,dx=m\log m-m+1$ and
$\sum_{m\le Q}m\log m\ge\int_1^Qx\log x\,dx$ give
\[
  \sum_{m=1}^{Q}\log m!\ \ge\ \frac{Q^2}2\log Q-\frac{Q^2}4+\frac14-\frac{Q(Q+1)}2+Q
  \ \ge\ \frac{Q^2}2\log Q-\frac34Q^2 .
\]
So the right side of the first inequality is at least
$3Q^2\log Q-\frac92Q^2-3\log2\,Q(Q+1)-\frac{\log2}2Q(Q+3)$, and
$\frac92+\frac72\log2<6.93$ and $3\log2+\frac32\log2<3.12$ give the second.
\end{proof}

The rows of~\cite[Theorem~5.10]{coefficient-mass} drop the largest roots of each sign,
not the smallest, and this costs only $O(Q^2)$ here because all the moduli are
polynomial in $Q$.  The input pairs contribute $2Q^2\log Q$, as in
Proposition~\ref{prop:bracket} below, and the real instruction roots add $Q^2\log Q$.

\begin{proposition}[Explicit bracket]\label{prop:bracket}
Let $N_n$ be as in Lemma~\ref{lem:maximal-width}, $v_j$ as in Lemma~\ref{lem:ppow},
$K_n=\max\bigl(N_n,\lceil T/(n+4)\rceil\bigr)$ and $g$ as in Lemma~\ref{lem:effprofile}.
For an automaton of Lemma~\ref{lem:bstrip} with $d\in\{1,2\}$, $d\le L$ and $L+dI<n$, put
$\kappa_\ell$, $S_m$ and $E_{d,I}$ as there, and
\[
 Y=d(I+1)+\sum_{\ell=L+1}^{n}\min\bigl(\kappa_\ell,2^{E_{d,I}(n-\ell)}\bigr)+S_{n-d(I+1)}+2,
 \qquad S=Y+\sum_{\ell=1}^{L}\kappa_\ell,\qquad Z=\kappa_L.
\]
For an automaton of Lemma~\ref{lem:trieband} with every $L_k\ge1$, put, with $e_k$ and $t$
as there,
\[
 Y=|\mathcal T|+K+\sum_{k=1}^K\sum_{\lambda>L_k}\min\bigl(2^\lambda,2^{e_k(\lambda)}\bigr)
   +\sum_{\lambda\le n}\min\bigl(t(\lambda),2^{2^{n-\lambda}}\bigr),
\]
$S=Y+\sum_k(2^{L_k+1}-2)$ and $Z=\sum_k2^{L_k}$.  In both cases let
$\Phi_{\mathcal A}=g(a,x)S^2$ with $aS=Y+Z$ and $xS=Y$.  Then:
\begin{enumerate}
\item for every $n\ge7$, with $K=K_n$, $Q=K-1$, $\sigma_K=\sum_{j=1}^{K}j\log(v_j^2-1)$
and $\tau_Q=\sum_{j=1}^{Q}(Q+1-j)\log\frac{v_j^2(j+1)^2}4-\frac{\log2}2Q(Q+3)$,
\[
  \begin{aligned}
  C_P(n)&\ \ge\ \frac{\max\bigl(\sigma_K,\min(2\sigma_K,\tau_Q)\bigr)}{\log10}\\
  &\ \ge\ \frac{\max\bigl(2K^2\log K-\frac52K(K+1),\ 3Q^2\log Q-7Q(Q+1)\bigr)}{\log10};
  \end{aligned}
\]
\item every $n$-input table has a program with
\[
  |f|\le\bigl(1+O(1/n)\bigr)\,n\log_{10}2\cdot\Phi^*_n,\qquad
  \Phi^*_n=\min_{\mathcal A}\bigl(\Phi_{\mathcal A}+O(S)\bigr),
\]
the minimum over the parameters of both kinds of automata, which do not depend on the
table.
\end{enumerate}
Moreover
\begin{equation}\label{eq:bracket-n}
  \Bigl(1-O\bigl(\tfrac{\log n}n\bigr)\Bigr)3\log_{10}2
  \ \le\ \frac{C_P(n)\,n}{T^2}\ \le\
  \Bigl(1+O\bigl(\tfrac{(\log n)^2}n\bigr)\Bigr)\frac{325}8\log_{10}2 .
\end{equation}
Consequently
\[
  3\log_{10}2\le\liminf_{n\to\infty}\frac{C_P(n)\,n}{T^2}
  \le\limsup_{n\to\infty}\frac{C_P(n)\,n}{T^2}\le\frac{325}8\log_{10}2 ;
\]
numerically, both limits lie in $[0.903,12.23]$.
\end{proposition}

\begin{proof}
\emph{Lower bound.}  Put $K=K_n$ and $Q=K-1$.  If $K=N_n$, take the table of
Corollary~\ref{cor:roots}: every program for it has at least $K$ distinct input root
values and at least $K$ distinct real instruction roots.  Otherwise
$K=\lceil T/(n+4)\rceil\le Z_n+1$, and we take the table of
Proposition~\ref{prop:counting}: every program for it has at least $Z_n+1\ge K$ read gaps,
hence at least $K$ distinct input root values.  Every gap except possibly the last one of
the list is followed by a real instruction, and, as in the proof of
Theorem~\ref{thm:count}, distinct gaps are followed by distinct real runs, which consist
of whole runs of equal real roots; so there are at least $Q$ distinct real instruction
roots.

Let $f$ be a source for this table, and let $\pm c_ji$ be its input roots.  Each
$x^2+c_j^2$ divides $f$, so their product does, and $|f_D|\ge1$ as $f$ has integer
coefficients.  The $c_j$ are distinct elements of $\{p^b:b\ge2\}$, so the $j$th smallest
is at least $v_j\ge4$, and $c_j^2\ge16$.  By~\cite[Corollary~5.3]{coefficient-mass},
$\Lambda(f)\ge\sum_{j\le K}j\log(c_{(j)}^2-1)\ge\sigma_K$.  If $f$ is neither even nor odd,
Remark~\ref{rem:parity} gives $\Lambda(f)\ge2\sigma_K$: write $f=E_0(x^2)+xE_1(x^2)$; by
the multisection lemma~\cite[Lemma~5.1]{coefficient-mass} both $E_\varepsilon$ are
nonzero integer multiples of $\prod_j(y+c_j^2)$, Theorem~\ref{thm:mass} applied to
$E_\varepsilon(-y)$ gives $\Lambda(E_\varepsilon)\ge\sigma_K$, and
$\Lambda(f)=\Lambda(E_0)+\Lambda(E_1)$.  If $f$ is even or odd, Lemma~\ref{lem:evensigns}
gives $\Lambda(f)\ge\tau_Q$.  Now $|f|\ge M(f)\ge\Lambda(f)/\log10$ gives the first
inequality.

For the second, Lemma~\ref{lem:ppow} gives
$v_j^2-1\ge(j+2)^4/16-1\ge\frac{65}{1296}(j+2)^4$, the last because
$(j+2)^4\ge81$.  So $\log(v_j^2-1)\ge4\log j-\log\frac{1296}{65}$, and
$\log\frac{1296}{65}<2.993$.  With
$\sum_{j\le K}j\log j\ge\int_1^Kx\log x\,dx=\frac{K^2}2\log K-\frac{K^2}4+\frac14$,
\[
  \sigma_K\ \ge\ 2K^2\log K-K^2-1.4965\,K(K+1)
  \ \ge\ 2K^2\log K-\tfrac52K(K+1).
\]
Lemma~\ref{lem:evensigns} gives $\tau_Q\ge3Q^2\log Q-7Q(Q+1)$, and
$2\sigma_K\ge4K^2\log K-5K(K+1)$ is at least this too: for $Q\le12$,
$3Q^2\log Q-7Q(Q+1)$ is negative, as $3Q\log Q<7(Q+1)$ there, and for $Q\ge13$
\[
  4K^2\log K-5K(K+1)-3Q^2\log Q+7Q(Q+1)\ \ge\ K^2\log K+2K^2-12K\ >\ 0 .
\]
With $Q\ge T/(n+4)-1$ and $\log Q\ge n\log2-\log(n+4)-O(n2^{-n})$, the term
$3Q^2\log Q-7Q(Q+1)$ is at least $3\log2\,\bigl(1-O(\tfrac{\log n}n)\bigr)T^2/n$; dividing
by $\log10$ gives the left side of~\eqref{eq:bracket-n}.

\emph{Upper bound, item 2.}  Fix an automaton $\mathcal A$ of either kind and a table.

For Lemma~\ref{lem:bstrip}, apply Proposition~\ref{prop:embprog} with $E$ the
states $\tau(w)$, $|w|=n$, and $F$ the tree states $u$ with $|u|<L$.  By
Lemma~\ref{lem:bstrip}(a) no tree state lies in $E$.  The successors of $u\in F$ are the
tree states $ub$, which have length at least $2$ and whose prefix $u$ is not a prefix of
$c$; by Lemma~\ref{lem:bstrip}(b) their only predecessor pair is $(u,b)$, and they are
not the start.  So the hypotheses hold.  The states outside $F$ are the tree states of
level $L$, the copy, deep and tail states; the dispatched states are the copy, deep and
tail states and the at most $d$ tree states $c'b$ with $c'$ a proper prefix of $c$.
By Lemma~\ref{lem:bstrip}(c), the multiset of effective exponents is contained, up to
$O(1)$ states and $O(1)$ roots, in the one with $Y$ states outside $F$ and dispatched,
$Z=\kappa_L$ tree states of level $L$, and $\kappa_\ell$ branching states at each level
$\ell<L$, each with one opener, half of them $\text{if}>0$; at every level $\ell>d$ the
tree words ending in $0$ and in $1$ are equally many.

For Lemma~\ref{lem:trieband}, apply Proposition~\ref{prop:embprog} with $E$ the states
$\tau(w)$, $|w|=n$, and $F$ the trie states whose two successors are trie states, together
with the tree states $(k,v)$ with $|v|<L_k$.  By Lemma~\ref{lem:trieband}(a) no state of
$F$ lies in $E$.  The successors of a state of $F$ are trie states other than
$\varepsilon$, or tree states $(k,v)$ with $|v|\ge1$; by Lemma~\ref{lem:trieband}(b) each
has a single predecessor pair, from that state, and none is the start $\varepsilon$.  So
the hypotheses hold.  The tree states $(k,v)$ with $|v|\ge1$ are embedded, and every
dispatched state is a trie state, a band root $(k,\varepsilon)$, a deep or a tail state.
By Lemma~\ref{lem:trieband}(c), the multiset of effective exponents is contained, up to
$O(1)$ roots, in the one with $Y$ states outside $F$ and dispatched, $Z$ tree states of the
levels $L_k$, and $2^\lambda$ branching states at each level $1\le\lambda<L_k$ of each
band, each with one opener, half of them $\text{if}>0$, because the words $v$ of length
$\lambda\ge1$ ending in $0$ and in $1$ are equally many.

In both cases the computation of Lemma~\ref{lem:effprofile} gives $g(a,x)S^2+O(S)$ for
that multiset, and $\Phi_{\rm e}$ only grows when a root is added or an exponent raised,
so $\Phi_{\rm e}\le\Phi_{\mathcal A}+O(S)$.

Every nonleading coefficient of the source is an elementary symmetric function of
its $D=O(S)$ roots, all of modulus greater than~$1$, so
\[
  \Lambda(f)\le\sum_{k}\log\binom Dk+\sum_{i}i\log|\rho|_{(i)} ,
\]
the second sum over the moduli in increasing order.  The encoder uses at most one
prime per instruction, so the largest prime is $P=O(S\log S)$.  It suffices to
treat automata with $S=O(T/n)$.  Indeed $g$ increases in $x\ge0$ and in
$a\in[0,\frac54]$, and $\frac12\le a\le1$: for Lemma~\ref{lem:bstrip} because
$\kappa_L=\sum_{\ell<L}\kappa_\ell+1$, and for Lemma~\ref{lem:trieband} because
$2^{L_k}\ge\frac12(2^{L_k+1}-2)$ and $L_k\ge1$.  So
$\Phi_{\mathcal A}\ge g(\frac12,0)S^2=\frac{325}8S^2$, while the automata used below have
$\Phi_{\mathcal A}=O(T^2/n^2)$.  Then $\log P\le n\log2+O(1)$.  The operands of the
additions $\mathord{+}\!=a_q$ are $O(W^2)=O(S^2)$, those of the fixed instructions
$O(W^2)$, and all others $O(1)$.  Hence every root satisfies
$\log|\rho|\le e(\rho)\,n\log2+O(1)$ with $e(\rho)$ its effective exponent, and by
domination of the sorted sequences
$\sum_ii\log|\rho|_{(i)}\le n\log2\cdot\Phi_{\rm e}+O(D^2)$.  Also
$\sum_k\log\binom Dk\le D^2\log2$.  Rendering adds at most $D+1$ digits and
$O(D\log D)$ further characters, and $\Phi_{\mathcal A}\ge S^2$; dividing by $\log10$
proves the second item.

\emph{Upper bound, asymptotics.}  Let $n$ be large and put $\lambda_0=\lceil\log_2n\rceil$,
$t_0=\sigma=\lambda_0$ and $A=t_0+\lambda_0+\lceil2(\lambda_0+1)\log n\rceil$.  Let $h$
be the largest integer with $2^{h-1}\le n^*$, where $n^*=n-h-A-\sigma$; as $n^*$ decreases
in $h$, it exists, and $h\ge2$ for large $n$.  By maximality $2^h>n-(h+1)-A-\sigma=n^*-1$,
so $x=n^*/2^{h-1}\in[1,2]$.  Put $r=h-1$, so $1\le r\le\lambda_0$, let
$y=\min\bigl(\lfloor(x-1)2^r\rfloor,2^r-1\bigr)2^{-r}$, and let $J\subseteq\{1,\dots,r\}$
be the set with $y=\sum_{j\in J}2^{-j}$.  Then
\[
 C=2^{h-1}(1+y)\quad\text{satisfies}\quad n^*-1\le C\le n^* :
\]
$y\le x-1$ gives $C\le n^*$; if $x<2$ then $y>x-1-2^{-r}$ and $C>n^*-2^{h-1-r}=n^*-1$; if
$x=2$ then $C=2^h-1=n^*-1$.

Take $\mathcal T$ and the bands of Lemma~\ref{lem:bandtrie} with these $r,J,t_0,A$, and give
the band whose shortest leaf has length $s$ the depth $L_k=n-h-s$.  For
$\ell\in\Lambda_k$, $|\ell|+L_k\le s+r+n-h-s=n-1$, and $L_k\ge n-h-A=n^*+\sigma\ge1$; so
Lemma~\ref{lem:trieband} applies, and
$e_k(L_k+1)=\sum_{j\in\{0\}\cup J}2^{\,h-1-j}=C$.  We bound the terms of $S$.
\begin{itemize}
\item The band has mass $\mu_k=\sum_{\ell\in\Lambda_k}2^{-|\ell|}=2^{-s}(1+y)$, so
$2^{L_k+1}=2^{\,n-h+1-s}=2^n\mu_k/C$.  The leaves are no prefixes of each other, so
$\sum_k\mu_k\le1$ and $\sum_k(2^{L_k+1}-2)<2^n/C$.
\item The deep states of level $L_k+1$ number at most $2^C\le2^{n^*}\le2^{L_k-\sigma}$,
in all at most $2^{-\sigma-1}2^n/C\le2^n/(2nC)$.  At the levels $L_k+t$, $t\ge2$, the
exponent is $e_k=2^{1-t}C\le n/2$; with fewer than $2^A$ bands and at most $n$ levels,
these deep states number less than $n2^{A+n/2}$.
\item The tail roots have length $A$, and since $m\le r+1\le\lambda_0+1$ and
$A-r-t_0\ge2(\lambda_0+1)\log n$, Lemma~\ref{lem:bandtrie} gives
$2^{-A}N_A<e^{-\log n}+2^{-t_0}\le2/n$.  At a level $\lambda\le n-\lambda_0+3$ there are
at most $2^{\lambda-A}N_A$ tail states, together at most $(2/n)2^{\,n-\lambda_0+4}\le32T/n^2$;
at each of the at most $\lambda_0$ higher levels, $2^{n-\lambda}\le2^{\lambda_0-4}\le n/8$,
so there are at most $2^{n/8}$.
\item $|\mathcal T|+K<2^{A+1}$.
\end{itemize}
Since $A=O((\log n)^2)$, $h,\sigma=O(\log n)$ and $C\ge n^*-1=n-O((\log n)^2)$, this gives
$Y=O(T/n^2)$ and $S\le\bigl(1+O((\log n)^2/n)\bigr)T/n$.  Also
$Z=\frac12(S-Y)+K$, so $a=\frac12+O(1/n)$ and $x=O(1/n)$, and
$g(a,x)=\frac{325}8+O(1/n)$, $g$ being a polynomial.  Item~2 gives
$C_P(n)\le\bigl(1+O((\log n)^2/n)\bigr)\frac{325}8\log_{10}2\cdot T^2/n$, the right side
of~\eqref{eq:bracket-n}.  The limits follow.
\end{proof}



\begin{remark}[What the bracket says]\label{rem:bracket}
The two sides of~\eqref{eq:bracket-n} differ by the factor $\frac{325}{24}=13.5$, at
both limits.  So Proposition~\ref{prop:bracket} fixes the order, but it does not fix the
constant.  The factor splits as follows.
\begin{itemize}
\item \emph{Routing contributes nothing.}  The lower bound credits one input
root value to every first-essential residual at one level
(Theorem~\ref{thm:count}), and Proposition~\ref{prop:sharp} shows the credit
cannot be raised.
\item \emph{Levels contribute nothing.}  The lower bound charges $T/(n+4)$ input values
(Proposition~\ref{prop:counting}).  For every $n$ and every table, the automaton of
Lemmas~\ref{lem:trieband} and~\ref{lem:bandtrie} used in the proof has
$(1+O((\log n)^2/n))T/n$ states, and its program has one input value per state.  So
$(S/(T/n))^2\to1$: the worst-case minimal automaton has $(1+o(1))T/n$ states, and the
earlier gap for the $n$ with $N_n$ close to $T/n$, between $T/n$ and the $\frac32T/n$ of
the bounded stripped automaton with $d=2$, is closed.  What closes it is the choice of the bands: a deep state
below band $k$ records $e_k(L_k+1)=2^{h-1}(1+y)$ bits, $y$ has the binary digits given by
the lengths of the leaves of the band, and so this number can be placed just below the
depth of the tree.  The bounded stripped automaton offers only the numbers
$2^{n-L-1}(1-2^{-d(I+1)})/(1-2^{-d})$.  At small $n$ it can still be the better of the two,
which is why item~2 of Proposition~\ref{prop:bracket} takes the minimum over both.
\item \emph{Profile: $g/3=\frac{325}{24}$.}  The lower bound charges
each input pair as one real root $c^2$, which is exact for pairs
alone~\cite[Corollary~5.3]{coefficient-mass}, and
$\sum_{j\le K}j\log v_j^2\sim2K^2\log K$ gives the mass constant $2$.  A source
that is neither even nor odd pays this twice (Remark~\ref{rem:parity}), and an even or
odd source pays it once, plus the constant $1$ of its real instruction roots
(Lemma~\ref{lem:evensigns}): hence the lower constant $3$.  The
construction pays $g=\frac{325}8$ per state squared: an input ($2,2$), a closing
bracket ($2$), an opener ($1$ or $4$), and either $\mathord{+}\!=-48$ ($1,1$) or one
addition that encodes both successor codes (effective $2,2$), the latter for half of the
states.  No tree state can see the end of the input (Lemma~\ref{lem:trieband}(a)), so no
state pays for it at leading order, and the dispatched states, which pay the dispatch
increments, are $o(S)$.
Remark~\ref{rem:floor} shows why rearranging these blocks does not lower $g$, and by
Corollary~\ref{cor:symm} these programs, which are neither even nor odd, are already
subject to the lower constant $4$.
\end{itemize}
Charging the forced real roots together with the input pairs is what
Lemma~\ref{lem:evensigns} does for even and odd sources, where $f=x^\varepsilon E(x^2)$
and $E$ carries both families on the real line, the inputs as negative roots $-c^2$ and
the real roots as positive roots $r^2$.  The rows at real roots of both
signs~\cite[Theorem~5.10]{coefficient-mass} charge the two signs separately.  Charging
them as one sorted family with the weights $\lceil i/2\rceil$, as the conjectured
rows~\cite[(21)]{coefficient-mass} would, is worth only about $\frac72Q^2\log Q$ at the
least admissible root values, still below $4$.  For sources that are neither even nor
odd the multisection proof of~\cite[Corollary~5.3]{coefficient-mass} needs $P=R(x^2)$
with all roots of $R$ of one sign; the real roots $p^v$ break the first condition, and
passing to $F(x)F(-x)$ breaks the second, but these sources already pay $4$.  The
order-statistic bound for arbitrary free positions (\cite[Lemma~3.1]{coefficient-mass})
is already sharp (\cite[Corollary~3.6]{coefficient-mass}).  So a lower constant above
$3$ needs a charge for the register roots of even and odd sources, which in $E$ are the
complex roots $(a\pm p^bi)^2$; bounds for such roots at arbitrary angles are open
(\cite[Section~5]{coefficient-mass}).
\end{remark}


\begin{remark}[Even and odd sources]\label{rem:parity}
Write a source as $f(x)=E_0(x^2)+xE_1(x^2)$.  If $f$ is divisible by
$\prod_j(x^2+c_j^2)$, then by the multisection lemma~\cite[Lemma~5.1]{coefficient-mass}
both $E_0$ and $E_1$ are multiples of $R(y)=\prod_j(y+c_j^2)$.  If $f$ is neither even
nor odd, both are nonzero, and both have integer coefficients, hence leading
coefficients of absolute value at least $1$.  Theorem~\ref{thm:mass}, applied to
$E_\varepsilon(-y)$, a multiple of $\prod_j(y-c_j^2)$ with the same coefficient
magnitudes, gives $\Lambda(E_\varepsilon)\ge\sum_jj\log(c_{(j)}^2-1)$ for
$\varepsilon=0,1$, and $\Lambda(f)=\Lambda(E_0)+\Lambda(E_1)$ gives
\[
  \Lambda(f)\ \ge\ 2\sum_{j}j\log(c_{(j)}^2-1).
\]
So every source for the table of item~1 of Proposition~\ref{prop:bracket} that is
neither even nor odd has length at least $(4-o(1))\log_{10}2\cdot T^2/n$, four thirds of the bound there.  An even or odd source has, with every root $\rho$, also the root
$-\rho$; its decoded program therefore contains the instruction $(-a,b)$ with every
register instruction $(a,b)$, $a\ne0$.  Lemma~\ref{lem:symruns} restricts such sources further: their additions and
subtractions change the register only right after reads, in the run of the read, and
Corollary~\ref{cor:symm} gives the constant $4$ to every source with a run of nonzero sum.
By Lemma~\ref{lem:evensigns} even and odd sources pay at least the constant $3$, and
whether they can come below $4$ is what separates the lower constant $3$ from $4$.
\end{remark}

\begin{lemma}[Symmetric runs]\label{lem:symruns}
Let $f$ be an even or odd source.  For a prime $p$ and $1\le b\le6$ let $R_{p,b}$ be the
list of decoded instructions $[a,b]$ of $p$ (roots $a\pm p^bi$), with multiplicity, in the
interpreter's order of increasing $a$, and let $R_p=R_{p,1}R_{p,2}\cdots R_{p,6}$.
\begin{enumerate}
\item For every $a\ne0$, $[a,b]$ and $[-a,b]$ occur in $R_{p,b}$ equally often.
\item $R_p$ is a contiguous part of the program without control instructions, and every
execution that reaches an instruction of $R_p$ has entered $R_p$ at its first instruction
and runs through all of $R_p$ before the next control instruction.
\item Whenever $R_p$ runs, the additions of $R_{p,1}$ change the register by $0$ in total
(an output among them prints the register minus $\sum_{a>0}a$), and so do the
subtractions of $R_{p,2}$ if $R_{p,2}$ contains no input; if it does, the register after
$R_{p,2}$ is the last value read minus the sum of the positive $a$ in $R_{p,2}$.
\end{enumerate}
\end{lemma}

\begin{proof}
1.  As $f(-x)=\pm f(x)$, the map $\rho\mapsto-\rho$ permutes the roots of $f$ preserving
multiplicities.  It sends the conjugate pair $a\pm p^bi$ of $[a,b]$ to the pair
$-a\pm p^bi$ of $[-a,b]$; whether a pair is recognized depends only on $p^b$.

2.  Recognized roots are sorted by the prime, then the imaginary part, then the real
part.  So the real roots of $p$, which are the control instructions of $p$, come first,
then $R_{p,1},\dots,R_{p,6}$, then everything of larger primes.  Execution starts at the
first instruction, moves by one, and jumps only to the instruction after a control
instruction (the partner of a bracket); none of these lies inside $R_p$ except its first
instruction.  Inside $R_p$ there is no control instruction, so a run that enters it
continues to its end.

3.  By 1 the operands of the additions of $R_{p,1}$ sum to $0$, and by 2 they are all
executed, in increasing order, with at most an output (at $a=0$) between the negative and
the positive ones.  The same holds for $R_{p,2}$ without input.  With an input $[0,2]$
(repeated $m$ times, $m$ reads) the subtractions before it are overwritten, and those after
it are the $[a,2]$ with $a>0$.
\end{proof}

\begin{corollary}[Uncancelled runs]\label{cor:symm}
Let $f$ be a source for the table of item~1 of Proposition~\ref{prop:bracket}.  If for
some prime $p$ the operands of the additions $[a,1]$ of $p$ have a nonzero sum, or $p$
has no input $[0,2]$ and the operands of its subtractions $[a,2]$ have a nonzero sum,
then
\[
  |f|\ \ge\ \bigl(4-o(1)\bigr)\log_{10}2\cdot\frac{T^2}n .
\]
\end{corollary}

\begin{proof}
By Lemma~\ref{lem:symruns}, parts 1 and 3, $f$ is neither even nor odd, and
Remark~\ref{rem:parity} applies.
\end{proof}

With one prime per instruction, as in the encoder of Section~\ref{sec:upper}, every
addition $\mathord{+}\!=a$, $a\ne0$, is such a run by itself; so for that table every
source built as in Section~\ref{sec:upper} needs twice the lower bound of
Proposition~\ref{prop:bracket}.
Only even or odd sources can come below the constant $4$, and by
Lemma~\ref{lem:symruns} these change the register additively only right after a read,
inside the run of that read: between two reads they route with tests and with runs of
multiplications, floor divisions, remainders and powers, whose roots have exponent at
least $3$.  In particular they have no increments with which to dispatch, as the programs
of Propositions~\ref{prop:dfaprog} and~\ref{prop:embprog} do.

The next lemma is the reason why the construction pays an opener of exponent $4$ at half
of its states.

\begin{lemma}[One instruction after a read]\label{lem:onestep}
Let $[a,b]$, $a\ne0$, be a register instruction, and let $v_y$ be the register after it
is executed on $48+y$, $y\in\{0,1\}$.  Then $v_0$ and $v_1$ do not have strictly opposite
signs.  Consequently, if neither is $0$, every test takes the same branch on $v_0$ and on
$v_1$.
\end{lemma}

\begin{proof}
For $b=1,2$ the values are consecutive integers.  For $b=3$ both have the sign of $a$.
For $b=4$, $\lfloor(48+y)/a\rfloor$ is at least $0$ if $a>0$ and at most $-1$ if $a<0$.
For $b=5$ the remainder lies in $[0,a)$ if $a>0$ and in $(a,0]$ if $a<0$.  For $b=6$ both
values are positive (reals if $a<0$).  The tests ($\text{if}$ or $\text{while}$ with
$>0$, $<0$, $=0$) depend only on the sign.
\end{proof}

After a read the register is $48$ or $49$, so every test agrees on the two runs until
the first instruction $[a,b]$ with $a\ne0$; by Lemma~\ref{lem:onestep}, if that is the only one before
the runs reach different cursors, they part at a test at which one of them has the value
$0$.  A test that fires on $0$ is $\text{if}=0$ or $\text{while}=0$, of exponents $4$ and
$8$.

\begin{remark}[The profile of per-state blocks]\label{rem:floor}
The programs of Proposition~\ref{prop:embprog} give every state one input, one register
instruction, one opener and one closing bracket, and every state is entered through its
own opener, which fires.  Two features of this shape are forced, and the local
alternatives to them all have a larger profile than the $\frac{325}8$ of
Lemma~\ref{lem:effprofile}.
\begin{itemize}
\item \emph{Openers.}  At a state of $F$ the two runs part after one register
instruction, so by the paragraph above one of its two successors is entered through an
opener that fires on $0$, of exponent at least $4$.  These are $|F|$ openers, and
$|F|\le S/2$ is about $S/2$ for the automata of Lemma~\ref{lem:trieband}.  Avoiding them
costs a second register instruction at each state of $F$: with $\mathord{+}\!=1$ between
the two successor blocks, both entered by $\text{if}>0$, the profile is
$\frac{89}2=44.5$; with $\mathord{+}\!=-49$, $\text{if}<0$ and $\mathord{+}\!=1$,
$\text{if}>0$ it is $\frac{197}4=49.25$.
\item \emph{Additions.}  Every embedded state has its only predecessor pair in $F$, so
$2|F|\le S$ and at least half of the states lie outside $F$.  For the automata of
Lemma~\ref{lem:trieband} with the parameters of Proposition~\ref{prop:bracket}, which do
not depend on the table, the program is determined by the numbering of the $D$
dispatched states and by the operands $a_q$ of the states outside $F$.  Counting the
$2^T$ tables against these data, all but a vanishing fraction of the tables have
$\sum_q\log_2(2|a_q|+1)\ge T-O(S\log n+D\log D)=(1-o(1))T$.  There are
$(\frac12+o(1))S$ states outside $F$ and $S=(1+o(1))T/n$, so their operands have
$\log|a_q|\ge(2-o(1))\,n\log2$ on average: effective exponent $2$ (replacing exponents by
their average does not increase $\Phi_{\rm e}$, since the sum of the $k$ largest
exponents can only decrease).  Deep
states recording $\theta n$ bits with $\theta<1$ make the operands smaller and the
automaton larger: the profile per $(T/n)^2$ is then at least
$(\frac{293}8+4\theta)/\theta^2>\frac{325}8$.
\item \emph{Other shapes.}  Dispatching every state, with its two successors at adjacent
codes so that an addition of size $O(S)$ suffices, costs an increment per group:
$\frac{421}8$.  Chains, with one embedded successor and a code for the other, cost
$\frac{103}2$.  A fraction $h$ of states whose $0$-successor is reached by falling
through to a later $\text{if}=0$ block saves those openers, but by the same count the
automaton then has at least $(1+h-o(1))T/n$ states, and the profile per $(T/n)^2$
exceeds $\frac{325}8$ for every $h>0$.  The
even version of the construction, with $\text{input},\mathord{-}\!=a$ in one run as
Lemma~\ref{lem:symruns} requires, has $\Lambda(f)=\Lambda(E)$ with profile $\frac{237}4$
in the exponents of the roots of $E$.
\end{itemize}
A first-essential state needs an input pair of exponent $2$ and a register pair (by the
paragraph above), and two inputs without a control instruction between them run one
after the other, so that the first bit is overwritten before any test sees it.  A state with one register pair of exponent $1$, an opener
$\text{if}>0$ and a closing bracket would give $\frac{63}2$; the difference
$\frac{325}8-\frac{63}2=\frac{73}8$ comes from the two forced features above.  Lowering
the upper constant therefore needs programs of another kind, not a rearrangement of these
blocks.
\end{remark}
