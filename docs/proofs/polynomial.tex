\begin{abstract}
In the Polynomial esoteric programming language, the roots of an
integer polynomial encode the instructions of a one-register machine, while
the source text lists the polynomial's expanded coefficients.  We prove that
the worst-case text complexity of $n$-input Boolean functions is
$\Theta(T^2/\log T)$, where $T=2^n$ is the truth-table length: every table
has a Polynomial program of length $O(T^2/\log T)$, and some tables require
$\Omega(T^2/\log T)$ source characters in every program, independently of the
program's degree, operand signs, and additional roots.  The upper bound is
an explicit residual-DAG construction.  For the lower bound, a routing
argument forces $\Omega(T/\log T)$ distinct positive real roots in every
program for a suitable table, with no assumption on the number of reads, and
a coefficient-mass theorem, proved separately, shows that a real polynomial
divisible by $L$ distinct prime-power roots and having leading coefficient
of absolute value at least one has logarithmic coefficient mass
$\Omega(L^2\log L)$.  Tracking the constants, the worst-case length $C_P(n)$
satisfies
$2\log_{10}2\le\liminf C_P(n)\,n/T^2\le\tfrac{525}8\log_{10}2$ and
$2\log_{10}2\le\limsup C_P(n)\,n/T^2\le\tfrac{5821}{32}\log_{10}2$: the
order is settled, but the constant is determined only up to a factor of
about $33$ at the limit inferior and $91$ at the limit superior.
\end{abstract}

\noindent\textbf{Keywords.} Descriptional complexity; Boolean functions;
ordered binary decision diagrams; polynomial roots; esoteric programming
languages.

\section{The language and the result}\label{sec:model}

A Polynomial source is the expanded form
\[
  f(x)=\sum_{j=0}^{D} f_jx^j,\qquad f_j\in\Z.
\]
It is serialized as \texttt{f(x) = } followed by nonzero monomials in
descending degree, with decimal coefficients and exponents, as in the
language specification~\cite{polynomial-spec}; whitespace is permitted
between tokens.  Throughout, ``program'' means a source in this specified
expanded form; permissive implementation extensions are outside the model.
The interpreter factors $f$ over the integers and orders the recognized
roots by their associated primes.  A positive real root $p^v$ encodes a
control-flow instruction; a conjugate pair $a\pm p^b i$ encodes a register
instruction.  Unrecognized roots are ignored, so a source may be any integer
multiple of the product of its instruction factors.  Repeated recognized
roots produce repeated instructions.

As a minimal example, $f(x)=x^2+4$ has roots $\pm2i$.  The imaginary
magnitude $2=2^1$ selects the first register instruction for the prime $2$,
while the real part $0$ supplies its operand.  This instruction outputs the
initial register value, the zero byte.  In general the interpreter follows
the same pipeline:
\[
 \text{expanded coefficients}\longrightarrow
 \text{recognized roots}\longrightarrow
 \text{sorted instructions}\longrightarrow
 \text{execution}.
\]

The machine has an integer register and an instruction cursor.  Its input
instruction overwrites the register with the next input symbol, $48+b$ for a
Boolean bit $b$.  Real-root instructions are the bracket-like control-flow
operations; complex-root instructions update the register.  The upper bound
uses input, output, addition and multiplication by an integer, integer floor
division, and ``if positive'' with its closing instruction; the sharper
constants of Section~\ref{sec:constants} also use the remainder, the tests
``negative'' and ``zero'', and a loop.  The lower bound
uses only the following structural properties.

\begin{enumerate}
\item Input is consumed as an ordered stream: the $j$-th read instruction
receives the $j$-th input bit, whatever the path taken.
\item Between two input reads the complete state is the pair consisting of
the register and the instruction cursor.
\item Each real instruction root is one of the first eight positive powers of
its associated prime.  One prime may supply several consecutive positions.
\item Equal real roots occur in one contiguous block after root sorting.
\item The bracket matching is noncrossing.
\item An input instruction has the purely imaginary roots $\pm ci$ with
$c=p^b$, $p$ prime, $2\le b\le6$, and equal roots of every kind, not only
real ones, occur in one contiguous block after root sorting.
\end{enumerate}

For Boolean computation, put $T=2^n$ and supply each bit as a separate line
containing its ASCII digit.  A program computes
$t=(t_0,\ldots,t_{T-1})\in\{0,1\}^{2^n}$ if, on every
$b_1\cdots b_n\in\{0,1\}^n$ in lexicographic order, it terminates and emits
exactly the character $t_{(b_1\cdots b_n)_2}$, with zero-based subscripts.
Reads consume the input stream in order; a read past its end stores $-1$.
A program may perform different numbers of reads on different inputs, and
may read past the end.  The upper-bound construction reads exactly $n$ bits
on every input, but the lower bound does not assume this.

The length $|f|$ is the total
number of characters in the shortest valid expanded serialization of $f$;
fixed punctuation and optional whitespace affect only lower-order terms.
Its coefficient-digit mass is
\[
  M(f)=\sum_{j:f_j\ne0}\bigl(1+\lfloor\log_{10}|f_j|\rfloor\bigr).
\]
Every nonzero coefficient appears in a monomial whose serialization supplies
at least $1+\lfloor\log_{10}|f_j|\rfloor$ characters, so $|f|\ge M(f)$.
The worst-case text complexity $C_P(n)$ is the maximum, over these tables, of
the minimum $|f|$ of a program computing the table.
All unqualified logarithms are natural.

\begin{theorem}[Main theorem]\label{thm:main}
Every $n$-input Boolean function has a Polynomial program of length
$O(T^2/\log T)$, and there are $n$-input Boolean functions for which every
program has length $\Omega(T^2/\log T)$.  Hence the
worst-case text complexity in the model of Section~\ref{sec:model} is
$C_P(n)=\Theta(T^2/\log T)$.
\end{theorem}

The theorem concerns source length, not the running time of polynomial
factorization or of source generation.  It allows arbitrary degrees,
arbitrary operand signs, repeated roots, and arbitrary unrecognized cofactor
roots, and its upper half is an existence statement for the uncapped
residual-DAG construction; implementation resource limits do not affect it.

The lower bound has two independent parts.  Section~\ref{sec:routing} shows
that a short instruction alphabet cannot distinguish enough residual truth
tables, so a suitable table forces $\Omega(T/\log T)$ distinct positive real
roots.  Section~\ref{sec:mass} applies the coefficient-mass theorem
of~\cite{coefficient-mass}: supporting that many roots forces
$\Omega(T^2/\log T)$ coefficient digits.  Section~\ref{sec:upper} supplies
the matching construction, and Section~\ref{sec:constants} tracks the
constants through both halves (Proposition~\ref{prop:bracket}):
\[
  2\log_{10}2\le\liminf_{n\to\infty}\frac{C_P(n)\,n}{T^2}
  \le\frac{525}{8}\log_{10}2,
  \qquad
  2\log_{10}2\le\limsup_{n\to\infty}\frac{C_P(n)\,n}{T^2}
  \le\frac{5821}{32}\log_{10}2 .
\]
Remark~\ref{rem:bracket} locates the gap between the two sides.

Residual DAGs are reduced ordered binary decision diagrams under a fixed
variable order~\cite{bryant}; classical results place the size of an optimal
diagram for almost every Boolean function at the same
$\Theta(T/\log T)$ scale~\cite{wegener,gps}.  Here the input stream fixes the
order, and Lemma~\ref{lem:maximal-width} uses a tailored width statistic,
the number of first-essential residuals at one level, which the
next-read argument (Theorem~\ref{thm:count}) translates into distinct
Polynomial roots.  The
certificate machinery relates the displaced-zero comparison and
coefficient-order statistics to the reduced-height
literature~\cite{coefficient-mass}.

\section{Routing forces distinct roots}\label{sec:routing}

The $k$th read of every execution receives the $k$th input bit $b_k$.  After
$k$ reads the prefix $b_1\cdots b_k$ therefore determines a residual Boolean
function of the remaining $n-k$ bits: in the truth table, the block of
$2^{n-k}$ consecutive entries indexed by the prefix.  Only this natural
variable order matters.  Call a function $g(y_1,\ldots,y_m)$
\emph{first-essential} if it depends on $y_1$ and is not a function of $y_1$
alone, and write $N^*(k)$ for the number of distinct first-essential
residuals at level $k$.

\begin{lemma}[Maximal-width tables]\label{lem:maximal-width}
Let $n\ge2$.  For $2\le j\le n$ put $q_j=2^{n-j}$ and
$E_j=2^{2^j}-2^{2^{j-1}}-2$, and let
$N_n=\max_{2\le j\le n}\min(q_j,E_j)$.  Some $n$-input truth table has
$N^*(K)=N_n$ at a level $K\le n-2$, and
\begin{equation}\label{eq:residual-width}
  N_n\ge\frac{T}{4n}=\Omega\!\left(\frac{T}{\log T}\right).
\end{equation}
\end{lemma}

\begin{proof}
Fix a maximizing $j$ and put $K=n-j\le n-2$.  The level-$K$ residuals are
the $q_j$ consecutive blocks of length $2^j$, and they may be prescribed
independently.  A string of that length fails to be first-essential exactly
when its halves are equal ($2^{2^{j-1}}$ strings) or are distinct constants
(two strings), so $E_j$ strings are first-essential.  Prescribing
$\min(q_j,E_j)$ distinct first-essential blocks, and the remaining blocks
arbitrarily, gives $N^*(K)=N_n$.

For~\eqref{eq:residual-width} take $j=\lceil\log_2n\rceil+1$, which lies in
$[2,n]$.  Since $2^j\ge2n$,
$E_j\ge2^{2^j-1}-2\ge2^{2n-1}-2\ge2^n\ge q_j$, so
$N_n\ge q_j\ge2^{n-\log_2n-2}=T/(4n)$.
\end{proof}

We call such a table, together with its level $K$, \emph{maximal-width}.
Since $q_j$ doubles with $n$, $N_n$ is nondecreasing in $n$; for instance
$N_6=10$.

Besides the properties listed in Section~\ref{sec:model} we use two facts about the
decoded instruction list.  A \emph{register instruction} (a conjugate pair
$a\pm p^bi$) never moves the cursor except by one step; among them, the
\emph{reads} ($a=0$, $b\ge2$) overwrite the register with the next input
symbol and the \emph{prints} ($a=0$, $b=1$) emit a character.  Equal roots
sort into consecutive positions, so the positions of one input root value
form a run of consecutive reads, and the positions of one real root value a
run of consecutive control-flow instructions.  Call a maximal run of
consecutive register instructions a \emph{gap}, and a maximal run of
consecutive real instructions a \emph{real run}.  Gaps and real runs
alternate along the list.

For a cursor $c$ holding a read and $m\ge0$, let $H^{(m)}_c$ be the function
of $y\in\{0,1\}^m$ that the machine prints when started at $c$ on the input
stream $y$ followed by end of input, with any register value.  It does not
depend on that value, because the read at $c$ overwrites it.

\begin{lemma}[Next read]\label{lem:nextread}
Let $k\le n-2$, and let the residual $g$ after the prefix $b_1\cdots b_k$ be
first-essential.  Then
\begin{enumerate}
\item every input extending the prefix makes a $(k+1)$st read, at one
common cursor $c$, and prints nothing before it;
\item $g=H^{(n-k)}_c$;
\item $c$ is the last read of its gap, and a real instruction follows that
gap.
\end{enumerate}
\end{lemma}

\begin{proof}
Between the $k$th and the $(k+1)$st read the run consumes no input, so up to
the $(k+1)$st read it is the same for every extension of the prefix.  If it
halted or printed there, $g$ would be constant, since a program computing
the table prints exactly one character.  This proves~(1), and~(2) follows
because the state before the read at $c$ is $(c,r)$ for some register $r$,
which the read overwrites.

For~(3), let $y_1,y_2$ be the next two input bits, which exist as
$k\le n-2$.  After the read at $c$ the state is $(c+1,48+y_1)$.  Suppose the
instructions $c+1,c+2,\ldots$ are register instructions up to a read $c'$ or
to the end of the list.  They are executed in order for both values of
$y_1$; a fault among them would occur on a reachable input, so there is
none.  If one of them prints, that character is the program's output, and
$g$ is a function of $y_1$ alone.  Otherwise the run reaches $c'$, whose
read overwrites the register, and $g(y_1,\ldots)=H^{(n-k-1)}_{c'}$ does not
depend on $y_1$; or it reaches the end without printing, which a program
computing the table does not do.  Each case contradicts first-essentiality.
So a real instruction occurs after $c$, and no read lies between them.
\end{proof}

\begin{theorem}[First-essential count]\label{thm:count}
Let a decoded program contain $K_{\mathrm{in}}$ distinct input root values and $L$
distinct real root values, and let $G$ be the number of gaps that contain a
read and are followed by a real instruction.  Then for every $k\le n-2$
\[
  N^*(k)\ \le\ G\ \le\ \min(K_{\mathrm{in}},L).
\]
\end{theorem}

\begin{proof}
By Lemma~\ref{lem:nextread}(2) the first-essential residual after a prefix
of length $k$ is determined by the cursor $c$ of the $(k+1)$st read, so
distinct first-essential residuals at level $k$ have distinct cursors.  By
part~(3) each such cursor is the last read of a gap of the kind counted by
$G$, and a gap has only one last read.  This proves $N^*(k)\le G$.

The last read of a gap lies in a run of equal input roots, and that run lies
inside the gap; different gaps therefore give different input root values,
so $G\le K_{\mathrm{in}}$.  The real instruction after a counted gap begins a real run,
which consists of whole runs of equal real roots; different gaps are
followed by different real runs, so $G\le L$.
\end{proof}

\begin{corollary}\label{cor:roots}
Every Polynomial program for a maximal-width truth table has at least $N_n$
distinct input root values and at least $N_n$ distinct positive real
instruction roots.
\end{corollary}

\begin{proof}
Lemma~\ref{lem:maximal-width} gives a level $K\le n-2$ with $N^*(K)=N_n$;
apply Theorem~\ref{thm:count}.
\end{proof}

Indexing a residual by the cursor of the $k$th read instead would lose a
factor: the register still carries the bit just read, so one cursor could
carry two residuals, and the reads before it one more.  The $(k+1)$st read
erases that bit.  Noncrossing of the brackets is not used.

\begin{remark}[Gaps]\label{rem:gaps}
The first gap of the list can be entered only from the initial state, since
every jump lands just after a real instruction.  Its reads are therefore
the first reads of every input, and if the $(k+1)$st read lies there, then
$N^*(k)\le1$.  So $N^*(k)\le G-1$ whenever $N^*(k)\ge2$ and the first gap
contains a read.  A loop that reads an input-dependent number of bits is
covered too: its first-essential residuals are indexed by the next read, not
by the offset of the current one.
\end{remark}

\begin{lemma}[Prime powers]\label{lem:ppow}
Let $v_1<v_2<\cdots$ enumerate $\{p^b:p\text{ prime},\ b\ge2\}$.  Then
$v_j\ge(j+2)^2/4$ for every $j$.
\end{lemma}

\begin{proof}
The map $p^b\mapsto(p^{\lfloor b/2\rfloor},\,b\bmod2)$ is injective, since
$p^{\lfloor b/2\rfloor}$ is a prime power with exponent at least $1$ and so
determines $p$ and $\lfloor b/2\rfloor$.  Its first component lies in
$[2,\sqrt{p^b}]$.  So at most $2(\lfloor\sqrt X\rfloor-1)$ elements are at
most $X$.  Taking $X=v_j$ gives $j\le2(\sqrt{v_j}-1)$.
\end{proof}

The bound of Theorem~\ref{thm:count} is attained exactly, at the width
$\Theta(T/\log T)$ that matters for the bracket.  The same example shows
that one input root can carry first-essential residuals at many levels.

\begin{proposition}[Sharpness]\label{prop:sharp}
Let $K\ge6$, $Z=2^K-1$, let $W=2^m$ be the least power of two with
$W\ge3K+6$, and $n=K+m$.  There is a labelling
$\lambda:\Z/Z\Z\to\{0,1\}$ such that the table
\[
  f(X)=\lambda(X\bmod Z),\qquad X\in\{0,\dots,2^n-1\}\text{ read in binary},
\]
has a Polynomial program with exactly $Z$ input instructions, and
\[
  N^*(K)=Z=K_{\mathrm{in}},\qquad N^*(k)=2^k\ (k<K),\qquad
  \sum_{k\le K}N^*(k)=2K_{\mathrm{in}} .
\]
Moreover $N^*(K)>T/(6n)-1$.
\end{proposition}

\begin{proof}
\emph{The automaton.}  On the states $\Z/Z\Z$ let
$\delta(s,b)=2s+b\bmod Z$.  From $s_0=0$ the prefix $x$ of an input leads
to $x\bmod Z$, where $x$ is read as a binary number, and after all $n$ bits
the label $\lambda$ of the final state is $f$.  For $k\le K$ the prefixes
of length $k$ reach the $2^k$ states $0,\ldots,2^k-1$ when $k<K$, and every
state when $k=K$ (the prefixes $0^K$ and $1^K$ both reach $0$).  The
residual at a state $s$ reached at level $K$ is the window
$\omega_s(z)=\lambda(2^ms+z)$, $0\le z<W$, indices mod~$Z$.

\emph{The program.}  Keep the register equal to $-(s+1)$ while state $s$ is
active, inside a loop $\text{while}<0\,\{B_0\cdots B_{Z-1}\}$ entered after
$\mathord{+}\!=-1$.  Block $B_i$ is
\[
  \mathord{+}\!=1,\ \text{if}{=}0\,\{\ \text{input},\
  \text{if}<0\{\mathord{\%}\!=1,\ \mathord{+}\!=P_i\},\
  \mathord{-}\!=50,\ \text{if}<0\{\mathord{*}\!=A_i,\ \mathord{+}\!=B_i\}\ \},
\]
and after the loop come $\mathord{\%}\!=2$, $\mathord{+}\!=48$ and a print
(an operand-zero update is omitted).  Entering the loop body with
register $-(s+1)$, the register before the test of $B_i$ is $i-s$, so only
$B_s$ fires.  A bit $b$ becomes $-2$ or $-1$ after $\mathord{-}\!=50$, and
$A_i,B_i$ are chosen so that it becomes
$w_b=-(\delta(i,b)+1)-(Z-1-i)$ (if $\delta(i,0)=\delta(i,1)$, use
$\mathord{\%}\!=1$ and add the common value).  The later blocks add
$Z-1-i$ and never see zero, so the loop restarts with $-(\delta(i,b)+1)$.
End of input stores $-1$, which the inner test replaces by
$P_i=M+\varepsilon_i$ with $M>50$ and $\varepsilon_i\in\{0,1\}$ chosen so
that $P_i-50+Z-1-i\equiv\lambda(i)\pmod2$.  That value stays positive, skips
every later block, leaves the loop, and prints $48+\lambda(i)$.  There is one
input instruction per block, in different gaps, so $K_{\mathrm{in}}=Z$.

\emph{The labels.}  Take $\lambda$ uniformly at random.  Since $2^m$ is
invertible mod the odd number $Z$, the starts $a_s=2^ms$ are distinct.  For
$s\ne s'$ put $d=a_{s'}-a_s\ne0$.  The event $\omega_s=\omega_{s'}$ imposes
$\lambda(v)=\lambda(v+d)$ for the $W\le Z$ vertices $v=a_s+z$.  These are
$W$ distinct edges of the graph $\{v,v+d\}$ on $\Z/Z\Z$, a disjoint union
of cycles of length $Z/\gcd(d,Z)\ge3$.  A set of edges has rank equal to its
size minus the number of whole cycles it contains, so the rank is at least
$\frac23W$ and the probability is at most $2^{-2W/3}$.  In the same way a
window has equal halves with probability at most $2^{-W/3}$, and two
constant halves with probability $2^{2-W}$.  With $Z<2^K$ and
$W\ge3K+6$,
\[
  \binom Z2 2^{-2W/3}+Z\bigl(2^{-W/3}+2^{2-W}\bigr)
  <2^{-5}+2^{-2}+2^{-4}<1,
\]
so some $\lambda$ makes all $Z$ windows distinct and first-essential; the
condition $W\le Z$ holds because $W<6K+12\le2^K-1$ for $K\ge6$.  Then
$N^*(K)=Z$.

For $k<K$ the residual at $y\in\{0,\ldots,2^k-1\}$ is the concatenation,
in order of $z\in\{0,1\}^{K-k}$, of the windows at the states
$2^{K-k}y+z\bmod Z$.  For $y\ne y'$ and each $z$ these states differ, since
$2^{K-k}(y-y')\not\equiv0\pmod Z$, so the windows differ and so do the
residuals.  The two halves of the residual at $y$ are those at $2y$ and
$2y+1$ (single windows when $k=K-1$), which differ and are nonconstant, so
the residual is first-essential.  Hence $N^*(k)=2^k$ and
$\sum_{k\le K}N^*(k)=2^K-1+Z=2Z$.  Finally $K\le n-2$, and
$T=2^K W<(Z+1)(6K+12)\le6n(Z+1)$.
\end{proof}

Call a gap that contains a read a \emph{read gap}.  The first read reached
after any configuration is the first read of some read gap: every jump, and
every step past a real instruction, lands on the instruction after a real
instruction, so a gap is always entered at its first instruction and then
run straight through.

\begin{lemma}[Gap automaton]\label{lem:gapauto}
Let $\Gamma$ be the set of read gaps of a program that computes an
$n$-input table, and put $\mathrm{Out}=\{\mathtt0,\mathtt1,\bot\}$.  The table
is determined by the following data: an entry $e\in\Gamma\cup\mathrm{Out}$,
and for each $g\in\Gamma$ a number $m_g\in\{1,\dots,n+1\}$, two targets
$\delta_g(0),\delta_g(1)\in\Gamma\cup\mathrm{Out}$ and a label
$\lambda_g\in\mathrm{Out}$.  The semantics: at a gap $g$ with $\pi$ bits
consumed, move to $\delta_g(b)$ with $\pi+m_g$ bits consumed, where
$b=b_{\pi+m_g}$, if $\pi+m_g\le n$; otherwise stop with output $\lambda_g$.
\end{lemma}

\begin{proof}
Let $r_1<\dots<r_k$ be the reads of $g$.  Let $m_g$ be the least $i$ such
that a print lies between $r_i$ and $r_{i+1}$ (or after $r_k$ in the gap), and
$m_g=k$ if there is none; replace it by $\min(m_g,n+1)$.  If $m_g<k$, the
print after $r_{m_g}$ is executed on every path through it, so the output is
decided there: set $\delta_g(b)$ and $\lambda_g$ to the character it prints
from the read values $48+b$ and $-1$ ($\bot$ on a fault).  If $m_g=k$, run
the program from the instruction after $r_k$ with register $48+b$ (or $-1$)
until the first read or print: $\delta_g(b)$ (or $\lambda_g$) is the read
gap whose first read is reached, or the printed character, or $\bot$.  The
entry $e$ is defined in the same way from the initial configuration.

A read overwrites the register, and the reads before $r_{m_g}$ are followed
by straight-line code without prints, so from the first read of $g$ the run
depends only on the value read at $r_{m_g}$; that is the value
$48+b_{\pi+m_g}$, or $-1$ once the input is exhausted.  A program that
computes the table never faults and prints exactly once on an input, so
every configuration it reaches is described correctly by these data, and
its output is the first printed character.
\end{proof}

\begin{proposition}[Counting]\label{prop:counting}
For $n\ge7$ some $n$-input table has no program with fewer than $T/(n+4)$
distinct input root values.  More precisely, let $Z_n$ be the largest $Z$ with
\[
  B_n(Z)=\frac{(Z+1)(Z+3)\,\bigl(3(n+1)\bigr)^Z(Z+3)^{2Z}}{Z!}<2^T;
\]
then some table needs at least $Z_n+1$ input root values, and
$Z_n+1>T/(n+4)$.
\end{proposition}

\begin{proof}
Restrict the data of Lemma~\ref{lem:gapauto} to the read gaps reachable from
$e$ through the $\delta_g$; the table is still determined.  With $z$
reachable gaps numbered $1,\dots,z$ there are at most
$t_z=(z+3)\bigl(3(n+1)(z+3)^2\bigr)^z$ such data.  Renumbering the gaps
does not change the table, and a renumbering that fixes the data fixes every
gap reachable from $e$, hence is the identity; so the $z!$ renumberings of
one set of data are distinct, and at most $t_z/z!$ tables arise from $z$
reachable gaps.  The ratio of consecutive terms is at least
$3(n+1)(z+4)^2/(z+1)>1$, so programs with at most $Z$ read gaps compute at
most $B_n(Z)$ tables.  If $B_n(Z)<2^T$, some table needs more than $Z$ read
gaps.  The last reads of distinct read gaps have distinct root values, as in
the proof of Theorem~\ref{thm:count}, so that table needs at least $Z+1$
input root values.

For the estimate let $Z=\lfloor T/(n+4)\rfloor$.  From $Z!\ge(Z/e)^Z$ and
$(1+3/Z)^{2Z}\le e^6$,
\[
  \log_2B_n(Z)\le 2\log_2(Z+3)+6\log_2e+Z\log_2\bigl(3e(n+1)Z\bigr).
\]
Here $3e(n+1)Z\le3e\,2^n(n+1)/(n+4)<3e\,2^n$, so the last term is less than
$Z(n+\log_2 3e)\le T-(4-\log_23e)\,T/(n+4)$, and $4-\log_23e>0.97$.  For
$n\ge9$, $0.97\,T/(n+4)>2n+6\log_2e\ge2\log_2(Z+3)+6\log_2e$, so
$B_n(Z)<2^T$ and $Z_n\ge Z$.  For $n=7,8$ exact computation gives
$Z_7=12$ and $Z_8=22$, above $128/11$ and $256/12$.
\end{proof}

Proposition~\ref{prop:counting} needs neither Lemma~\ref{lem:maximal-width}
nor Theorem~\ref{thm:count}; it is the counting argument with the
relabelling symmetry.  Asymptotically $Z_n=T/(n+\log_23e+o(1))$, and exact
values are $Z_{12}=274$ and $Z_{16}=3470$, against $N_{12}=256$ and
$N_{16}=4096$.  Since $N_n=\nu_nT/n\,(1+o(1))$ with $\nu_n\in(\frac12,1+o(1)]$,
the counting bound is the larger one for most $n$, by up to a factor $2$.

\begin{remark}[Levels]\label{rem:levels}
In Proposition~\ref{prop:sharp} the state $s$ is reached at every level
from the bit length of $s$ up to $n$, and it carries a first-essential
residual at every such level up to $K$ (and, when its shorter windows are
distinct, beyond).  For instance the state $1$ is reached at every level $k\ge1$, by
$0^{k-1}1$, and carries a first-essential residual at each $k\le K$: a single
input root serves $K=n-\Theta(\log n)$ levels, and no inequality
$\sum_{k\le K}N^*(k)\le cK_{\mathrm{in}}$ with $c<2$ holds in general.  The same
happens for the maximal-width tables that the lower bound uses: a SAT
search for the smallest automaton that agrees with the table on
$\{0,1\}^n$, compiled as above and run on every input, gives programs with
$K_{\mathrm{in}}=9$ against $\sum_kN^*(k)=15$ and a leveled residual DAG of $21$
states ($n=5$, minimum proved), and $K_{\mathrm{in}}=15$ against $24$ and $33$
($n=6$).  The minimum input count of a table therefore lies between its
largest first-essential width and the size of its smallest such automaton,
and it is the latter, not the leveled DAG of the construction, that a
multi-level lower bound would have to reach.
\end{remark}

\begin{remark}[Levels and counting]\label{rem:levels-count}
Counting automata with $Z$ states gives about $2Z\log_2Z$ bits, but the
$Z!$ renumberings of one automaton compute the same table, and removing
them leaves $Z\log_2Z+O(Z\log n)$ bits.  So counting certifies about
$T/n$ read gaps (Proposition~\ref{prop:counting}), not $T/(2n)$.  This is
$N_n/\nu_n\ge N_n$, and the construction of Section~\ref{sec:upper}
matches it up to the factor $\frac32$ (Proposition~\ref{prop:dfaprog} with
Lemma~\ref{lem:strip}).
\end{remark}

\section{Coefficient mass from prescribed roots}\label{sec:mass}

Write
\[
  \Lambda(F)=\sum_{j:f_j\ne0}\log^+|f_j|,\qquad \log^+x=\max(0,\log x).
\]
The exponential-sum certificate machinery yields the following
degree-independent statement~\cite[Corollary~3.4]{coefficient-mass}.

\begin{theorem}[Coefficient-mass theorem]\label{thm:mass}
Let
\[
  P(x)=\prod_{i=1}^{L}(x-r_i),
  \qquad 2\le r_1\le\cdots\le r_L,
\]
with repetitions allowed, and let \(F(x)=\sum_{j=0}^{D}f_jx^j\in\R[x]\) be a
nonzero multiple of \(P\) with \(|f_D|\ge1\).  Then
\begin{equation}\label{eq:mass-general}
  \Lambda(F)
  \ge (L+1)\log|f_D| + \sum_{u=0}^{L-1}
       \sum_{i=u+1}^{L}\log(r_i-1).
\end{equation}
\end{theorem}

Each \(\log(r_i-1)\) occurs \(i\) times on the right.  For the first \(L\)
primes, or for increasing roots bounded below by them, \(r_i\ge i+1\) and
the right side is at least \((1/2+o(1))L^2\log L\).  This is asymptotically
sharp: \(\Lambda(P_L)\le(1/2+o(1))L^2\log L\) for
\(P_L=\prod_{i=1}^L(x-p_i)\).  The theorem applies to every real multiple,
independently of its degree and additional roots.

\begin{corollary}[Polynomial lower bound]\label{cor:lower}
Every Polynomial source for a maximal-width truth table has
\[
  |f|=\Omega(T^2/\log T).
\]
\end{corollary}

\begin{proof}
By Corollary~\ref{cor:roots}, the program contains
\(L=\Omega(T/\log T)\) distinct positive real instruction roots.  They are
distinct integers \(\ge2\), so after sorting \(r_i\ge i+1\), and the weighted
sum in Theorem~\ref{thm:mass} is at least
\(\sum_{i\le L}i\log i=(1/2+o(1))L^2\log L\).  The source polynomial
is an integer multiple of their distinct-root product and its leading
coefficient has absolute value at least one.  Theorem~\ref{thm:mass} gives
\[
 \Lambda(f)=\Omega(L^2\log L)
           =\Omega\!\left(\frac{T^2}{\log T}\right).
\]
Since integer coefficients satisfy
$M(f)\ge\Lambda(f)/\log 10$ and $|f|\ge M(f)$, the result follows.
\end{proof}

\begin{remark}[Repeated roots]
Repeated real roots do not weaken Corollary~\ref{cor:lower}:
Theorem~\ref{thm:count} already forces the stated number of distinct values,
and Theorem~\ref{thm:mass} is stated for roots counted with multiplicity.
\end{remark}

\section{The matching construction}\label{sec:upper}

The residual DAG of a truth table has at most
\[
  s_k=\min\bigl(2^k,2^{2^{n-k}}\bigr)
\]
states after $k$ reads: the first term counts input prefixes, and the second
counts Boolean residuals of the remaining width.  Put
$h=\lfloor\log_2 n\rfloor-1$.  The levels with $n-k\le h$ contribute
$O(\sqrt T)=O(T/n)$ states; the earlier levels form a geometric tail
of size $O(T/2^h)=O(T/n)$.  Hence
\[
  S\coloneqq\sum_k s_k=O(T/\log T).
\]

Label the states at every level by $0,\ldots,s_k-1$.  Enter level $k$ with
register $-j$ when state $j$ is active.  Its blocks are scanned in label
order: block $j$ increments the register and opens an ``if positive'', so
exactly block $j$ fires.  That block reads the next bit, overwriting the
register with $48+b$.  If its child labels are $z,o$, multiply by $z-o$ and
add $-(z+r)-48(z-o)$, where $r$ is the number of blocks remaining at that
level.  This sends $48$ to $-(z+r)$ and $49$ to $-(o+r)$.  The skipped blocks
each increment once, leaving $-z$ or $-o$ at the next level.  Equal children
instead floor-divide $48+b$ by $50$, obtaining zero, then add $-(z+r)$.  At
the leaf level the unique active block adjusts the register to $48$ or $49$,
prints, and leaves the register negative.

Thus induction on the levels proves that
the machine follows exactly the residual selected by the input and prints its
table value.  Each state block uses at most six instructions, its brackets
are local and therefore properly matched, and every operand is $O(S)$.  An
update whose operand would be zero is omitted: the language spells a zero
operand as I/O, and dropping it leaves the register unchanged, which is what
a zero update does.

Encode the resulting $m=O(S)$ instructions in order, using one fresh prime
per instruction.  Real instructions give linear factors and register
instructions conjugate quadratic factors; multiplying them gives an integer
polynomial decoded back to that list.  Instruction exponents are bounded
constants.  The prime number theorem~\cite{rs} gives the standard estimate
$p_m=O(m\log m)$ for the largest assigned prime.  Every
linear or quadratic factor therefore has
coefficient $\ell^1$ norm $m^{O(1)}$.  Submultiplicativity gives coefficient
norm $m^{O(m)}$ for their product, so each expanded coefficient has
$O(m\log m)$ decimal digits.  There are at most $2m+1$ coefficients, while
exponents and separators contribute only $O(m\log m)$.  Therefore
\[
  |f|=O(m^2\log m)
      =O\!\left(\frac{T^2}{\log T}\right).
\]
Together with Corollary~\ref{cor:lower}, this proves
Theorem~\ref{thm:main}.

The construction of Section~\ref{sec:upper} spends one state per residual
at every level.  A program can share states across levels, because its
state between reads is only the cursor of the next read.  The next lemma
is an explicit way to share them for every table.

Fix $d\ge1$ and a word $c\in\{0,1\}^d$.  Call a word \emph{canonical} if it
does not begin with $c$, and let $\operatorname{st}(w)$ be $w$ with its
leading copies of $c$ removed, so that $w=c^i\operatorname{st}(w)$ with
$\operatorname{st}(w)$ canonical and $i$ unique.  For a canonical $u$ with
$|u|\le n$ let $V(u)$ be the tuple of residuals of the table after the
prefixes $c^iu$, $0\le i\le(n-|u|)/d$: the $i$-th entry is a Boolean
function of $n-|u|-di$ bits, or a single table value when that number is
$0$.

\begin{lemma}[Stripped automaton]\label{lem:strip}
Let $d\le L\le n$.  For a word $w$ with $|w|\le n$ and $u=\operatorname{st}(w)$,
put $\sigma(w)=u$ if $|u|\le L$ and $\sigma(w)=(|u|,V(u))$ otherwise.  Then
$\sigma(wb)$ depends only on $\sigma(w)$ and $b$, and $\sigma(w)$ with
$|w|=n$ determines the table value at $w$.  So the values of $\sigma$ are
the states of an automaton that computes the table.  At level $\ell=|u|$
there are
\[
  \kappa_\ell=2^\ell-[\ell\ge d]\,2^{\ell-d}
\]
states $u$ with $\ell\le L$, and at most $\min\bigl(\kappa_\ell,2^{E_d(n-\ell)}\bigr)$
states $(\ell,V)$ with $\ell>L$, where
$E_d(m)=\sum_{0\le i\le m/d}2^{m-di}$.  A state at level $\ell$ is reached
only after $\ell+di$ bits, $i\ge0$, so only states with $d\mid n-\ell$ are
reached after $n$ bits.
\end{lemma}

\begin{proof}
Write $w=c^iu$.  If $|u|\ge d$, then $ub$ does not begin with $c$, since its
first $d$ letters are those of $u$; so $\operatorname{st}(wb)=ub$.  If
$|u|<d$, then $ub$ begins with $c$ only if $ub=c$, and then
$\operatorname{st}(wb)$ is empty; otherwise it is $ub$.  So
$\operatorname{st}(wb)$ is a function of $u$ and $b$, which settles the
states with $|u|\le L$ (note $L\ge d$).  If $|u|>L$, then
$\operatorname{st}(wb)=ub$ with $|ub|>L$, and the $i$-th entry of $V(ub)$,
the residual after $c^iub$, is the $i$-th entry of $V(u)$ restricted to
first bit $b$ (entries of length $0$ are dropped).  So
$(|ub|,V(ub))$ is a function of $(|u|,V(u))$ and $b$.  For $|w|=n$ we have
$i=(n-|u|)/d$, so $u$ determines $w$, and $V(u)$ contains the value at $w$
as its entry of length~$0$.  The counts are the number of canonical words
of length $\ell$ and the number of tuples of functions of
$n-\ell-di$ bits.
\end{proof}

For $d$ large, Lemma~\ref{lem:strip} is the residual DAG.  The program for an
automaton needs a way to turn the bit read into the next state that does
not depend on the order of the states.  A single multiplication does it,
followed by a shared decoder.

\begin{lemma}[Threshold decoder]\label{lem:decoder}
Let $W,R\ge1$, $G=\lfloor(R+48)/48\rfloor+1$,
$M=48\bigl((W^2-1)G+1\bigr)+R+1$ and $\alpha^+=M+(W^2-1)G+1$.  For
$0\le z,o<W$ and $\varepsilon\in\{0,1\}$ put
$\alpha(z,o,\varepsilon)=M+(zW+o)G+\varepsilon$.  There is a fixed list
$\mathrm{Dec}_{W,R}$ of $17$ instructions, with operands of size
$O(W^2R)$ and no zero operand, that sends every register value
$y=-\alpha(z,o,\varepsilon)(48+b)+D$ with $b\in\{0,1\}$ and $0\le D\le R$
to $-z$ if $b=0$ and to $-o$ if $b=1$.
\end{lemma}

\begin{proof}
Let $t=48\alpha^+$.  The list is
\[
\begin{aligned}
 &\mathord{+}\!=t,\ \text{if}<0\,\{\ \mathord{*}\!=-1,\ \mathord{+}\!=-1,\
   /\!/\!=49G,\ \mathord{\%}\!=W,\ \mathord{*}\!=-1,\ \mathord{+}\!=-1\ \},\\
 &\mathord{+}\!=1,\ \text{if}>0\,\{\ \mathord{*}\!=-1,\
   \mathord{+}\!=t+1-48M+R,\ /\!/\!=48G,\ /\!/\!=W,\ \mathord{*}\!=-1\ \}.
\end{aligned}
\]
Put $\alpha=\alpha(z,o,\varepsilon)\in[M,\alpha^+]$, $k=zW+o$, and
$v=y+t$.  If $b=1$ then $v\le-49M+R+48\alpha^+<0$, by the choice of $M$;
if $b=0$ then $v\ge-48\alpha^++t=0$.  In the first branch
$-v-1=49\alpha-D-t-1$, and $t-49M+R=-1$ by the choice of $M$, so the
register becomes $49(\alpha-M)+R-D=49kG+(49\varepsilon+R-D)$.  The
bracket lies in $[0,49+R]\subset[0,49G)$, so floor division by $49G$ gives
$k$, the remainder by $W$ gives $o$, and the branch leaves $-o-1$.  Then
$\mathord{+}\!=1$ gives $-o\le0$ and the second test fails.  If $b=0$ the
first test fails, $\mathord{+}\!=1$ gives $v+1\ge1$, and the second branch
makes $48(\alpha-M)+R-D=48kG+(48\varepsilon+R-D)$ with the bracket in
$[0,48G)$, then $k$, then $z$, then $-z$.  Every operand is nonzero, since
$t+1-48M+R=48\bigl((W^2-1)G+1\bigr)+R+1$.  Python's floor division and
remainder agree with these values because the operands are nonnegative
there.
\end{proof}

\begin{proposition}[Automaton programs]\label{prop:dfaprog}
Let an automaton with state set $Q$, start $q_0$, transitions $\delta$ and
labels $\lambda$ compute an $n$-input table, and let $E\subseteq Q$ contain
every state reached after $n$ bits.  Then the table has a program whose
instructions are $O(1)$ fixed ones plus
\begin{itemize}
\item for each pair of states of $Q\setminus E$ (and one leftover state):
 $\mathord{+}\!=2$, $\text{if}>0$, input, $\mathord{*}\!=A$, endif,
 $\text{if}=0$, input, $\mathord{*}\!=A'$, endif;
\item for each state of $E$: $\mathord{+}\!=1$, $\text{if}=0$, input,
 $\mathord{*}\!=A$, endif,
\end{itemize}
with all operands $O(|Q|^3)$.  For the residual DAG of
Section~\ref{sec:upper}, read level by level, the same holds with $E$ empty
and $O(n)$ fixed instructions.
\end{proposition}

\begin{proof}
Order the states with $Q\setminus E$ first, grouped in pairs, then $E$.  The
groups add $2$ (a pair or the leftover state) or $1$ (a state of $E$); let
$C_i$ be the running sum up to group $i$ and $C$ the total.  Give the first
state of a pair, and the leftover state, the code $C_i-1$; give the second
state of a pair, and a state of $E$, the code $C_i$.  Put $W=C+1$, $R=C$,
and take $G,M,\alpha$ from Lemma~\ref{lem:decoder}.  A state $q$ with
children $q^0,q^1$ gets $A=-\alpha(c(q^0),c(q^1),\varepsilon_q)$.  The
program is
\[
  \mathord{+}\!=-48\alpha(c(q_0),c(q_0),0),\quad
  \text{while}<0\,\{\ \mathrm{Dec}_{W,R},\ \text{groups}\ \},\quad
  \mathord{\%}\!=2,\ \mathord{+}\!=48,\ \text{output}.
\]

If the register is $-c(q)$ before the groups, the value tested in group
$i$ is $C_i-c(q)$.  It is at most $-1$ before the group of $q$, and in that
group it is $1$ for the $\text{if}>0$ of a first or leftover state and $0$
for an $\text{if}=0$.  So exactly the block of $q$ fires.  It reads; a bit
$b$ gives $-\alpha_q(48+b)\le-48M$, which no later test fires on, and the
groups after it add $D\in[0,R]$.  The value stays negative, the loop
repeats, and Lemma~\ref{lem:decoder} turns it into $-c(q^b)$.  The first
pass starts from the value that Lemma~\ref{lem:decoder} decodes to
$-c(q_0)$.  So after $j$ bits the register selects the state reached by
those bits.  A state outside $E$ never reads past the input.  A state
$q\in E$ that reads the end of input gets $-1$ and then $\alpha_q>0$.  All
later groups belong to $E$ and test only $=0$, so none fires, and the loop
ends with $\alpha_q+D$.  Choosing $\varepsilon_q$ makes its parity
$\lambda(q)$, so the program prints $48+\lambda(q)$.  The operands are
$O(W^2R)=O(|Q|^3)$.

For the residual DAG, run the levels in order without the loop.  Level $k$
has only paired groups, $\mathrm{Dec}_{W_k,R_k}$ follows it, and after the
last level the codes of the two leaves are their labels.  The register then
holds $-\lambda$, and $\mathord{*}\!=-1$, $\mathord{+}\!=48$ and an output
print it.  The start value is $-1$, the code of the root.
\end{proof}

Every construction here was compiled and run with the interpreter's
\texttt{\_advance} on all $2^n$ inputs for $n\le11$: random, maximal-width,
parity and constant tables, $d=1,2,3$ and the leveled form.  Several were
also expanded to source, parsed back to the same list, and run through the
public entry point.

\section{Explicit constants}\label{sec:constants}

Theorem~\ref{thm:main} is a statement of order.  This section tracks the
constants through both halves, normalizing $C_P(n)$ by
$T^2/n=T^2/\log_2T$.  The lower side charges the input roots:
Corollary~\ref{cor:roots} and Proposition~\ref{prop:counting} force
$\max(N_n,\lceil T/(n+4)\rceil)$ of them, and the imaginary-pair form
of the coefficient-mass theorem~\cite[Corollary~5.3]{coefficient-mass}
prices each pair $\pm ci$ as one real root $c^2$.  This beats the
real roots with Theorem~\ref{thm:mass} by a factor $4$.  The upper side
counts the exponents of the roots that the automaton programs of
Proposition~\ref{prop:dfaprog} use.

For a multiset of positive root exponents let $\Phi=\sum_ii\,b_{(i)}$, taken
in increasing order.

\begin{lemma}[Profiles]\label{lem:profile}
Let a program have, besides $O(n)$ further roots, $h$ paired states and
$e$ states of $E$ in the sense of Proposition~\ref{prop:dfaprog}.  Put
$\varphi=e/(h+e)$ and $S=h+e$.  Then
\[
  \Phi=f(\varphi)\,S^2+O(nS),\qquad
  f(\varphi)=\tfrac12\Bigl(4(7+\varphi)^2-\tfrac14\bigl((3+\varphi)^2+(9+\varphi)^2+(13+\varphi)^2\bigr)\Bigr).
\]
In particular $f(0)=\frac{525}8$, $f(\frac13)=\frac{1315}{18}$ and
$f(\frac23)=\frac{5821}{72}$.
\end{lemma}

\begin{proof}
An addition has the exponent $1$, a multiplication $3$ and a read $2$ (each
a conjugate pair, so two roots); the tests ``positive'' and ``zero'' and the
closing bracket are real roots of exponent $1$, $4$ and $2$.  So a pair has
the exponents $1,1$ ($\mathord{+}\!=2$), $1$ ($\text{if}>0$), $4$
($\text{if}=0$), $2,2$ (the two endifs), $2,2,2,2$ (the reads) and
$3,3,3,3$ (the multiplications), and a state of $E$ has $1,1,4,2,2,2,3,3$.
Per state there are $c_1=\frac{3+\varphi}2$, $c_2=3$, $c_3=2$ and
$c_4=\frac{1+\varphi}2$ roots of exponent $b$.  Sorting puts the
exponent-$b$ roots at ranks $C_{b-1}S<i\le C_bS$, with
$C_b=\sum_{b'\le b}c_{b'}$.  So $\Phi=\frac{S^2}2\sum_bb\,(C_b^2-C_{b-1}^2)+O(S)$,
and this equals $\frac{S^2}2\bigl(4C_4^2-C_1^2-C_2^2-C_3^2\bigr)$.  The
$O(n)$ other roots shift ranks by $O(n)$.
\end{proof}

\begin{proposition}[Explicit bracket]\label{prop:bracket}
Let $N_n$ be as in Lemma~\ref{lem:maximal-width},
$v_j$ as in Lemma~\ref{lem:ppow}, and $s_k$ as in Section~\ref{sec:upper}.  Put
$S_n=\sum_{k<n}s_k$ and $K_n=\max\bigl(N_n,\lceil T/(n+4)\rceil\bigr)$, and for
$d\ge1$ let $h_{d,n}$ and $e_{d,n}$ bound the numbers of states of
Lemma~\ref{lem:strip} with $d\nmid n-\ell$ and with $d\mid n-\ell$, as
there with $L=d$, and $\varphi_{d,n}=e_{d,n}/(h_{d,n}+e_{d,n})$.  Then:
\begin{enumerate}
\item for every $n\ge7$,
\[
  C_P(n)\ \ge\ \frac1{\log10}\sum_{j=1}^{K_n}j\log(v_j^2-1)
        \ \ge\ \frac{2K_n^2\log K_n-\frac52K_n(K_n+1)}{\log10};
\]
\item every $n$-input table has a program with
\[
  |f|\le\bigl(1+O(1/n)\bigr)\,n\log_{10}2\cdot\Phi^*_n,\quad
  \Phi^*_n=\min\Bigl(\tfrac{525}8S_n^2,\ \min_{d\ge1}f(\varphi_{d,n})(h_{d,n}+e_{d,n})^2\Bigr)+O(nS_n).
\]
\end{enumerate}
Put $j_1=\min\{j:2^j+j\ge n\}$, $\nu_n=n/2^{j_1}$, write
$n=2^{j_1-1}+j_1-1+s$ with $s\ge1$, and let $u=2^{-s}$.  Then
\begin{equation}\label{eq:bracket-n}
  \Bigl(1-O\bigl(\tfrac{\log n}n\bigr)\Bigr)2\log_{10}2
  \ \le\ \frac{C_P(n)\,n}{T^2}\ \le\
  \bigl(1+o(1)\bigr)\log_{10}2\cdot\min\Bigl(\tfrac{525}2\nu_n^2(1+u)^2,\ \tfrac94f_{j_1}\nu_n^2\Bigr),
\end{equation}
where the second term is present when $n\ge\frac452^{j_1}$, and
$f_j=\frac{5821}{72}$ for even $j$, $f_j=\frac{1315}{18}$ for odd $j$.
Consequently
\[
  2\log_{10}2\le\liminf_{n\to\infty}\frac{C_P(n)\,n}{T^2}\le\frac{525}8\log_{10}2,
  \qquad
  2\log_{10}2\le\limsup_{n\to\infty}\frac{C_P(n)\,n}{T^2}\le\frac{5821}{32}\log_{10}2 .
\]
Numerically, $0.602\le\liminf\le19.76$ and $0.602\le\limsup\le54.76$.
\end{proposition}

\begin{proof}
\emph{Lower bound.}  By Corollary~\ref{cor:roots} and
Proposition~\ref{prop:counting}, some table needs at least $K_n$ distinct
input root values $\pm c_ji$ in every program.  Each $x^2+c_j^2$ divides the
source $f$, so their product does, and $|f_D|\ge1$ as $f$ has integer
coefficients.  The $c_j$ are distinct elements of $\{p^b:b\ge2\}$, so the
$j$th smallest is at least $v_j\ge4$, and $c_j^2\ge16$.
By~\cite[Corollary~5.3]{coefficient-mass},
$\Lambda(f)\ge\sum_{j\le K_n}j\log(c_{(j)}^2-1)\ge\sum_{j\le K_n}j\log(v_j^2-1)$,
and $|f|\ge M(f)\ge\Lambda(f)/\log10$ gives the first inequality.

For the second, Lemma~\ref{lem:ppow} gives
$v_j^2-1\ge(j+2)^4/16-1\ge\frac{65}{1296}(j+2)^4$, the last because
$(j+2)^4\ge81$.  So $\log(v_j^2-1)\ge4\log j-\log\frac{1296}{65}$, and
$\log\frac{1296}{65}<2.993$.  With
$\sum_{j\le K}j\log j\ge\int_1^Kx\log x\,dx=\frac{K^2}2\log K-\frac{K^2}4+\frac14$,
\[
  \sum_{j\le K}j\log(v_j^2-1)\ \ge\ 2K^2\log K-K^2-1.4965\,K(K+1)
  \ \ge\ 2K^2\log K-\tfrac52K(K+1).
\]
With $K=K_n\ge T/(n+4)$ and $\log K\ge n\log2-\log(n+4)$, the right side
is at least $2\bigl(\tfrac n{n+4}\bigr)^2\log_{10}2\,\bigl(1-O(\tfrac{\log n}n)\bigr)T^2/n$,
which is the left side of~\eqref{eq:bracket-n}.

\emph{Upper bound, item 2.}  Proposition~\ref{prop:dfaprog} applied to the
residual DAG, or to the automaton of Lemma~\ref{lem:strip} with $L=d$ and
$E$ the states with $d\mid n-\ell$, gives programs whose exponent multisets
are those of Lemma~\ref{lem:profile}, with $O(n)$ further roots.  There are
$S_n$ states in the first case and at most $h_{d,n}+e_{d,n}$ in the
second, and $\Phi$ only grows when a state of $Q\setminus E$ is moved to $E$
or a state is added.

Every nonleading coefficient is an elementary symmetric function of the
$D=O(S_n)$ roots, and all moduli exceed~$1$, so
\[
  \Lambda(f)\le\sum_{k}\log\binom Dk+\sum_{i}i\log|\rho|_{(i)} ,
\]
the second sum taken over the moduli in increasing order.  Write
$\log|\rho|\le b\log P+\varepsilon_\rho$, where $P$ is the largest prime and
$\varepsilon_\rho=\log(1+|a|/p^b)$.  By the rearrangement inequality the
second sum is at most $\Phi\log P+D\sum_\rho\varepsilon_\rho$.  Consecutive
instructions share a prime when their decode keys do not decrease, and at
most four share one, so there are $O(S_n)$ primes and~\cite{rs} gives
$\log P=n\log2+O(1)$.  The operands are $O(S_n^3)$, and apart from $O(1)$
decoder instructions only the multiplications, of exponent $3$, carry
operands above $O(1)$; so only the $O(S_n/\log S_n)$ roots whose prime is
below a fixed multiple of $S_n$ have $\varepsilon_\rho>\log2$, and each has
$\varepsilon_\rho=O(\log S_n)$.  Hence $D\sum\varepsilon_\rho=O(S_n^2)$, and
also $\sum_k\log\binom Dk=O(S_n^2)$.  Rendering adds at most $D+1$ digits and
$O(D\log D)$ further characters.  Dividing by $\log10$ proves the second
item.

\emph{Asymptotics.}  As $2^{j}\ge n-j$ exactly when $j\ge j_1$, the levels
$k<n-j_1$ have $s_k=2^k$, and $S_n=2q_{j_1}(1+u)(1+o(1))$ with
$q_{j_1}=2^{n-j_1}=\nu_nT/n$.  So the first term is
$\frac{525}8S_n^2n^2/T^2=\frac{525}2\nu_n^2(1+u)^2(1+o(1))$.  For
the second, take $d=2$ and $j=j_1$, so $\kappa_\ell=\frac342^\ell$ and
$E_2(m)=(2^{m+2}-2^{m\bmod2})/3$.  Since $n\le2^j+j$ and
$E_2(j)\ge\frac432^j-\frac23$, level $n-j$ has $\kappa\le2^{E_2}$.  If
$n\ge\frac452^j$ and $j\ge7$, every level $\ell>n-j$ has at most
$2^{E_2(j-1)}\le2^{\frac232^j}$ states, together at most
$j\,2^{\frac232^j}=o(2^{n-j})$, because
$\frac452^j-j-\frac232^j-\log_2j\to\infty$.  So
$h+e=\frac322^{n-j}(1+o(1))=\frac32\nu_nT/n\,(1+o(1))$.  The states with
$2\mid n-\ell$ at levels $\ell\le n-j$ are a fraction $\frac23$ of them when
$j$ is even and $\frac13$ when $j$ is odd.  This gives the term
$\frac94f_{j_1}\nu_n^2$.

For the limits, the first term tends to $\frac{525}8$ along
$n=2^{j-1}+2j$, where $\nu_n\to\frac12$ and $u\to0$.  For the limit
superior, suppose $n<\frac452^{j_1}$, so $\nu_n<\frac45$.  Either $s\le6$,
and then $\nu_n\to\frac12$ and $\nu_n(1+u)\le\frac34+o(1)$; or $u\le2^{-7}$,
and then $\nu_n(1+u)<0.81$.  Both are below $\sqrt{5821/8400}=0.8324\ldots$,
where $\frac{525}2x^2=\frac{5821}{32}$.  Otherwise the second term applies,
with $\frac94f_{j_1}\le\frac{5821}{32}$ and $\nu_n\le1+j_1/2^{j_1}$.
\end{proof}

\begin{remark}[What the bracket says]\label{rem:bracket}
The two sides of~\eqref{eq:bracket-n} differ by the factor
$\frac{525}{16}=32.8$ at the limit inferior and $\frac{5821}{64}=90.95$ at
the limit superior.  So Proposition~\ref{prop:bracket} fixes the order, but
it does not fix the constant.  The factor splits as follows.
\begin{itemize}
\item \emph{Routing contributes nothing.}  The lower bound credits one input
root value to every first-essential residual at one level
(Theorem~\ref{thm:count}), and Proposition~\ref{prop:sharp} shows the credit
cannot be raised.
\item \emph{Levels: $(S/(T/n))^2\in[1,\frac94]$.}  The lower bound charges
$T/n$ input values (Proposition~\ref{prop:counting}).  The residual DAG has
$S_n=2\nu_n(1+u)T/n$ states, which is $T/n$ when $\nu_n\to\frac12$: there the
state count is sharp to first order.  Near $\nu_n=1$ the DAG pays $2T/n$ and
the stripped automaton of Lemma~\ref{lem:strip} pays $\frac32T/n$, for every
table.  For general $d$ its cost oscillates like
$2^{\{\log_2n-\log_2(1-2^{-d})^{-1}\}}$, and the phases $d=2$ and $d=\infty$
leave the worst point at $\frac32$.  Whether some automaton does better for
all tables near $\nu_n=1$ is open; the true minimum lies in
$[1,\frac32]\cdot T/n$.
\item \emph{Profile: $f/2$, from $\frac{525}{16}$ to $\frac{5821}{144}$.}
The lower bound charges each input pair as one real root $c^2$, which is
exact for pairs alone~\cite[Corollary~5.3]{coefficient-mass}, and
$\sum_{j\le K}j\log v_j^2\sim2K^2\log K$ gives the mass constant $2$.  The
construction pays $f(\varphi)$ per state squared: $\frac{525}8$ counts the
reads ($2,2$), the brackets ($1$ or $4$, and $2$), a multiplication
($3,3$), and half an increment ($1,1$).  The threshold decoder of
Lemma~\ref{lem:decoder} removes a per-state addition and the equal-children
case, and the paired dispatch shares the increment.  States that can read
the end of input pay $\text{if}=0$ instead of $\text{if}>0$, which gives the
factor $f(\frac23)/f(0)=1.232$ at the limit superior.  Within this
block-dispatch design a state needs a multiplication to separate its two
children, since one register only allows threshold tests.
\end{itemize}
Charging the forced real roots together with the input pairs would help,
but the multisection proof of~\cite[Corollary~5.3]{coefficient-mass} needs
$P=R(x^2)$ with all roots of $R$ of one sign.  The real roots $p^v$ break
the first condition, and passing to $F(x)F(-x)$ breaks the second.  The
order-statistic bound for arbitrary free positions
(\cite[Lemma~3.1]{coefficient-mass}) is already sharp
(\cite[Corollary~3.6]{coefficient-mass}), so no sharpening of the mass step
alone narrows the bracket.
\end{remark}

\paragraph{Reproducibility.}
Executable checks cover the finite block-counting identities and repeated-root
cases used here.  They support the proof, but no bounded computation is used
as a premise.
