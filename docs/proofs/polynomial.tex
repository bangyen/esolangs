\title{A Tight Text-Complexity Bound for the Polynomial Language}
\author{The \texttt{esolangs} project}
\date{September 2026}

\begin{abstract}
In the Polynomial esoteric programming language, the roots of an
integer polynomial encode the instructions of a one-register machine, while
the source text lists the polynomial's expanded coefficients.  We prove that
some Boolean functions with truth-table length $T$ require
$\Omega(T^2/\log T)$ source characters in every Polynomial program,
independently of the program's degree, operand signs, and additional roots.
An explicit residual-DAG construction gives the matching
$O(T^2/\log T)$ upper bound for every Boolean function.  The main algebraic
ingredient is a sharp $\ell^1$ bound for exponential sums with prescribed
integer zeros.  It implies that every real polynomial divisible by $L$
distinct prime-power roots has coefficient mass
$\Omega(L^2\log L)$.  A routing argument, sharpened by an outerplanar
block-incidence bound, forces $L=\Omega(T/\log T)$ distinct real roots in a
program for a maximal-width table.
\end{abstract}

\section{The language and the result}

A Polynomial source is the expanded form
\[
  f(x)=\sum_{j=0}^{D} f_jx^j,\qquad f_j\in\Z.
\]
The interpreter factors $f$ over the integers and orders the recognised
roots by their associated primes.  A positive real root $p^v$ encodes a
control-flow instruction; a conjugate pair $a\pm p^b i$ encodes a register
instruction.  Unrecognised roots are ignored, so a source may be any integer
multiple of the product of its instruction factors.  Repeated recognised
roots produce repeated instructions.

The machine has an integer register and an instruction cursor.  Its input
instruction overwrites the register with the next input bit.  Real-root
instructions are the bracket-like control-flow operations; complex-root
instructions update the register.  The precise instruction table is not
needed below.  We use only the following properties of the interpreter.

\begin{enumerate}
\item Between two input reads the complete state is the pair consisting of
the register and the instruction cursor.
\item Each real instruction root is a positive power of the prime assigned to
its position in the decoded instruction list.
\item Equal real roots occur in one contiguous block after root sorting.
\item The bracket matching is noncrossing.
\end{enumerate}

The length $|f|$ of a source is the number of characters in its expanded
decimal representation.  Its coefficient-digit mass is
\[
  M(f)=\sum_{j:f_j\ne0}\bigl(1+\lfloor\log_{10}|f_j|\rfloor\bigr).
\]
Plainly $|f|\ge M(f)$.  Let $T=2^n$ be the length of the truth table of an
$n$-input Boolean function.

\begin{theorem}[Main theorem]\label{thm:main}
There are $n$-input Boolean functions for which every Polynomial program has
length
\[
  \Omega\!\left(\frac{T^2}{\log T}\right).
\]
Every $n$-input Boolean function has a Polynomial program of length
$O(T^2/\log T)$.  Thus the worst-case Polynomial text complexity is
$\Theta(T^2/\log T)$.
\end{theorem}

The lower bound has two independent parts.  Section~\ref{sec:routing} forces
$\Omega(T/\log T)$ distinct positive roots.  Sections~\ref{sec:tail}
and~\ref{sec:mass} show that every polynomial containing those roots has
coefficient mass $\Omega(T^2/\log T)$.  Section~\ref{sec:upper} supplies the
matching construction.

\section{Routing forces distinct real roots}\label{sec:routing}

Fix an order of the $n$ input variables.  After the first $k$ reads, each
input prefix determines a residual Boolean function of the remaining
$n-k$ variables.  Write $N(k)$ for the number of distinct residuals at that
level, $N'(k)$ for the nonconstant ones, and $E(k)$ for the residuals whose
two children are equal.

\begin{lemma}[Maximal-width tables]\label{lem:maximal-width}
For every sufficiently large $n$, there is an $n$-input truth table such
that, under every variable order, some level $k$ satisfies
\begin{equation}\label{eq:residual-width}
  N'(k+1)-E(k)=\Omega(T/\log T).
\end{equation}
\end{lemma}

\begin{proof}
Choose a truth table uniformly at random.  Put
$\ell=\lceil\log_2 n\rceil+1$ and expose the residuals after
$k=n-\ell$ variables.  For any fixed variable order, the
$q=2^k=\Theta(T/n)$ residuals occupy disjoint blocks of the truth table and
are therefore independent uniform strings of length
$R=2^\ell\in[2n,4n)$.  Their $2q$ children at level $k+1$ are independent
uniform strings of length $R/2\in[n,2n)$.  Two prescribed children agree
with probability $2^{-R/2}$, and a prescribed parent has equal children with
the same probability.

If $N'(k+1)-E(k)<q/2$, then either at least $q/4$ parents have equal children
or the child occupancy experiment has at least $q/4$ repetitions (constant
children count as repetitions against either constant string).  A binomial
tail bounds the first event by $\exp(-\Omega(qn))$.  For the second, the
expected number of colliding child pairs is $O(q/n)$; the standard factorial-
moment bound for the occupancy problem gives
\[
  \Pr\{\text{at least }q/4\text{ repetitions}\}
  \le \exp(-\Omega(q\log n)).
\]
There are only $n!$ input orders, and
$\log(n!)=O(n\log n)=o(q\log n)$, so with positive probability every order has
$N'(k+1)-E(k)\ge q/2$.  Since $q=\Theta(T/\log T)$, such a table satisfies
\eqref{eq:residual-width}.
\end{proof}

We call any table satisfying Lemma~\ref{lem:maximal-width}
\emph{maximal-width}.

Call an instruction position \emph{routing} if both of its possible
successors occur on reachable executions between two consecutive reads.
Positions with only one reachable successor do not split a residual class.
Consequently,
\begin{equation}\label{eq:basic-routing}
  N'(k+1)\le 2m_{\rm route}+E(k),
\end{equation}
where $m_{\rm route}$ is the number of routing real-instruction positions.
The factor two allows the two outcomes of each routing position.

It is not enough to count positions: repeated roots are legal.  We therefore
bound routing positions by the number of distinct root values.

\begin{lemma}[Block-incidence lemma]\label{lem:block}
If a decoded program contains $L$ distinct real instruction-root values,
then
\[
  m_{\rm route}\le 3L-3
  \quad\text{and hence}\quad
  N'(k+1)\le 6L+E(k).
\]
\end{lemma}

\begin{proof}
Root sorting places every occurrence of one value in a contiguous block.
Draw each matched control-flow pair as an arc above the instruction line and
contract each block to a vertex.  The arcs are noncrossing, so after parallel
edges are identified the block-incidence graph is a simple outerplanar graph.
It has at most $2L-3$ edges.

At most one opening instruction routes in each block.  Indeed, after the
first opener in a block, execution can enter the next equal opener only by
falling through its predecessor or by a loop edge landing immediately after
an equal test.  Both entries certify the same truth value of the unchanged
register, so the later opener cannot take both successors.

Charge a routing closer to the incidence between its block and its partner's
opener block.  All closers with the same incidence are consecutive within
their block.  After the first, entry is either fallthrough with the common
condition false or a skip landing after the preceding closer, again with that
condition false; the register is unchanged between them.  Thus each incidence
is charged at most once.  There are at most $L$ routing openers and at most
$2L-3$ routing closers.  Substitute this in
\eqref{eq:basic-routing}.
\end{proof}

\begin{corollary}\label{cor:roots}
Every Polynomial program for a maximal-width truth table has
$L=\Omega(T/\log T)$ distinct positive real instruction roots.
\end{corollary}

\begin{proof}
Combine \eqref{eq:residual-width} with Lemma~\ref{lem:block}.
\end{proof}

\section{A tail theorem for exponential sums}\label{sec:tail}

The coefficient bound rests on a dual certificate.  We first prove the
analytic statement that controls its norm.

\begin{theorem}[Each leading zero buys one root]\label{thm:tail}
Let
\[
  \rho_1>\cdots>\rho_c\ge2,
  \qquad y_i=\rho_i^{-1},
\]
and let $Z\subset\N_{>0}$ have $c-1$ elements.  Suppose that
\[
  u_d=\sum_{i=1}^{c}a_i y_i^d,
  \qquad u_0=1,
  \qquad u_z=0\quad(z\in Z).
\]
Let $f$ be maximal such that $\{1,\ldots,f\}\subseteq Z$.  Then
\begin{equation}\label{eq:tail-bound}
  \Tail(u):=\sum_{d\ge1}|u_d|
  \le \prod_{i=1}^{f+1}\frac{y_i}{1-y_i}
  =\frac{1}{\prod_{i=1}^{f+1}(\rho_i-1)}.
\end{equation}
Equality holds exactly when $Z=\{1,\ldots,c-1\}$.
\end{theorem}

We use the elementary zero bound that a nonzero exponential sum on $r$
distinct positive nodes has at most $r-1$ real zeros, counted with
multiplicity.  Divide by the smallest node to the real power and apply
Rolle's theorem inductively.  In particular, an $r$-node sum with $r-1$
specified zeros has no others and changes sign at each specified zero.

\begin{proof}[Proof of Theorem~\ref{thm:tail}]
Induct on the number $c-1-f$ of displaced zeros.

If $Z=\{1,\ldots,c-1\}$, put
\[
  U(x)=\sum_{d\ge0}u_dx^d
      =\frac{N(x)}{\prod_i(1-y_ix)},
  \qquad \deg N\le c-1.
\]
The first $c-1$ nonconstant coefficients of $U$ vanish.  Comparing the
coefficient of $x^c$ gives, for $d\ge c$,
\[
  u_d=(-1)^{c+1}\Bigl(\prod_i y_i\Bigr)h_{d-c}(y_1,\ldots,y_c),
\]
where $h_j$ is the complete homogeneous symmetric polynomial.  These terms
have one sign, and therefore
\[
  \Tail(u)=\Bigl(\prod_i y_i\Bigr)
            \sum_{j\ge0}h_j(y_1,\ldots,y_c)
          =\prod_i\frac{y_i}{1-y_i}.
\]

Now assume that a zero is displaced.  Set $z=\max Z$,
$Z'=Z\setminus\{z\}$, and $m=\max Z'$, with $m=0$ if $Z'$ is empty.  Let
$F$ be the exponential sum on $y_1,\ldots,y_{c-1}$ satisfying
$F_0=1$ and $F|_{Z'}=0$.  Let $G$ be the sum on all $c$ nodes satisfying
$G|_{\{0\}\cup Z'}=0$ and $G_z=1$.  Uniqueness in the corresponding
Vandermonde systems gives
\[
  u=F+\lambda G,qquad \lambda=-F_z.
\]
The induction hypothesis gives the desired bound for $F$, on the same first
$f+1$ roots.  It remains to show $\Tail(u)\le\Tail(F)$.

The zero bound fixes all signs.  Put $\eta=\sgn(F_z)$ and
$\mu=|F_z|$.  Away from $Z'$, the two sequences $F$ and $G$ have constant
relative sign $\eta$, while $u$ changes sign at $z$ and $F$ does not.  Hence
\[
 |u_d|=\bigl||F_d|-\mu|G_d|\bigr|,
\]
with $|F_d|>\mu|G_d|$ below $z$ and the reverse inequality above $z$.
Writing
\[
  \Gamma_V(z)=\frac{\sum_{d\ge z}|V_d|}{|V_z|},
\]
the resulting exact split of the two tails reduces
$\Tail(u)\le\Tail(F)$ to
\begin{equation}\label{eq:gamma-target}
  \Gamma_G(z)\le2\Gamma_F(z).
\end{equation}

We prove the stronger estimate
\begin{equation}\label{eq:gamma-strong}
  \Gamma_G(z)\le\frac{\Gamma_F(z)}{1-y_c}.
\end{equation}
Let $\widehat F_d=\eta F_d>0$ for $d>m$ and
$E_d=G_d-y_cG_{d-1}$.  The latter is an exponential sum on the first
$c-1$ nodes.  The required comparison is
\begin{equation}\label{eq:drive}
  \frac{E_d}{\widehat F_d}
  \le\frac{G_z}{\widehat F_z}
  \qquad(d\ge z>m).
\end{equation}
Indeed, induction in the recurrence $G_d=y_cG_{d-1}+E_d$ then gives
\[
  \frac{G_{z+t}}{G_z}
  \le\sum_{j=0}^{t}y_c^{,t-j}
       \frac{\widehat F_{z+j}}{\widehat F_z}.
\]
All $G_d$ for $d\ge z$ are positive.  Summing in $t$ proves
\eqref{eq:gamma-strong}.  Since $y_c\le1/2$, this implies
\eqref{eq:gamma-target}.

It remains to verify \eqref{eq:drive}.  Write
\[
 A=\{0\}\cup Z'=\{a_1=0<\cdots<a_{c-1}=m\},\qquad
 \sigma=\frac{G_{m+1}}{\widehat F_{m+1}},
\]
and define the $(c-1)$-node exponential sum
\[
  \Delta_d=\sigma\widehat F_d-E_d.
\]
It is either identically zero or has at most $c-2$ real zeros.  It vanishes
at $m+1$ and at each $d$ for which $d-1,d\in A$.  At every remaining
$d=a_{j+1}\in Z'$, its nonzero sign is $(-1)^{c-1-j}$.  Between two
successive such points, parity forces one more zero than the consecutive
pairs already provide.  In total these are exactly $c-2$ zeros.  They are
all simple and no zero lies above $m+1$, so $\Delta_d\ge0$ for $d\ge m+1$.
Thus
\begin{equation}\label{eq:first-drive}
  \frac{E_d}{\widehat F_d}\le\sigma\qquad(d\ge m+1).
\end{equation}
For the other half, the $c$-node sum
\[
  W_d=\widehat F_{m+1}G_d-G_{m+1}\widehat F_d
\]
vanishes on $Z'\cup\{m+1\}$.  These are all its $c-1$ possible zeros.  It
is positive beyond $m+1$: asymptotically only $G$ contains the largest node
$y_c$, with positive coefficient there.  Hence
\begin{equation}\label{eq:second-drive}
  \sigma\le\frac{G_z}{\widehat F_z}\qquad(z>m).
\end{equation}
Equations \eqref{eq:first-drive} and \eqref{eq:second-drive} give
\eqref{eq:drive}.

In the displaced case the tail comparison is strict.  Equality throughout
requires the all-leading zero set treated in the base case.  This completes
the induction.
\end{proof}

\section{From the tail theorem to coefficient mass}\label{sec:mass}

Let
\[
  P(x)=\prod_{i=1}^{L}(x-r_i),
  \qquad 2\le r_1<\cdots<r_L,
\]
and let $F(x)=\sum_{j=0}^{D}f_jx^j\in\R[x]$ be a nonzero multiple of $P$.
After scaling, assume $|f_D|=1$.

\begin{lemma}[Slack certificate]\label{lem:slack}
Fix $0\le u\le(L-1)/2$ and any set $U$ of $u$ coefficient positions below
$D$.  Some position $j<D$ outside $U$ satisfies
\begin{equation}\label{eq:threshold}
  |f_j|\ge \prod_{i=2u+1}^{L}(r_i-1).
\end{equation}
\end{lemma}

\begin{proof}
Put $c=L-u$ and use the $c$ largest roots.  Read coefficient positions
backwards from $D$.  Choose a $c$-node exponential sum $w$ with $w_D=1$
whose $c-1$ zeros occur at the positions in $U$ together with the first
$L-2u-1$ backward distances not occupied by $U$.  The Vandermonde system is
nonsingular, and $w$ lies in the row space of the equations $F(r_i)=0$.
Thus
\[
  1=|f_Dw_D|
   \le\sum_{j<D,\,j\notin U}|f_jw_j|.
\]
The selected zero set begins with a run of at least $L-2u-1$ backward
positions.  Theorem~\ref{thm:tail}, applied to the reciprocal roots, gives
\[
  \sum_{j<D,\,j\notin U}|w_j|
  \le\frac{1}{\prod_{i=2u+1}^{L}(r_i-1)}.
\]
If every coefficient outside $U$ were smaller than the right side of
\eqref{eq:threshold}, the preceding two displays would contradict each
other.
\end{proof}

\begin{theorem}[Mass of every multiple]\label{thm:mass}
Every nonzero real multiple $F$ of $P$ satisfies
\begin{equation}\label{eq:mass-general}
  \sum_{j:f_j\ne0}\log^+|f_j|
  \ge \sum_{u=0}^{\lfloor(L-1)/2\rfloor}
       \sum_{i=2u+1}^{L}\log(r_i-1),
\end{equation}
after normalising $|f_D|\ge1$, where $\log^+x=\max(0,\log x)$.
For the first $L$ primes, or for any increasing prime powers bounded below
by them, the right side is $\Omega(L^2\log L)$.
\end{theorem}

\begin{proof}
For each $u$, take $U$ to be the positions of the $u$ largest coefficients
below the leading term.  Lemma~\ref{lem:slack} produces a new coefficient,
the $(u+1)$st largest, of size at least the threshold in
\eqref{eq:threshold}.  Summing its logarithm over $u$ proves
\eqref{eq:mass-general}.

For prime roots $p_1<\cdots<p_L$, each $\log(p_i-1)$ appears
$\lceil i/2\rceil$ times, up to reversing the harmless indexing convention.
The prime number theorem, or the elementary bound $p_i\ge i+1$, yields
\[
  \sum_{i=1}^{L}\lceil i/2\rceil\log(p_i-1)
  =\Omega(L^2\log L).
\]
The sharper asymptotic constant is $1/4$ in natural logarithms.
\end{proof}

The theorem is deliberately stated over $\R$: integrality and the signs of
the other roots play no role.  Additional roots merely choose another
multiple $F$ and cannot evade the bound.

\begin{corollary}[Polynomial lower bound]\label{cor:lower}
Every Polynomial source for a maximal-width truth table has
\[
  |f|=\Omega(T^2/\log T).
\]
\end{corollary}

\begin{proof}
By Corollary~\ref{cor:roots}, the program contains
$L=\Omega(T/\log T)$ distinct positive real instruction roots.  Their
bases are distinct assigned primes, and a prime power is no smaller than its
base.  The source polynomial is a multiple of their distinct-root product.
Theorem~\ref{thm:mass} therefore gives
\[
 M(f)=\Omega(L^2\log L)
     =\Omega\!\left(\frac{T^2}{\log T}\right).
\]
Since $|f|\ge M(f)$, the result follows.
\end{proof}

\begin{remark}[Repeated roots]
Repeated real roots do not weaken Corollary~\ref{cor:lower}: the
block-incidence lemma already forces the stated number of \emph{distinct}
values.  A separate confluent version of Theorem~\ref{thm:tail} follows by a
Hermite limit, replacing $a_iy_i^d$ with $Q_i(d)y_i^d$ and repeating each
$y_i$ according to $1+\deg Q_i$.  It yields an independent quadratic mass
bound in the total multiplicity, but is not needed for the sharp language
bound.
\end{remark}

\section{The matching construction}\label{sec:upper}

The residual DAG of a truth table has at most
\[
  s_k=\min\bigl(2^k,2^{2^{n-k}}\bigr)
\]
states after $k$ reads: the first term counts input prefixes, and the second
counts Boolean residuals of the remaining width.  Put
$h=\lfloor\log_2 n\rfloor-1$.  The levels with $n-k\le h$ contribute
$O(\sqrt T\log n)=O(T/n)$ states; the earlier levels form a geometric tail
of size $O(T/2^h)=O(T/n)$.  Hence
\[
  S:=\sum_k s_k=O(T/\log T).
\]

The direct Polynomial encoding of this DAG uses at most six instructions per
state, so it has $m=O(S)$ instruction factors.  Its operands are $O(S)$,
its instruction exponents are bounded constants, and its assigned primes are
at most $p_m=O(m\log m)$.  Every linear or quadratic factor therefore has
coefficient $\ell^1$ norm $m^{O(1)}$.  Submultiplicativity gives coefficient
norm $m^{O(m)}$ for their product, so each expanded coefficient has
$O(m\log m)$ decimal digits.  There are at most $2m+1$ coefficients, while
exponents and separators contribute only $O(m\log m)$.  Therefore
\[
  |f|=O(m^2\log m)
      =O\!\left(\frac{T^2}{\log T}\right).
\]
Together with Corollary~\ref{cor:lower}, this proves
Theorem~\ref{thm:main}.

\section{Scope and reproducibility}

The result concerns source length, not the running time of polynomial
factorisation or of source generation.  It allows arbitrary degrees,
arbitrary operand signs, repeated roots, and arbitrary unrecognised cofactor
roots.  It is an existence theorem for the uncapped residual-DAG
construction; the public generator may impose a resource cap before reaching
the asymptotic family.

The companion repository contains executable checks of the finite identities
used above.  In particular,
\texttt{tests/proofs/test\_negatives.py} checks the tail identities and dual
thresholds in exact arithmetic, while
\texttt{tests/proofs/deep/multiplicity.py} checks the block charges,
outerplanar count, and repeated-root cases.  The longer development record,
including counterexamples to earlier proof attempts and bounded searches, is
in \texttt{docs/proofs/polynomial.md}.  These computations support the proof but no
bounded search is used as a premise.
